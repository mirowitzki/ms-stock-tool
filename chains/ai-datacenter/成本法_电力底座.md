# 闸门② 成本法 · 电力底座：价值在这条链的哪一节（只论产业链，不碰个股）

> 数据时点 2026-06。这一关只在产业链上找真正的价值在哪一节、是否持久。个股的估值、贵不贵、买不买，全部留给第一阶段单股工具——你过完闸门、锁定价值在哪个环节，再自己把那一节的公司丢进工具深析。
> 所以下面没有任何个股推荐或估值判断；提到公司只为说清这一节由谁占据、集中度如何。基调：发现价值、不批判。

---

## 一、钱流过哪里（成本栈，是背景不是结论）

给一座 AI 数据中心供上电，钱怎么分：含 GPU / 服务器全口径，电气占总投资不到 10%——但它是 100% 的瓶颈（没电，再多 GPU 也开不了机）。只算建设（不含 IT），电气约 40–50%、是最大一桶。

电气这桶内部相对大小（口径含散热）：备用柴油发电机最大（约 1/5）＞ UPS（约 16%）＞ 中压配电+开关柜（约 11%）＞ 大型变压器 ≈ 母线/PDU（各约 2%）；散热本身其实更大（约 32%，叫电力底座可聚焦电气，但要知道它在旁边）。走能源孤岛自建电源时，自建发电另成最大一桶。

关键：成本栈告诉你钱花在哪，但钱花得多的地方 ≠ 价值留得住的地方。下面就是把花钱和留住价值分开。

---

## 二、价值在每一节怎么被创造、又被谁占有

一个环节能长期拿走超额利润，要三个条件同时成立、且持续：必要（绕不过）＋ 稀缺（供给扩不出来）＋ 可占有（这份稀缺有壁垒守住——工艺 / IP / 良率 / 关系，而不只是暂时产能不够）。三者缺一，超额利润就守不住。逐节看价值被谁占有：

- 发电（燃气轮机）：创造＝把燃料变成马上能用的可调度电力。占有不在总装——总装利润薄；占有在两处：更上游的单晶高温合金叶片铸造（工艺卡口），和卖出后几十年的服务合同（锁定）。
- 输配（变压器）：创造＝升降压把电送进来。占有在短缺期落到上游材料（铜 + 取向硅钢 GOES）；变压器组装本身被中国约 60% 产能打成商品、拼价格。
- 机房配电（UPS / 开关柜）：创造＝把电安全送到机柜。占有在功率半导体（尤其 SiC）和开关柜寡头；UPS 总装利润中等。
- 储能（BESS）：创造＝储电、削峰、备电。占有在电芯（LFP）；集成端薄利。

一句话：电力底座的钱大多花在发电机、UPS、变压器总装这些总装/大宗环节，但价值被它们上游的卡脖子材料、关键芯片，以及发电机卖出后的服务合同抽走了。

## 三、租金 vs 护城河：哪些价值持久，哪些是短缺顶点的租金

这是这一关的核心。同样叫卡脖子，有的是结构护城河（穿越周期），有的只是短缺顶点的周期租金（产能一补上就回吐）。差别就在第二节那个可占有——稀缺是结构性的、还是暂时产能不够。逐个卡脖子判：

| 环节 | 必要 | 稀缺 | 可占有（是否持久） | 判定 |
|---|---|---|---|---|
| 单晶叶片铸造 | 是 | 是（全球就几家铸造厂、双位数废品率） | 持久——靠几十年工艺 / 冶金 / 良率积累 + 铸造装备本身受限 + 买方（整机厂）难后向一体化 | 持久结构护城河（全链最硬） |
| 燃机服务年金 | 是 | 是（只能用原厂服务） | 持久——转换成本 + 装机基数滚动越滚越大 | 持久，但是整机 OEM 的属性、非独立环节 |
| 取向硅钢 GOES | 是 | 弱（美国唯一是区域 / 贸易错配；全球 5+ 家、中国占约 56% 产量且在扩、已喊过剩） | 不持久——产能可以建 | 周期租金，短缺一缓解就回吐 |
| 大型变压器组装 | 是 | 弱（中国约 60% 产能） | 不持久——拼价格 | 商品 |
| 开关柜 | 是 | 中（寡头 + 一次设备 / 认证） | 半持久——寡头 + 认证有壁垒，但也在扩产 | 介于租金与护城河之间 |
| IGBT 功率半导体 | 是 | 弱（成熟、分散、国产价格战） | 不持久 | 商品化中 |
| SiC 功率半导体 | 是 | 中（衬底 / 工艺壁垒真） | 半持久——但中国 8 寸扩产在压价、自己也在被商品化 | 有壁垒但正被侵蚀 |
| 柴油备电、铜铝母线 | 是 | 弱（成熟 / 大宗） | 不持久 | 商品、苦力 |
| 储能电芯 LFP | 渐成必要 | 弱（产能过剩、价格战） | 不持久（但是价值迁入侧，见第五节） | 卷，但方向在变 |

读这张表的方式：电力底座里真正穿越周期的持久价值，只有两处——单晶叶片铸造、燃机服务年金；它们的共同点是供给扩不出来、买方绕不开。其余看起来很肥的环节（变压器、GOES、燃机整机），肥的那部分大半是下一节要讲的短缺顶点租金。

## 四、资本周期：整条链在顶点，最肥的两节正是最顶点的两节

这一整轮电力大建设本身就是一个 capex 超级周期。当前那些惊人的数字——GSU 变压器交期约 3 年（144 周、部分最长 4 年，Wood Mac Q2'25 口径，2026-06 核实修正旧引用"4 年"）、燃气轮机裸机 $/kW 自 2019 涨 195%、新单还能再加价 10–20%、利润率 +500bps——是短缺顶点的指纹，不是护城河的指纹。判据很硬：产能墙已经在建。

| 环节 | 当前暴利信号 | 产能墙 / 见顶信号 | 周期位置 |
|---|---|---|---|
| 变压器 + GOES | 交期 4 年、GSU 需求 2019→2025 涨 274%、价格近 5 年翻倍 | 各家 $1B+ 扩产、新厂 2027–28 投产；缺口 100%(2025)→<10%(2030, Wood Mac) | 顶点 |
| 燃气轮机 + 整机 | 订单 100GW vs 产能 60–70GW、新单再加价 10–20% | Wood Mac 点名燃机 2026 见顶；三寡头各扩产 25–35% | 顶点 |

资本疯狂涌入扩产（各家 $1B+ 新厂）本身就是回报即将见顶的信号。结论：变压器和燃机整机现在看起来价值最厚，但那层厚利润里有一大块是周期租金，2027–28 产能墙落成会回吐。真正穿越周期的，是供给扩不出来的那两节（单晶叶片、服务年金）——它们不在涨价最猛的地方，反而是最容易被这波短缺叙事盖过的地方。

## 四·五、适用边界：中美市场分叉（发电这节是谁的命题）

> 2026-06-10 新增（独立核数 agent 多源核实；此前版本把美国能源经济学的故事全球化了，被用户两轮质疑戳穿——本节就是修正 + 把"适用边界"立成闸门②的必填规格）。

同一节产业链，换一个要素价格和电网体制，经济账完全反转：

- 美国：页岩气 Henry Hub 约 $3-3.5/MMBtu（2025 年均 $3.52，EIA）、电网并网中位等待约 4.6 年（在队约 2,060-2,290GW；旧引用 2,600GW 是 2023 年峰值，2024-25 已回落，LBNL）。用 $3.5 的气自发电，燃料成本约 2.4-3.0¢/kWh、加折旧运维全成本约 4-5¢/kWh，显著低于工业电价约 8.6-9¢/kWh——自建燃机既省钱又绕开排队。所以是真金白银在建：xAI 孟菲斯 15 台 SMT-130 约 247MW、密西西比 Colossus 2 已部署 Titan-350 约 250MW（规划超 1.1GW）、OpenAI Abilene 约 360MW 自建气电、Meta 俄亥俄 2×200MW behind-the-meter。数据中心烧气，是美国命题。
- 中国：工业管道气到厂折约 $14-15/MMBtu（36 城均价约 3.58 元/方）、LNG 现货正常约 $10-13——同一台燃机燃料成本 7.5-12.6¢/kWh，高于东部工业电价约 9.7¢，更被西部枢纽 2-3.6¢/kWh 的绿电/谷电碾压；叠加煤电托底与国家统调体制，自建燃机账算不平。中国数据中心的主流＝双路市电 + 柴油备用 + UPS、绿电直购/绿证；东数西算西部枢纽走风光储微电网（新建 80% 可再生要求）；燃气三联供只有个别探索案例、不是路线。
- 含义（给本页所有判断标边界）：单晶叶片与燃机服务年金的持久价值由全球（主要美国）需求撑。A 股的相关方式只有两条——① 叶片铸造等环节做全球供应链的出口供应商（吃美国数据中心 capex，如应流 603308 之于全球整机厂+航发）；② 中国本土的真机会在电网/绿电/储能侧（特高压外送、风光储、绿电交易），不在本土燃机需求。把一国的能源经济账套到另一国，这页结论即不成立。

## 五、价值往哪迁移（动态：发现价值不能只看现在的利润池）

价值地图是动的。静态看价值在变压器 / 燃机；动态看价值正在往别处流。这是原版漏掉、却很关键的一层：

- 备电架构：BESS 正在釜底抽薪 UPS + 柴油机——AI 训练的突发尖峰负载打破了 UPS 撑几分钟、柴油机接力 的老模型。若架构迁到大储能，价值会从 UPS 里的功率半导体，迁向电芯 / PCS / EMS。这是电力底座价值迁移最大的一条暗线。
- 功率器件：硅基 IGBT → SiC（更高效、TCO 多数已翻正）。押 IGBT 存量＝押被颠覆方；但 SiC 自己又在被中国 8 寸扩产压价。
- 变压器：工频铜 + GOES → 固态变压器 SST（用功率电子替代部分铁芯，2028 起放量）。这是对变压器 / GOES 护城河的远端期权式威胁。
- 供电路线：电网接入 → 自建电源 / 能源孤岛（燃机 / SMR）。价值从并网环节迁向自建发电。

洞察：电力底座今天的利润池在变压器和燃机，但利润池正在往储能电化学和宽禁带半导体（SiC）迁。要发现真正的价值，得同时看现在在哪、和正往哪流。

## 六、国产替代双面卡（A股 在这条链的相关性，环节层）

同一个环节，在 A股 和海外的含义常常相反。电力底座里：

- 单晶叶片：A 股相关性是出口供应商逻辑（给全球整机厂+航发供货、吃美国数据中心 capex）——不是中国本土燃机需求（见四·五适用边界）；国产高端替代另算一条线，是国家级长期攻关、慢。
- 变压器 / GOES：中国产能过剩 + 面对多国反倾销 + 欧盟 CBAM 2026 落地，出口逻辑正在被围堵；机会面有限、且是周期租金。
- IGBT：国产已是内卷血海（扩产 + 价格战），不是机会、是反噬。
- 储能电芯：中国主导，但产能过剩、价格战。

环节层结论：A股 在电力底座的真国产机会很窄——最硬的国产空白（高端叶片）最难突破，多数环节是过剩内卷。这条链的 A股 故事，多是出口受益（被反倾销围堵）或内卷替代，少有又硬又开放的真空白。

## 七、综合：电力底座的价值地图（三档）

剥掉短缺顶点的周期租金、再叠上价值迁移方向，电力底座真正的价值落点是这样：

- 持久结构价值（穿越周期、最值得拿去深析）：单晶叶片铸造（全链最硬的卡口）、燃机服务年金（锁定型现金流）。这两处供给扩不出来、买方绕不开。
- 真实但周期性（短缺顶点租金、会回吐，要等供给墙）：大型变压器、燃机整机、GOES、开关柜。值得关注，但厚利润里一大块是周期 froth，别当永续。
- 价值正在迁入的下一站（动态机会）：储能电芯 / PCS / EMS、SiC。是利润池流向的方向，但本身也在卷、要挑壁垒能立住的细分。
- 苦力 / 商品（价值占有低、不必深究）：柴油备电、铜铝母线、IGBT 存量、变压器总装。

比任何环节都上位的两个结构事实（决定整张地图成不成立）：① 2027–28 供给墙——日立 / 西门子新厂、变压器缺口 100%→<10%，是这条链短缺反转的窗口；② capex / 收入 13:1 变现缺口——一旦 2027–28 AI 收入跟不上、叠加新产能，整条链需求供给同时反向。这两条是看整条电力底座时始终要盯的背景。

## 一句话闸门②结论

电力底座现在看起来最有价值的是变压器和燃机（因为短缺、涨价最猛），但拆到结构层，真正持久的价值只在两个供给扩不出来的卡口——单晶叶片铸造和燃机服务年金；其余的厚利润是短缺顶点的周期租金、会被 2027–28 产能墙吃掉；而价值正在往储能电化学和宽禁带半导体（SiC）迁移。

要深析，就深析那两节持久价值（叶片铸造、服务年金），或者下注价值迁移的下一站（储能电化学 / SiC）。挑哪个环节、再去找环节里的公司丢进第一阶段——由你定，这一关不替你选股。
