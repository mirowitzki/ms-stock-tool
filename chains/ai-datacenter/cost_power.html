💵 钱流过哪里（成本栈，是背景不是结论）
给一座 AI 数据中心供上电，钱怎么分。先看清，再说价值。

含 GPU / 服务器全口径，电气只占总投资不到 10%——但它是 100% 的瓶颈（没电，再多 GPU 也开不了机）。只算建设（不含 IT 设备），电气约 40–50%、是最大一桶。这桶内部相对大小（口径含散热）：

关键：钱花得多的地方 ≠ 价值留得住的地方。变压器只占约 2%、却是头号交期瓶颈；散热其实是更大的一桶（约 32%）。下面就把花钱和留住价值分开。

🧲 价值靠什么被占有（第一性原理）
一个环节能长期拿走超额利润，要三个条件同时且持续成立。

必要（绕不过）＋ 稀缺（供给扩不出来）＋ 可占有（这份稀缺有壁垒守住——工艺 / IP / 良率 / 关系，而不只是暂时产能不够）。三者缺一，超额利润就守不住。逐节看价值被谁占有——

发电（燃气轮机）：占有不在总装，在更上游的单晶叶片铸造、和卖出后几十年的服务年金 LTSA。输配（变压器）：占有在短缺期落到上游材料（铜 + 取向硅钢 GOES）；总装被中国约 60% 产能打成商品。机房配电（UPS / 开关柜）：占有在功率半导体（尤其 SiC）。储能（BESS）：占有在电芯（LFP）。一句话：钱大多花在发电机、UPS、变压器总装这些大宗环节，价值却被它们上游的卡脖子材料、关键芯片、以及卖出后的服务合同抽走了。

🏰 租金 vs 护城河（这一关的核心）
同样叫卡脖子，有的是结构护城河（穿越周期），有的只是短缺顶点的周期租金（产能一补上就回吐）。差别就在可占有是不是持久。
环节稀缺可占有（是否持久）判定

真正穿越周期的持久价值只有两处：单晶叶片铸造、燃机服务年金——供给扩不出来、买方绕不开。其余看着很肥的环节（变压器、GOES、燃机整机），肥的那部分大半是下一节的短缺顶点租金。

📉 资本周期：整条链在顶点，最肥的两节正是最顶点
这一整轮电力大建设本身就是个 capex 超级周期。

GSU 变压器交期约 3 年（144 周、部分最长 4 年，Wood Mac Q2'25 口径，2026-06 核实修正旧引用"4 年"）、燃气轮机裸机 $/kW 自 2019 涨 195%、新单还能再加价 10–20%、利润率 +500bps——这是短缺顶点的指纹，不是护城河的指纹。判据很硬：产能墙已经在建（各家 $1B+ 扩产、新厂 2027–28 投产、燃机三寡头各扩产 25–35%；变压器缺口 100%(2025)→<10%(2030, Wood Mac)）。资本疯狂涌入扩产本身，就是回报即将见顶的信号。

结论：变压器和燃机整机现在看着价值最厚，但那层厚利润里有一大块是周期租金，2027–28 产能墙落成会回吐。真正穿越周期的，是供给扩不出来的那两节——它们不在涨价最猛的地方，反而最容易被短缺叙事盖过。

🌏 适用边界：中美市场分叉（发电这节是谁的命题）
同一节产业链，换一个要素价格和电网体制，经济账完全反转。数据 2026-06 独立核实（多源）。

美国：页岩气 Henry Hub 约 $3-3.5/MMBtu（2025 年均 $3.52，EIA）、电网并网中位等待约 4.6 年（在队约 2,060-2,290GW；旧引用 2,600GW 是 2023 峰值、2024-25 已回落，LBNL）。用 $3.5 的气自发电，燃料成本约 2.4-3.0¢/kWh、加折旧运维全成本约 4-5¢/kWh，显著低于工业电价约 8.6-9¢/kWh——自建燃机既省钱又绕开排队。所以是真金白银在建：xAI 孟菲斯 15 台 SMT-130 约 247MW、密西西比 Colossus 2 已部署 Titan-350 约 250MW（规划超 1.1GW）、OpenAI Abilene 约 360MW 自建气电、Meta 俄亥俄 2×200MW。数据中心烧气，是美国命题。

中国：工业管道气到厂折约 $14-15/MMBtu（36 城均价约 3.58 元/方）、LNG 现货正常约 $10-13——同一台燃机燃料成本 7.5-12.6¢/kWh，高于东部工业电价约 9.7¢，更被西部枢纽 2-3.6¢/kWh 的绿电/谷电碾压；叠加煤电托底与国家统调，自建燃机账算不平。中国数据中心的主流＝双路市电＋柴油备用＋UPS、绿电直购/绿证；东数西算西部枢纽走风光储微电网（新建 80% 可再生）；燃气三联供只有个别探索案例、不是路线。

含义（给本页所有判断标边界）：单晶叶片与燃机服务年金的持久价值由全球（主要美国）需求撑。A股 的相关方式只有两条——① 叶片铸造等环节做全球供应链的出口供应商（吃美国数据中心 capex）；② 中国本土的真机会在电网/绿电/储能侧（特高压外送、风光储、绿电交易），不在本土燃机需求。把一国的能源经济账套到另一国，本页结论即不成立。

➡️ 价值往哪迁移（发现价值不能只看现在的利润池）
价值地图是动的。静态看价值在变压器 / 燃机，动态看它正往别处流。
备电架构：UPS ＋ 柴油机→大储能 BESS（价值迁向电芯 / PCS / EMS）
功率器件：硅基 IGBT→SiC（押 IGBT 存量＝押被颠覆方）
变压器：工频铜 ＋ GOES→固态变压器 SST（2028 起，远端威胁）
供电路线：电网接入→自建电源 / 能源孤岛（燃机 / SMR）

洞察：电力底座今天的利润池在变压器和燃机，但正在往储能电化学和宽禁带半导体（SiC）迁。要发现真正的价值，得同时看现在在哪、和正往哪流。BESS 釜底抽薪 UPS+柴油机这条，是原版漏掉、却最大的一条暗线。

🇨🇳 国产替代双面卡（A股 在这条链的相关性）
同一个环节，在 A股 和海外的含义常常相反。

单晶叶片：A股 相关性是出口供应商逻辑（给全球整机厂+航发供货、吃美国数据中心 capex）——不是中国本土燃机需求（见适用边界节）；国产高端替代另算一条线、国家级长期攻关，慢。变压器 / GOES：中国产能过剩 + 多国反倾销 + 欧盟 CBAM 2026 落地，出口逻辑正被围堵。IGBT：国产已是内卷血海（扩产 + 价格战），不是机会、是反噬。储能电芯：中国主导，但产能过剩、价格战。一句话：A股 在电力底座的相关方式就两条——出口供应链吃美国 capex，或回到中国本土真正的电力侧机会（电网/绿电/储能）；本土燃机需求不是其中之一。

🗺️ 电力底座的价值地图（三档 + 苦力）
剥掉短缺顶点的周期租金、再叠上价值迁移方向，价值的真实落点是这样。
持久结构价值（穿越周期、最值得拿去深析）
单晶叶片铸造（全链最硬的卡口）、燃机服务年金（锁定型现金流）。这两处供给扩不出来、买方绕不开。
真实但周期性（短缺顶点租金、会回吐，要等供给墙）
大型变压器、燃机整机、GOES、开关柜。值得关注，但厚利润里一大块是周期 froth，别当永续。
价值正在迁入的下一站（动态机会）
储能电芯 / PCS / EMS、SiC。是利润池流向的方向，但本身也在卷，要挑壁垒能立住的细分。
苦力 / 商品（价值占有低、不必深究）
柴油备电、铜铝母线、IGBT 存量、变压器总装。

两个比任何环节都上位的背景（看整条电力底座始终要盯）：① 2027–28 供给墙——新厂投产、变压器缺口 100%→<10%，是短缺反转的窗口；② capex / 收入 13:1 变现缺口——一旦 2027–28 AI 收入跟不上、叠加新产能，整条链需求供给同时反向。

一句话结论

电力底座现在看着最有价值的是变压器和燃机（因为短缺、涨价最猛），但拆到结构层，真正持久的价值只在两个供给扩不出来的卡口——单晶叶片铸造和燃机服务年金；其余厚利润是短缺顶点的周期租金、会被 2027–28 产能墙吃掉；而价值正往储能电化学和宽禁带半导体（SiC）迁移。

要深析，就深析那两节持久价值，或下注价值迁移的下一站。挑哪个环节、再去找它的公司丢进第一阶段单股工具——由你定，这一关不替你选股。
