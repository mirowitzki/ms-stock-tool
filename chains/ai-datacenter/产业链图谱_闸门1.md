# AI 数据中心产业链图谱（闸门①·第一性原理拆解 + 候选赛道）

> 数据时点 2026-06。方法论见 skills/industry-chain.md。本文是第二阶段三道闸门的第①道：把整条链拆透、定位价值落在哪一节、端出值得研究的候选赛道供选择。深析留到闸门②③。
> 基调：发现价值，不是批判产业。下面对过热环节也只摆事实、先给善意视角、落到要盯什么。

---

## 总览：一条被资本狂潮定价到极致的链

2026 年是人类第一个万亿美元 compute 资本开支年——四大云厂 capex 约 7250 亿美元、同比约 +77%，全口径含 Oracle / neocloud / 中国 / 主权约 1.04 万亿美元（[Tom's Hardware](https://www.tomshardware.com/tech-industry/big-tech/big-techs-ai-spending-plans-reach-725-billion)、[businessengineer.ai](https://businessengineer.ai/p/the-ai-capex-map-and-the-state-of)）。Goldman 基线 2026→2031 累计跨算力 / 数据中心 / 电力约 7.6 万亿美元（[Goldman Sachs](https://www.goldmansachs.com/insights/articles/tracking-trillions-the-assumptions-shaping-scale-of-the-ai-build-out)）。

这决定了这张图谱的底色，也是它和别处不一样的地方：几乎每一个好环节都已经被市场看见、被定价。所以这条链的研究重点不在找谁是好生意（满链都是好生意），而在三件事——

1. 哪一节的护城河最硬、且超额利润不依赖 capex 永不退潮（供给受限、无人能扩的环节）。
2. 哪一节虽然好、却已经把未来多年增长付了全款（好生意贵价格，安全边际为负）。
3. 哪一节市场的隐含预期和产业现实之间还有差（variant perception，价值投资真正的 edge 所在）。

底层还悬着一个 β 风险：需求地基有第一批可证伪的裂缝——capex 与直接 AI 收入约 13:1、Burry 质疑 GPU 折旧假设激进、微软冻结 1.5GW 自建并退租、OpenAI 收入与用户双不及内部目标、Sightline 估 2026 年 30–50% 数据中心延期或取消、英伟达股权投资敞口超 400 亿美元形成循环融资（[CNBC](https://www.cnbc.com/2025/11/14/ai-gpu-depreciation-coreweave-nvidia-michael-burry.html)、[SemiAnalysis](https://newsletter.semianalysis.com/p/microsofts-datacenter-freeze)、[DCD](https://www.datacenterdynamics.com/en/news/openai-missed-revenue-and-user-targets-faces-internal-concern-over-meeting-data-center-spend-commitments-report/)）。多方的反驳同样成立（建设方是史上最赚钱的公司、瀑布式折旧有合理性、全线供不应求佐证真需求）。这不是有没有泡沫的二元题，而是回本窗口能不能跑赢 3–5 年折旧的赔率题。纪律：用中周期归一化估值、别在峰值付全款、对循环融资敞口大的标的要更厚的安全边际。

## 第一性原理：这条链在交付什么

价值锚：单位成本最低的有效算力（每美元能算多少有用的训练 / 推理 token）。整条链的每一节，都是为把电和资本转成最便宜的有效算力而存在。从这个锚往上推每一节没有它成不成——

```
        ┌─────────────────────────  有效算力（训练/推理 token）  ─────────────────────────┐
        │                                                                                  │
   [算] 逻辑芯片 GPU/ASIC ──喂数据── [存] HBM ──做出来── [造] 晶圆代工 + 先进封装
        │                                                                                  │
   [连] 芯片间通信：光模块 / 光芯片EML / DSP / 交换芯片 / 铜连接 / CPO
        │                                                                                  │
   [电] 供电底座：发电(燃气轮机/SMR) → 输配(变压器/GOES钢) → 并网 → 机房配电(UPS/母线/PDU)
        │                                                                                  │
   [冷] 散热：风冷→液冷(冷板/CDU)→浸没        [装] 数据中心建设/机柜/预制模块
        │                                                                                  │
   [拼] 服务器ODM整机组装        [运] IDC/数据中心运营
        │                                                                                  │
   [软] 贯穿全链的护城河：CUDA 软件生态（英伟达真正的城墙，正被ASIC商品化）
```

那把刀（原理必须 vs 当下技术选择，决定能不能长期押）：
- 原理上必须、价值稳固：芯片必须被喂数据（HBM）、必须被制造（代工/封装）、必须供电、必须散热。这些是物理铁律。
- 只是当下技术选择、价值脆弱会被替代：用 GPU 还是 ASIC（英伟达份额正被侵蚀）、用铜还是用光（边界随速率移动）、可插拔光模块还是 CPO（2028 后可能被颠覆）、风冷还是液冷（已锁死液冷）、用谁的软件栈（CUDA vs ROCm vs 自研）。这些是会变的，押注前要看它站在哪一边。

陷阱提醒（第一层命门）：物理必须 ≠ 经济上能拿走利润。服务器组装物理上不可绕过，却是全链最薄的一环（毛利 5–10%）——因为它供给不受限、可占有性低。下面第二层就专门分这个。

## 我的判断：如果先看，先看这几个

满链都被定价的背景下，最值得先研究的不是最热的（光模块、液冷、国产芯片那些已经把2027付全款的），而是护城河硬 + 还有 variant perception 的几个：

1. 变压器 / 输配电（候选10，尤其特变电工）——全链估值最不极端的硬约束环节。市场把它当煤炭/多晶硅周期股压估值，但它的电力设备 + 出口 + AIDC 那块正在垂直拉升，PE 18–24 倍 vs 满链 50–450 倍。这是最像 variant perception 的地方：好资产被周期业务的标签掩盖。需要做的是拆分部，把电力设备那块单独估出来。

2. 燃气轮机（候选9，西门子能源 vs GE Vernova）——供给纪律最强（三寡头刻意不豪赌扩产）、backlog 锁到 2030、$/kW 三年翻三倍。GE Vernova 已 52–62 倍贵，但西门子能源 29 倍是同主题的折价镜像，值得研究这个价差是否合理。

3. 光芯片 EML（候选6）——全链供给最受限、超额利润最可持续的一节，是真正的卡脖子中的卡脖子。两条研究线：美股 Lumentum/Coherent 的定价权能不能持续；A股源杰/长光华芯的高速段国产替代（<15% 缺口）是高赔率高不确定的弹性。

4. 高端 CCL 覆铜板（候选13）——A股里少数替代逻辑成立 + 壁垒真实（英伟达 M9 认证）+ 替代率还低的环节，避开了光模块/算力芯片那种已透支的拥挤。

这四个的共性：要么市场的隐含预期和产业现实之间还有差（特变、西门子能源），要么护城河硬到 capex 退潮也最后才轮到它受伤（EML、变压器）。其余赛道不是不好，是大多已经把好付了全款——它们更适合等回落、或作为对照。

## 数据诚实交底（免费联网的边界）

- 本图谱的结构判断（哪节卡脖子、利润往哪迁、谁有护城河）可信度高；具体数字（份额、毛利、交期、估值倍数）来自 2026 上半年公开财报 / 券商 / 财经媒体，随股价和季度大幅波动，仅作量级，进闸门②深析时要逐一回查到原始财报。
