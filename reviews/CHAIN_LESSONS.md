## 判断铁律（已进 industry-chain.md，这里留索引 + 来历）
1. 闸门只找价值在哪一节、是否持久，完全不碰个股估值 / 买卖——个股交第一阶段（用户两次强调）。
2. 卡脖子是周期租金、不是护城河——成本栈里最肥的环节往往正是周期最顶点。闸门②必须跑第四层（资本周期 / peak）+ 第五层（结构护城河 vs 短缺租金），别把短缺顶点的暴利当永续。（电力底座差点把变压器 / 燃机的短缺租金当护城河、被独立审稿推翻）
3. 列占位者公司必须独立 agent 联网核 + 代码再复核——凭记忆枚举上市公司必漏必错（漏了 A股单晶叶片的万泽 000534；代码 002303 其实是雅本化学），连核查 agent 自己都会把代码搞错（时代电气是 688187、不是 688008）。
4. 价值地图是动态的——发现价值要同时看现在在哪 + 往哪迁（差点漏掉 BESS 釜底抽薪 UPS+柴油机这条最大暗线）。
5. 重大判断都过独立对抗 agent（方法论审、结论审、选股核）——主动用、别等问。（2026-06-10 已制度化为 `skills/chain-check.md` 三道防线：数字与时效核查 / 结构红队 / 完备性走查，出闸门页前必过、🔴 清零才发布。）
6. **拆产业链价值要按市场（中/美）分叉——要素成本（能源/气价/电价）的国别差异会让同一环节在不同市场价值完全不同，别把一国的经济账套全球。** 典型：AI 数据中心电力底座里"数据中心烧燃气发电"基本是美国命题——美国便宜页岩气(~$3/MMBtu)+慢电网+市场化电价→自建燃机的 spark spread（火花价差）划算；中国贵进口气(~$9-13/MMBtu)+便宜煤电+国家统调+东数西算地理套利→自建燃机账算不平。含义：单晶叶片铸造/燃机服务年金的持久价值是全球（主要美国）需求撑的，对 A 股只能当全球供应链的出口供应商玩（应流 603308→全球整机厂+航发）、不是中国本土燃机需求。能源/电力这类要素成本敏感的环节，天生要做 US vs China 市场分叉；判断某环节"持久价值"时先问清是哪个市场的需求撑的。（来历：2026-06 用户两轮质疑燃机那条，戳出原电力底座成本法把一个美国能源经济学的故事全球化了。）

10. **数字的口径之外还有"性质"要核——同一个目标数，是公司目标还是法律义务，β 含义完全不同（2026-06-10 商业航天链红队抓出）**：千帆"2026 底 648 颗"——若是工程目标，跳票=商业事件；若是 ITU 频轨义务换算，跳票=丢频段级法律后果。给任何"计划 vs 实际"缺口定权重前，先问这个计划的违约后果是什么。同链还验证了两条：①扩张早期链的数据过期速度快于页面生产速度（质检期间千帆从 162 颗变 200 颗）——按季拉数不是仪式是刚需；②预测之间要写明联动关系（S2 组网节奏 × S3 运力缺口存在共因死锁，已加 scenario_interdependence 字段）——孤立打分会漏掉联动放大的尾部。

11. **渲染层丢限定词＝制造新判断；"已兑现"≠"持久"（2026-06-11 两链补底色/第一性原理节时质检抓出、高频伤）**：把 JSON 真相源的判断往页面搬时，最容易丢的不是数字、是**限定词**——"唯一已**大规模**兑现"被写成"唯一已兑现"（绝对化）、"史上首个盈利**巨型**星座"被写成"唯一盈利样本"（铱星重生后盈利、命题为假）、"中国装车口径 CR2 65%"标 rich 时口径被颜色吞掉。同源的第二刀：页面论证到"已兑现"，结论却写"持久价值"——快照判断与久期判断是两件事，分层图颜色只许表快照、久期必须另说。规矩：限定词是判断的一部分，渲染时一个字不许丢；新增可视化判级必须先进 nodes.json（map_tier）再渲染，渲染层不许发明真相源里没有的判级。另：base rate 要区分**首建股权回报 vs 重置成本回报**（铱星首建毁灭 $6B、按 $25M 重置成本重来就持续盈利）——"行业历史全亏"常常只对首建股权成立。
