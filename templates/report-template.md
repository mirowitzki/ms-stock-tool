# 完整报告模板（机构级 · 唯一交付物）

> 这是 `<TICKER>_公司完整报告.md` 的**章节骨架与深度标准**。对标专业尽调报告。
>
> **写作铁律（防止把报告写水）：**
> 1. **每章先一段「执行摘要」、再「正文详情」**（多个二级/三级小节）。
> 2. **穷尽、深挖**：每个业务线、每笔资本运作、每项治理与风险，都要给**具体数字、具体公告/事件、具体证据**——不能只给一句话结论。
> 3. **追求完整度、不限页数**。该多长就多长。绝不写成"放大版摘要"。
> 4. **深读全部年报 + 高信号公告**再动笔；先读 `reviews/LESSONS.md`。
> 5. 守反成见铁律（红旗先写善意解释）、生意与价格分开、剥离一次性、看归母、真实流动性合并算。报告里可以出现人名（实控人/董监高/关键交易对手等，用户 2026-05-31 改），但仍不给管理层贴人格标签。
> 6. **分析深度（2026-06-19 加，最高优先级，按 `skills/analysis-depth.md`）——报告的价值在判断、不在事实罗列：** 动笔前先做四步（定一句贯穿全文的核心论点 / 找认知差·市场看错在哪 / 诊断价值困在哪靠什么释放 / 定主变量）把判断脊梁立起来；写正文时**每个承重数字都要解读成"对价值意味着什么"**（不止陈述数字与机制）；财务章必做"视角二·反向"（用数字反推体质与文化）、估值章必做"价值阶梯诊断"。事实深度过 depth-check（第四关）、分析深度过 insight-check（第五关），两关各管一轴。这一条专防"事实很全、却只在组织事实、没形成价值判断"。

## 目录（标准九章；可按公司增删，但深度不能减）

**第一章 公司主营业务概述**
- 执行摘要（一段把"这是门什么生意"讲透）
- 起点与底色 / 它卖什么·卖给谁·解决什么问题 / 各业务板块（每块单独深讲：营收、占比、毛利率、同比、来源、角色）/ 客户结构 / 核心人员（家族/管理层背景，可写人名，重点放在出身、过往战绩与资本配置记录上）/ 小结
- **交互器交付（标准见 `skills/chapter-cards.md`）**：必出「业务质量判断卡」＝`valuation_inputs.json` 的 `ch1` 块（质量光谱 + 五字段 + 业务速览；代码供数、我下判断）。`check_chapters.py` 闸门校验，不填全 `qc_gate` 拦 PDF。

**第二章 发展历程**（上市前 → 最近一季）
- 执行摘要 + **大事记表**（时间/类型/事件）
- 上市前、上市当年、各关键年份逐年讲（业绩、动作、转折）+ 总账表（多年营收/归母/扣非/现金流）
- **交互器交付（标准见 `skills/chapter-cards.md`，标尺＝超卓 688237 深版）**：必出「历程判断卡」＝`ch2` 块（历程脊梁 / 四段时间轴 / 看行为读出的模式 / 会重演的暗线或期权 / 峰值坐标 / 总账速览+双面判读）。承重判断＝**看行为不看口号**：从历史动作读出控股股东/管理层会怎么对待这个平台 + 会重演的暗线。正文必含**大事记表 + 总账表**两张表（闸门硬校验）+ 7 条正文深度线（见 `skills/chapter-cards.md`）。

**第三章 行业与竞争格局**
- 执行摘要
- 横跨哪几个行业（每个的竞争结构 + 公司的位置）/ 核心战场深描 / **各赛道竞争格局（对手是谁·份额·谁强谁弱·这家排第几——"竞争格局"四个字真正要交付的内容）** / **这门生意的"游戏规则"**（推导出 N 条规则，并点明护城河与财务特征是同一套规则的一体两面）/ 这块市场往哪走（判方向、要带趋势数字+有日期催化+出处）/ 小结
  > ⚠️ **三章/四章分界（门道分两种）**：第三章往外看市场和对手（竞争格局/价值链里谁拿走钱/竞争门道），怎么赚钱的钱流机制（进货/触达/变现）与盈利门道（二房东抽成、自营吃掉溢价）归第四章盈利引擎、本章不写。详见 `skills/chapter-cards.md` 第三章标准。
- **交互器交付（标准见 `skills/chapter-cards.md`，标尺＝超卓 688237 深版）**：必出「行业判断卡」＝`ch3` 块（格局脊梁 / 竞争结构地图 / 各业务谁掌握价值 / 核心护城河 / 价值集中vs压力 / 决胜变量；卡精炼、门道留正文）。铁律：**正文先写、卡片后提炼**；游戏规则（内行才懂、外行看不出的门道）按**五步套路**挖、每条带出处（公司披露/外部源/我的推断三层分清）；**平台型公司**的商业模式/门道/市场往哪走**逐块走**；市场往哪走**判方向不判快照**（美光教训）。正文必含 ≥1 张竞争结构表（闸门校验）。写作守纪律：无后台过程话、无引号（除逐字）、不加粗、戒"不是……而是……"。
- **供给侧仪表盘（周期行业必填，2026-06-10 新增）**：周期位置要从**行业供给侧**外看，不能只靠自家报表的 peak_suspect 旗（从里往外看）。填硬指标（借 `skills/industry-chain.md` 第四层）：① 在建/规划产能与投放时间表 ② 全行业 capex 强度与同比 ③ 近 12-24 月行业融资潮（IPO/定增/可转债）④ 竞争者是否同步扩产 ⑤ 当前行业利润率 vs 中周期均值的偏离度。结论落一格：扩张顶部 / 衰退 / 出清底部 / 复苏纪律——喂第八章的周期校准与 Bear 概率。

**第四章 商业模式与盈利引擎**
- 执行摘要
- 商业模式总览 / **每个盈利引擎：上下游·怎么开展·怎么赚钱·盈利角色** / 盈利引擎全景（谁在真正赚钱）/ 为什么有利润没现金（或现金好）/ 成本与采购 / 小结
  > 本章接住第三章移交的每块钱流机制（进货/触达/变现的"怎么赚钱"拆解）与盈利门道（如二房东抽成、自营吃掉溢价）——第三章只到"价值归谁"为止，这里把每块自己怎么赚展开成地基，再叠上盈利引擎全景的屋顶（谁在真正赚钱）。
- **价值判断·第一柱 复利引擎**（引用 `metrics.json` 的 `compounding_engine`）：ROIC 水平与趋势、**增量 ROIC（新资本赚不赚）**、再投资率/跑道、ROE。把 ROIC 接回护城河（高 ROIC 凭什么持续），判断这是复利机器还是融化的冰块；增量 ROIC < 资金成本＝过了黄金期。注意轻资产/ROIC 失真标记。方法见 `skills/value-judgment.md` 第一柱。
- **交互器交付（标准见 `skills/chapter-cards.md`，落地样板＝600327）**：必出「经营判断卡」＝`ch4` 块（经营脊梁 / 三门生意总览[本质·营收占比·赚不赚钱] / 每门怎么玩[游戏规则明暗] / 哪门真赚钱 / 决胜动作）。**口吻＝第三人称分析报告，别写成对 CEO 的汇报体（你接手的是…）。****铁律：第四章是给新 CEO 的经营说明书、不做财务报表分析**——只讲每门生意做什么、怎么运转、游戏规则明暗、怎么玩才能赢、哪门赚钱（定性）；毛利净利/投资收益/总部抽水/利润含金量/现金净债等财务账全归第七章。正文必含 **≥1 张总览表**（闸门校验）。守写作纪律：正面直说、戒否定开头/不是…而是。

**第五章 资本配置**（标尺＝"资本配置系统提示词"+超卓 688237；终极标尺＝每股内在价值有没有被持续创造）
- 执行摘要（先给分级结论）
- 钱从哪来·到哪去（数据脊柱：来源÷去向+历年股数/ROIC，机械完整、数据不足标不可得） / **生意阶段诊断（前置闸门：①复利机器②成熟③恶化，定义这家"好配置"长什么样，脱离阶段谈对错＝无效）** / 配置审讯（并购事后剖检·估值倍数·商誉墓碑·价值创造vs帝国建造 / 回购时机·均价vs内在价值 / **净股数轨迹·不看回购金额** / 分红配不配阶段 / 现金纪律） / **每股记分牌（终判：每股盈利·FCF·内在价值有没有真长）** / **为谁配置（A股控股平台：关联交易·担保·股权质押·抽血）** / 透过记录读管理层（所有者vs机构惯性·激励结构） / 合规与瑕疵 / 小结+**最强反方（先给最善意解释）**+什么会改变判断
- **铁律**：每股口径思考、判决策框架不判单笔结果（防 resulting）、结果是证据不是判据、绝不把"做大"当好事、无证据褒义词不要、脱离阶段不谈对错。
- **交互器交付（标准见 `skills/chapter-cards.md`，落地样板＝600327）**：必出「资本配置记录卡」＝`ch5` 块（脊梁 / 阶段诊断 / 资金来去 / 大决策剖检 / **每股记分牌**[归母·经营现金流代码算、扣非·分红已核年报] / 分红轨迹·激励 / **为谁配置** / 分级结论 / **最强反方**）。**两类标的两重心**：大额募资公司重募投复盘+效率账（能力为主），老牌控股平台重分红+并购绕谁+质押担保（忠诚为主）。正文必含 **≥1 张表**（闸门校验）。守写作纪律：正面直说、戒否定开头/不是…而是、看行为不看口号、可写人名但不贴人格标签。方法见 `skills/value-judgment.md` 第三柱。

**第六章 组织治理与诚信**（承重判断＝能不能信任掌控这家公司的人；标尺＝超卓 688237 治理分析 + 补"管理层背景背调"）
- 执行摘要（先给"能不能信"的分层结论）
- 谁说了算（权力结构：股权 vs 经营权、控制权状态、**内部人持股=利益绑没绑**）/ **关键人背景背调（承重节）** / **控股股东跨主体记录（控股平台专属）** / 诚信记录全链（重大事件·一次性 vs 结构性·A 股退市清单逐项核）/ 关联交易与资金往来 / 信息披露与合规（监管函/处罚/整改）/ 同业竞争与资金占用 / 小结（能不能信+治理折价+胜负手+**最强反方**）
- **管理层背景背调（用户点名、本章承重件）**：逐个背关键人——身份关系 / **履历与战绩**（从哪来、过往创造还是毁灭价值，预测力最强）/ 持股与薪酬（skin in the game+激励对齐）/ 体外布局与利益冲突 / **背景红旗**（违规/诉讼/占用/失信/处罚）。**A 股控股平台最高价值层＝背控股股东本身 + 它在其他主体怎么对待小股东**（分红/占用/担保/处罚记录），比派驻经理的简历更能预测它会怎么对待本公司。
- **取证铁律**：我们是公开信息价值投资报告、不是尽调访谈报告——**只用公开记录**（年报/招股书/公告/公开工商登记企查查类/裁判文书网/失信被执行人/监管处罚/央媒），**摆事实不贴人格标签**（可写人名+履历、不写"贪婪/平庸"），查不到就如实说"未见公开记录"、不替年报背书，媒体来源的推断（如"分红回血"动机）标清是推断、不冒充已证事实；可派独立联网 agent 采集后核对。
  > ⚠️ 别只信年报"同业竞争：不适用"——那是**窄法律口径**（只看实控人"控制"的单位），会漏掉关键个人（二代/技术核心/创始人亲属）以**个人身份**设立或参股的体外公司。对关键内部人要**补查公开工商登记（企查查/启信宝类）**，看有没有与主业相近的体外布局（潜在利益冲突/技术外溢/同业）；查不到就如实说"未见公开记录"，别替年报背书。
- **交互器交付（标准见 `skills/chapter-cards.md`，落地样板＝600327）**：必出「治理判断卡」＝`ch6` 块（脊梁 / 谁说了算 / **关键人背景背调表** / **控股股东跨主体记录** / 诚信记录 / 能不能信+治理折价 / 胜负手 / **最强反方**）。**这一章代码不供数**（无可算结构化数据），背调全由人第一手挖、`build_ch6_card` 透传。正文必含 **≥1 张表**（背调表，闸门校验）。

**第七章 财务全貌**（两视角 + 三层；标尺＝超卓 688237 框架 + **把它做深**——超卓那章用户嫌"不够深"，深在管理心理、浅在财务取证，补量化层）
> **深化＝把我们自己的量化工具搬到超卓的框上**（超卓是尽调叙事、没用这些）：① **正常化盈利**（剥一次性+分部清理+看穿会计估计后正常一年赚多少）② **盈利质量取证**（净利 vs 现金流为什么背离、应计、营运资本——拆到机制和数字）③ **会计可信度全扫**（量化每个会计杠杆对利润的影响）④ **价值阶梯诊断在本章做**（资产地板/按盈利能力折出的价值/分部加总/成长 + 价值困在哪靠什么释放，**用户拍板从第八章移来**，是把第七章做深的核心）。EPV 一律白话成"按盈利能力折出的价值"、不用 `>=<` 符号。
- 执行摘要
- **视角一·正向**：三张表 + 分部（逐块）+ **会计可信度扫描**（主动找抬高账面利润的会计估计变更：折旧/摊销年限延长、减值计提是否充分、收入确认口径、研发资本化；A 股尤其要扫）+ 管理层怎么解释（**既看他们强调什么，也看他们系统性淡化 / 回避了什么**——回避的往往是资金效率、亏损子公司、应收占款这类结构性问题）
  > ⚠️ 扫会计估计变更**必须跨年 diff 折旧/摊销年限、残值率表本身**，绝不能只信最新一年附注的"本年会计估计变更：不适用"——延长往往发生在前某一年（如房屋折旧 20-25→20-40），从那年起利润被**永久**垫高，但之后每年附注都写"本年不适用"，只读最新年会漏判成"账很干净"。一定回看上市以来各年的折旧表逐行比，并查董事会议案/专项公告。
- **视角二·反向**：只看数据反推这是家什么状态的公司、它怎么管理、反映什么文化（数据 → 管理层视角 → 管理与文化 三层）
- **价值判断·第二柱 所有者盈余**（引用 `metrics.json` 的 `owner_earnings`）：报告 FCF vs **SBC 调整后 FCF**（SBC 占 FCF 高就用调整口径）、正常化所有者盈余、维护性 capex 拆分；分清"GAAP 亏但现金为正"（会计假象）与"真烧钱"。
- **价值判断·第四柱 生存测试**（引用 `metrics.json` 的 `survival`）：净债/EBITDA、利息覆盖、流动比、一年内到期墙 vs 现金；烧钱公司看**现金跑道**（净现金≠安全）；有净债+亏损＝最脆弱。方法见 `skills/value-judgment.md` 第二、四柱。
- **价值阶梯诊断（在本章做、第八章用作输入）**：资产地板/按盈利能力折出的价值/分部加总/成长四层依次摆出，下两个诊断——① **按盈利折出的价值 < 资产值 ＝ 公司没在创造价值、资本被低效占用**（价值靠资本配置释放、非业务变好）；**分部加总 >> 现状市值 ＝ 价值被结构困住**，点出什么动作释放；② **经营性资本回报 vs 合并净资产收益率背离**，把"生意本身好不好"与"合并层配置好不好"分开。这两个诊断直接决定第八章用资产法还是现金流折现。
- 两视角对照 + 对外部投资者的含义 + **小结交底第八章**（正常化盈利 + 价值阶梯 + 安全度三条硬结论）
- **交互器交付（标准见 `skills/chapter-cards.md`，落地样板＝600327）**：必出「财务判断卡」＝`ch7` 块（脊梁 / 利润表透视[营收/归母/营业利润/投资收益/资本回报率**代码算**、扣非手抄] / 谁真赚钱 / 盈利质量+会计可信度 / **价值阶梯** / 反向画像 / 生存 / 交底第八章）。**这章代码供数最多**（四柱硬数字在顶部仪表盘）。正文必含 **≥1 张表**。

**第八章 投资分析与估值**（替代原 memo；标尺＝超卓 688237、基本吸收。承重判断＝两个问题分开：作为生意值多少 / 作为这个价格的股票对不对称）
- 执行摘要（作为生意值多少 / 作为这个价格的股票是否对称）
- 方法说明 / **作为生意值多少（精简引第七章价值阶梯结论、不重新推导）** / **三情景（故事 + 对应价值 + 可能性·定性文字 + 关键前提，要有三情景表）** / **市场买入了什么故事（反向 DCF）** / 安全边际（现价 vs 保守端·区间口径）/ **不对称性（下行托底 vs 上行催化）** / 关键价值变量（催化剂清单）/ 小结（生意 vs 价格分开答、不给单一目标价、合理与否在价格）
- **区间口径铁律（用户 2026-06-30 点名，覆盖原概率加权）**：戒给情景拍概率、戒算加权中枢、戒算隐含年化（"精准的错误"）。三情景就是价值区间、可能性用文字说、**安全边际＝现价离保守端多远**（现价 vs 保守价值，不是 vs 加权中枢）。详见 `skills/chapter-cards.md` 第八章「区间口径铁律」。引擎/odds/梯队榜重构待办。
- **每股价值 vs 市值（换股平台情景适用时）**：做大市值≠每股价值提升；用相对内在价值偏高估的股票去收购公允定价的资产，反而可能增厚每股价值——对换股扩张型标的必判（看每股价值口径、不只看市值）。
- **资产型标的拆地板成色（2026-06-30 加）**：账面 NAV 不是干净地板时（如大东方 28 亿净资产近六成是失血参股+波动金融投资+减值商誉），把地板分硬（经营资产+净现金）软（投资类、要打折），下行情景显式让软资产缩水——真硬地板可能远低于账面，安全边际判断要据此打折，别把账面市净率1.0当成扎实托底。
- **交互器交付（标准见 `skills/chapter-cards.md`，落地样板＝600327）**：必出「投资决策卡」＝`ch8` 块（脊梁 / 作为生意值多少 / 安全边际+市场买了什么 / 不对称性 / 催化剂 / 决策）——整份报告的收口 capstone，和顶部「生意质量四柱仪表盘」互补（一个判生意、一个判价格）。**卡刻意不重复三情景表**（交互器顶部仪表盘+三情景滑块+市场vs我已有活数字），只做判断综合。正文必含 **≥1 张三情景表**（闸门校验）。
- **价值阶梯诊断（2026-06-30 起移到第七章做、第八章用作输入）**：资产地板/按盈利折出的价值/分部加总/成长四层 + "价值困在哪靠什么释放" + 经营性资本回报 vs 合并净资产收益率背离——这套诊断现在在**第七章财务全貌**里做（它是财务全貌的结论），第八章直接拿第七章的正常化盈利 + 资产值当输入，决定用资产法还是现金流折现、并据此搭三情景。方法见 `skills/analysis-depth.md`。
- **认知差必写（variant perception）**：反向 DCF 之外，明说一处"市场以为 X、实际是 Y、这个差就是价值/风险"；哪怕结论是"市场大体定价对"，也要说清市场在为什么故事付钱。这是"寻找价值"的核心动作。
- **三情景的三道新关（2026-06-10 新增，写情景时同步过）**：① **base rate 先行**——给概率前先报 `reviews/BASE_RATES.md` 同类事件历史频率、再论证这家为什么偏离（成熟期 FCF 利润率同样要给同业历史最佳值参照，超过须单独论证）；② **对手桌检查**——Bull/Base 写完过一遍竞争对手/最大客户/供应商渠道/监管者的最优反应，反应之后故事还成立才算成立；③ **单位经济**——凡有披露，Bull 必须量×价×单位成本算得通，讲不出单位经济的 Bull 概率降档。详见 `skills/valuation.md`。
- **安全边际＝区间口径（2026-06-30 起，替代原"双口径/期望口径/概率加权中枢"）**：只看一个口径——**现价离保守端（区间下沿/硬地板）多远**＝最坏看错亏多少（安全边际本义）。三情景给区间、可能性用文字说，不算加权中枢、不算 expected_irr。原"期望口径（odds+概率加权中枢）"作废、待引擎重构移除。
- **事前验尸（pre-mortem，小节，放催化剂清单后）**：两段——假设 5 年后回看，这个判断**往上错**（错过大牛股）的最可能剧情是什么；**往下错**（亏了大钱）的最可能剧情是什么。写不出具体剧情＝情景想象宽度不够，回去补情景。两段同步存进 `decision.json` 的 `premortem`，复盘时当对照样本。
- **核心 driver 拆解与四维分类**（小节，放在三情景前）：把利润拆成机械 driver（量×价−截流 / 分部加总），每个 driver 按四维分类（可控/外生、结构/周期、持久/脆弱、是否已被定价）+ 用什么动作验证 + 投资含义，做成一张表喂三情景——driver 的类型决定该用哪条 Track、给多大折现率、把哪个写成核心 Bear。方法见 `skills/value-judgment.md` 横切·核心 driver 节；每个 driver 同步进 `decision.json` 的 `drivers` 字段供复盘对账。
- **四柱 → 安全边际（头条综合）**：把前四章的四柱判断（生意好不好＝复利引擎+所有者盈余、管理层行不行＝资本配置、扛不扛得住＝生存）与价格合起来，得出头条——**安全边际＝保守内在价值 − 价格，强调"我能看错多少还不亏本金"，不是精确 DCF 点**。好生意可以是烂股票（买太贵），脆弱生意再便宜也是陷阱。方法见 `skills/value-judgment.md` 综合节。
- **周期校准**（适用时）：若 `metrics.json` 的 `cycle_calibration.peak_suspect` 被标旗（当前 ROIC/利润率是周期高峰），**必须做中周期归一化**——别用高峰利润率喂终值，并把"周期转冷/资本开支见顶"写成核心 Bear。详见 `skills/value-judgment.md` 横切·周期校准节。
- **预测窗口口径（默认）**：头条用 **5 年显性**（更在能力圈内、可证伪性强），并并列一个**延伸至 10 年的参考值**；正文点出两者差距的含义（差距小＝价值扎实、不靠远期；差距大＝乐观押在最难看清的第 6–10 年，是 Bull 最易藏泡沫处）。注意窗口越短终值占比越高（5 年常 ~85%），纪律来自把第 5 年后的稳态显性写出、而非塞进终值。详见 `skills/valuation.md` 第三补条。
- **近期动作雷达**（小节，适用时）：扫最近 6–12 个月的 PR / 公告 / 发布会 / 指引，按 `skills/valuation.md` 第九条四问法逐条过，固化成一张表——**事件（剥掉口号的动作）→ 收入机制+时点 → 落 5 年还是 6–10 年 → 影响哪个情景 → 是否已被定价 → 可盯里程碑**。诚实优先：已被定价 / 属远期就如实写，不为故事性感硬造上行。其中的里程碑同步进 `decision.json` 催化剂清单。
