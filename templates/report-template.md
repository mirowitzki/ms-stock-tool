# 完整报告模板（机构级 · 唯一交付物）

> 这是 `<TICKER>_公司完整报告.md` 的**章节骨架与深度标准**。对标专业尽调报告。
>
> **写作铁律（防止把报告写水）：**
> 1. **每章先一段「执行摘要」、再「正文详情」**（多个二级/三级小节）。
> 2. **穷尽、深挖**：每个业务线、每笔资本运作、每项治理与风险，都要给**具体数字、具体公告/事件、具体证据**——不能只给一句话结论。
> 3. **追求完整度、不限页数**。该多长就多长。绝不写成"放大版摘要"。
> 4. **深读全部年报 + 高信号公告**再动笔；先读 `reviews/LESSONS.md`。
> 5. 守反成见铁律（红旗先写善意解释）、生意与价格分开、剥离一次性、看归母、真实流动性合并算。报告里可以出现人名（实控人/董监高/关键交易对手等，用户 2026-05-31 改），但仍不给管理层贴人格标签。
> 6. **分析深度（2026-06-19 加，最高优先级，按 `skills/analysis-depth.md`）——报告的价值在判断、不在事实罗列：** 动笔前先做四步（定一句贯穿全文的核心论点 / 找认知差·市场看错在哪 / 诊断价值困在哪靠什么释放 / 定主变量）把判断脊梁立起来；写正文时**每个承重数字都要解读成"对价值意味着什么"**（不止陈述数字与机制）；财务章必做"视角二·反向"（用数字反推体质与文化）、估值章必做"价值阶梯诊断"。事实深度过 depth-check（第四关）、分析深度过 insight-check（第五关），两关各管一轴。这一条专防"事实很全、却只在组织事实、没形成价值判断"。

## 目录（标准九章；可按公司增删，但深度不能减）

**第一章 公司主营业务概述**
- 执行摘要（一段把"这是门什么生意"讲透）
- 起点与底色 / 它卖什么·卖给谁·解决什么问题 / 各业务板块（每块单独深讲：营收、占比、毛利率、同比、来源、角色）/ 客户结构 / 核心人员（家族/管理层背景，可写人名，重点放在出身、过往战绩与资本配置记录上）/ 小结

**第二章 发展历程**（上市前 → 最近一季）
- 执行摘要 + **大事记表**（时间/类型/事件）
- 上市前、上市当年、各关键年份逐年讲（业绩、动作、转折）+ 总账表（多年营收/归母/扣非/现金流）

**第三章 行业与竞争格局**
- 执行摘要
- 横跨哪几个行业（每个的竞争结构 + 公司的位置）/ 核心战场深描 / **这门生意的"游戏规则"**（推导出 N 条规则，并点明护城河与财务特征是同一套规则的一体两面）/ 各赛道竞争 / 小结
- **供给侧仪表盘（周期行业必填，2026-06-10 新增）**：周期位置要从**行业供给侧**外看，不能只靠自家报表的 peak_suspect 旗（从里往外看）。填硬指标（借 `skills/industry-chain.md` 第四层）：① 在建/规划产能与投放时间表 ② 全行业 capex 强度与同比 ③ 近 12-24 月行业融资潮（IPO/定增/可转债）④ 竞争者是否同步扩产 ⑤ 当前行业利润率 vs 中周期均值的偏离度。结论落一格：扩张顶部 / 衰退 / 出清底部 / 复苏纪律——喂第八章的周期校准与 Bear 概率。

**第四章 商业模式与盈利引擎**
- 执行摘要
- 商业模式总览 / **每个盈利引擎：上下游·怎么开展·怎么赚钱·盈利角色** / 盈利引擎全景（谁在真正赚钱）/ 为什么有利润没现金（或现金好）/ 成本与采购 / 小结
- **价值判断·第一柱 复利引擎**（引用 `metrics.json` 的 `compounding_engine`）：ROIC 水平与趋势、**增量 ROIC（新资本赚不赚）**、再投资率/跑道、ROE。把 ROIC 接回护城河（高 ROIC 凭什么持续），判断这是复利机器还是融化的冰块；增量 ROIC < 资金成本＝过了黄金期。注意轻资产/ROIC 失真标记。方法见 `skills/value-judgment.md` 第一柱。

**第五章 资本配置**（募资去向 / 收购 / 分红 / 再融资）
- 执行摘要
- 募了多少·原计划花多少 / 募投项目逐个复盘 / 超募与闲置资金去向 / **每笔收购的成色（对价·商誉·业绩兑现）** / 资金效率账 / 合规与瑕疵 / 小结
- **价值判断·第三柱 资本配置记录卡**（引用 `metrics.json` 的 `capital_allocation`）：近 5 年每块经营现金流的去向（再投/回购/分红/并购/还债占 CFO 比），**回购要交叉核对当年股价（便宜时回购增厚、高位接盘毁价值）**，并购看商誉堆积与减值；外加**管理层激励结构**（薪酬挂每股价值/ROIC 还是营收/规模、内部人持股——联网/委托书）。看行为不看口号，可写人名但不贴人格标签。方法见 `skills/value-judgment.md` 第三柱。

**第六章 组织治理与诚信**
- 执行摘要
- 股权与权力结构 / 控制权与关键人 / 管理层变动 / 技术/核心团队 / **重大治理事件全貌** / 关联交易 / 信息披露与合规（监管函/处罚/整改）/ 同业竞争与资金占用 / 小结
  > ⚠️ 别只信年报"同业竞争：不适用"——那是**窄法律口径**（只看实控人"控制"的单位），会漏掉关键个人（二代/技术核心/创始人亲属）以**个人身份**设立或参股的体外公司。对关键内部人要**补查公开工商登记（企查查/启信宝类）**，看有没有与主业相近的体外布局（潜在利益冲突/技术外溢/同业）；查不到就如实说"未见公开记录"，别替年报背书。

**第七章 财务全貌**（两视角 + 三层）
- 执行摘要
- **视角一·正向**：三张表 + 分部（逐块）+ **会计可信度扫描**（主动找抬高账面利润的会计估计变更：折旧/摊销年限延长、减值计提是否充分、收入确认口径、研发资本化；A 股尤其要扫）+ 管理层怎么解释（**既看他们强调什么，也看他们系统性淡化 / 回避了什么**——回避的往往是资金效率、亏损子公司、应收占款这类结构性问题）
  > ⚠️ 扫会计估计变更**必须跨年 diff 折旧/摊销年限、残值率表本身**，绝不能只信最新一年附注的"本年会计估计变更：不适用"——延长往往发生在前某一年（如房屋折旧 20-25→20-40），从那年起利润被**永久**垫高，但之后每年附注都写"本年不适用"，只读最新年会漏判成"账很干净"。一定回看上市以来各年的折旧表逐行比，并查董事会议案/专项公告。
- **视角二·反向**：只看数据反推这是家什么状态的公司、它怎么管理、反映什么文化（数据 → 管理层视角 → 管理与文化 三层）
- **价值判断·第二柱 所有者盈余**（引用 `metrics.json` 的 `owner_earnings`）：报告 FCF vs **SBC 调整后 FCF**（SBC 占 FCF 高就用调整口径）、正常化所有者盈余、维护性 capex 拆分；分清"GAAP 亏但现金为正"（会计假象）与"真烧钱"。
- **价值判断·第四柱 生存测试**（引用 `metrics.json` 的 `survival`）：净债/EBITDA、利息覆盖、流动比、一年内到期墙 vs 现金；烧钱公司看**现金跑道**（净现金≠安全）；有净债+亏损＝最脆弱。方法见 `skills/value-judgment.md` 第二、四柱。
- 两视角对照 + 对外部投资者的含义

**第八章 投资分析与估值**（替代原 memo）
- 执行摘要（作为生意值多少 / 作为这个价格的股票是否对称）
- 方法说明 / 多层绝对估值（资产地板·EPV·分部加总，适用时）/ 所有者收益 / **三情景（故事 + 管理层应对 + 毛估价值区间）** / **反向 DCF：市场买入了什么故事** / 安全边际·概率加权·隐含预期 / 关键价值变量（催化剂清单）/ 小结（生意 vs 价格分开答、不给单一目标价）
- **价值阶梯诊断（2026-06-19 加，按 analysis-depth）**：把资产价值（地板）/ EPV（正常化所有者盈余÷要求回报率、零增长）/ 分部加总（结构修复后）/ 成长 四层依次摆出，并下两个诊断——① **EPV < 资产价值 ＝ 公司没在创造价值、资本被低效占用**（价值靠资本配置释放、非业务变好）；**分部加总 >> 现状市值 ＝ 价值被结构困住**，点出什么动作释放；② 用"**经营性资本回报率（剔除过剩现金后业务自身的回报）vs 合并 ROE 的背离**"把"生意本身好不好"与"合并层资本配置好不好"分开。这是回答"价值困在哪、靠什么释放"的核心，别只回答"贵不贵"。
- **认知差必写（variant perception）**：反向 DCF 之外，明说一处"市场以为 X、实际是 Y、这个差就是价值/风险"；哪怕结论是"市场大体定价对"，也要说清市场在为什么故事付钱。这是"寻找价值"的核心动作。
- **三情景的三道新关（2026-06-10 新增，写情景时同步过）**：① **base rate 先行**——给概率前先报 `reviews/BASE_RATES.md` 同类事件历史频率、再论证这家为什么偏离（成熟期 FCF 利润率同样要给同业历史最佳值参照，超过须单独论证）；② **对手桌检查**——Bull/Base 写完过一遍竞争对手/最大客户/供应商渠道/监管者的最优反应，反应之后故事还成立才算成立；③ **单位经济**——凡有披露，Bull 必须量×价×单位成本算得通，讲不出单位经济的 Bull 概率降档。详见 `skills/valuation.md`。
- **安全边际双口径（2026-06-10 起）**：头条并列①保守口径（现价 vs 中性情景下沿——最坏看错亏多少）②期望口径（odds 不对称度 + expected_irr_5y，代码机械推导）；概率加权中枢明确标注是期望值、不是目标价。
- **事前验尸（pre-mortem，小节，放催化剂清单后）**：两段——假设 5 年后回看，这个判断**往上错**（错过大牛股）的最可能剧情是什么；**往下错**（亏了大钱）的最可能剧情是什么。写不出具体剧情＝情景想象宽度不够，回去补情景。两段同步存进 `decision.json` 的 `premortem`，复盘时当对照样本。
- **核心 driver 拆解与四维分类**（小节，放在三情景前）：把利润拆成机械 driver（量×价−截流 / 分部加总），每个 driver 按四维分类（可控/外生、结构/周期、持久/脆弱、是否已被定价）+ 用什么动作验证 + 投资含义，做成一张表喂三情景——driver 的类型决定该用哪条 Track、给多大折现率、把哪个写成核心 Bear。方法见 `skills/value-judgment.md` 横切·核心 driver 节；每个 driver 同步进 `decision.json` 的 `drivers` 字段供复盘对账。
- **四柱 → 安全边际（头条综合）**：把前四章的四柱判断（生意好不好＝复利引擎+所有者盈余、管理层行不行＝资本配置、扛不扛得住＝生存）与价格合起来，得出头条——**安全边际＝保守内在价值 − 价格，强调"我能看错多少还不亏本金"，不是精确 DCF 点**。好生意可以是烂股票（买太贵），脆弱生意再便宜也是陷阱。方法见 `skills/value-judgment.md` 综合节。
- **周期校准**（适用时）：若 `metrics.json` 的 `cycle_calibration.peak_suspect` 被标旗（当前 ROIC/利润率是周期高峰），**必须做中周期归一化**——别用高峰利润率喂终值，并把"周期转冷/资本开支见顶"写成核心 Bear。详见 `skills/value-judgment.md` 横切·周期校准节。
- **预测窗口口径（默认）**：头条用 **5 年显性**（更在能力圈内、可证伪性强），并并列一个**延伸至 10 年的参考值**；正文点出两者差距的含义（差距小＝价值扎实、不靠远期；差距大＝乐观押在最难看清的第 6–10 年，是 Bull 最易藏泡沫处）。注意窗口越短终值占比越高（5 年常 ~85%），纪律来自把第 5 年后的稳态显性写出、而非塞进终值。详见 `skills/valuation.md` 第三补条。
- **近期动作雷达**（小节，适用时）：扫最近 6–12 个月的 PR / 公告 / 发布会 / 指引，按 `skills/valuation.md` 第九条四问法逐条过，固化成一张表——**事件（剥掉口号的动作）→ 收入机制+时点 → 落 5 年还是 6–10 年 → 影响哪个情景 → 是否已被定价 → 可盯里程碑**。诚实优先：已被定价 / 属远期就如实写，不为故事性感硬造上行。其中的里程碑同步进 `decision.json` 催化剂清单。

**第九章 风险全景**
- 执行摘要
- 按类别逐条（治理 / 经营 / 财务 / 估值市场 / 交易 / 行业宏观），每条给"风险 + 缓释"
- **风险矩阵表**（概率 × 影响 → 综合等级 + 主要缓释）
- 小结（核心风险 + 缓释逻辑 + 监控清单）
