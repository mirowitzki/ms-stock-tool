这是整套方法论的总纲——把散落在各处的东西串成一条主线。读这一份，就能
知道"我是怎么分析一家公司的、靠什么纪律不犯傻"。数据时点会变，方法不变。
先读这份，再读教训库（踩过的坑），再动手。

2026-06-10 方法论升级（四批，已全部落地——详见 md 版对应章节）
──────────────────────────────────────────────────────────────────────

升级主线：以前的体系强在"防错"（防幻觉、防成见、代码算数），这次补的是
"可校准"——给概率找外部锚、让结论挨打、让每个预测留下可记分的痕迹。

一、复盘可记分（skills/postmortem.md 大改版 + reviews/CALIBRATION.md 台账）
  · 每家 decision.json 把预测钉成可判对错的四元组：指标＋阈值＋期限＋查证处；
    另加 review_by（最迟复盘日）、entry_watch（数字化入场观察区）、原型标签、
    odds 与 5 年隐含年化（代码算）、事前验尸两段。11 家已全部补齐
    （NVDA、RKLB 两份缺失的决策记录已补建）。
  · 复盘三类触发：新数据 / 到期 / 价格进入观察区（review.py 已支持）。
  · 复盘流程：先盲评（独立 agent 只看新数据、不看旧结论）再对照；按 driver
    记分、不按股价；错误分五类归因（数据错/生意理解错/概率错/意外/纪律违反）；
    防 resulting（单次坏结果不证明决策错、靠运气对的也不算对）。
  · 季度做机器级复盘：概率桶校准（说 45% 时到底是不是 45%）、判断方向命中
    分布（这台机器是纪律还是系统性偏空）、误差类别分布。

二、判断装外部锚（reviews/BASE_RATES.md + reviews/ARCHETYPES.md）
  · base rate 先行：给情景概率、定成熟期利润率之前，先报同类事件的历史频率，
    再论证这家为什么偏离；成熟利润率超同业历史最佳值必须单独论证。
  · 原型判例库：分析新公司第一步判原型（题材壳/控股折价/高杠杆题材/利差生意/
    待决并购/贵的好生意/烧钱期权……共 12 型），调同型判例与教训并排对照。
  · 事前验尸：估值定稿前写两段——这个判断往上错（错过）和往下错（亏钱）的
    最可能剧情；写不出剧情＝情景宽度不够。

三、让结论挨打（skills/red-team.md，第四道质检）
  · 触发：用户要行动 / 价格进观察区 / 首次结论为偏低有边际。
  · 独立 agent 唯一任务＝论证结论是错的（偏空给最强多头案、偏多给最强空头案、
    攻击概率分布与情景宽度）；主 Claude 逐条回应，驳回必须给证据级理由。

四、分析加强四件 + 代码修复
  · 对手桌检查：Bull/Base 写完过一遍对手/大客户/供应商/监管者的最优反应。
  · 单位经济硬要求：Bull 必须量×价×单位成本算得通，否则概率降档。
  · 周期供给侧外查：周期行业必填行业级供给仪表盘（在建产能/全行业资本开支/
    融资潮），周期位置从外面看、不只看自家高峰旗。
  · 安全边际双口径：保守口径（现价 vs 中性下沿）与期望口径（赔率＋隐含年化）
    并列；概率加权中枢是期望值、不是目标价。
  · 证据分级与三角验证：承重判断要有交易对手方/监管级印证，公司自述只算一票。
  · 净负债计算 bug 已修（曾漏算短期借款、咬过 300199/000925）：负债科目改为
    求和、新增覆盖缺口清单与盈利质量取证模块（应计占比/应收剪刀差），并立了
    金标准回归测试（scripts/test_metrics.py），全部 11 家已重算重渲。


──────────────────────────────────────────────────────────────────────
〇、一句话概括这套方法
──────────────────────────────────────────────────────────────────────

人主导、工具辅助；代码算数、人下判断；先看懂生意，再分开回答"生意值多少"
和"这个价格买不买"；给区间和概率、不给单一目标价；用独立的对抗性检查防
自己的幻觉和成见；每分析一家就往教训库里沉淀一条，越学越智慧。

它不是一台"算出目标价"的机器，而是一张【判断卡】：帮你把一家公司看透、
把价值和价格的关系说清、把自己最容易犯的错堵住。


──────────────────────────────────────────────────────────────────────
一、五条底层信念（不要挑战，这是地基）
──────────────────────────────────────────────────────────────────────

1. 人主导，工具辅助。工具替你读资料、算数字、按框架梳理；最终判断是人的事。

2. 代码算数，Claude 判断。抓数据、解析、算 DCF/四柱/估值——全部交代码，
   免费且精确，绝不用大模型做算术。理解生意、判断护城河、评估管理层、写
   报告——这是判断密集、价值最高的部分，交人。

3. 看不懂就不估值。讲不出一个可信的生意故事，就在估值章里如实说"看不清/
   太难"，而不是硬估一个数。

4. 生意 vs 价格，永远分开答。好生意可以是烂股票（买太贵），脆弱生意再便宜
   也可能是陷阱。把两者糊成一句话，是最常见的错。

5. 模糊的正确 > 精准的错误。给毛估区间 + 方向 + 主观概率，锚在治理和情景
   故事上；别追一个看似精确、实则虚假的单一目标价。


──────────────────────────────────────────────────────────────────────
二、完整流水线（按顺序）
──────────────────────────────────────────────────────────────────────

   取数（纯代码） → 深读 → 写一份完整报告 → 过质检关 → 出交付物 → 复盘沉淀

最终交付物只有两个：一份机构级完整报告（PDF）+ 一个估值交互器。
外加后台不显示的 decision.json（决策记录，供复盘）。

  步骤 0  取数：招股书 + 近 5 年年报 + 高信号公告 + 财务/分部/季报 +
                近 5 年月度股价。（A股/美股各有取数脚本 + 股价脚本）
  步骤 1  算硬数字：四柱真相源（ROIC/FCF/资本配置/生存）→ metrics.json
  步骤 2  深读：招股书 + 近 5 年年报 + 高信号公告（问询函/控制权/重组等）
                + 联网补组织/管理/文化
  步骤 3  写报告：九章机构级、展示别断言、四柱嵌入、含估值章
  步骤 4  质检关：代码对账 + 防幻觉 agent + 防成见 agent，红牌清零才放行
  步骤 5  出交付：PDF + 交互器 + decision.json + 刷新仪表盘
  步骤 6  复盘：出新数据/定期对照论点、提炼 1 条可推广教训进教训库

数据规模铁律：上市 ≤5 年 → 招股书 + 全部年报；上市 >5 年 → 招股书 +
只读近 5 年。别想读 20 年资料、会消化不过来；聚焦深挖、别贪多。

取数前必做：先读教训库（机构记忆），把过去踩过的坑用上——光记不回喂，
就只是日记。


──────────────────────────────────────────────────────────────────────
三、理解生意（估值之前的闸门）
──────────────────────────────────────────────────────────────────────

· 它卖什么、卖给谁、解决什么问题。逐个业务板块讲透：营收、占比、毛利率、
  同比、来源、谁在做（哪个子公司、持股多少）、谁是利润中心、谁在萎缩。

· 横跨哪几个行业、在每个里的位置。公司是规则制定者还是规则接受者？规则
  接受者很难有持续的经营性超额利润。

· 推导这门生意的"游戏规则"。护城河和财务特征是同一套规则的一体两面
  （高 ROIC 凭什么持续）。

· 看行为、不看口号。判断管理层与文化，优先看资本配置历史等"行动"，其次
  才是"言辞"。桌面下的规则不在年报里——组织、管理、文化、真实获客逻辑，
  要靠委托书、致股东信、电话会、联网检索补全。

· 近期动作雷达：扫最近 6–12 个月 PR/公告/发布会，用四问法（剥口号取动作 /
  收入机制+时点 / 落 5 年还是 6-10 年 / 反向 DCF 是否已被定价）反推故事和
  催化剂，但不让 PR 定价。


──────────────────────────────────────────────────────────────────────
四、价值判断·四柱（生意好不好、扛不扛得住）
──────────────────────────────────────────────────────────────────────

硬数字从 metrics.json 取（代码算），判断由人结合定性证据下、但必须引用
这些数字。

第一柱 复利引擎：ROIC 水平与趋势、增量 ROIC（新投的钱赚不赚）、再投资率/
  跑道、ROE。把 ROIC 接回护城河——这是复利机器，还是融化的冰？增量 ROIC
  < 资金成本＝过了黄金期。注意轻资产/ROIC 失真旗。

第二柱 所有者盈余：报告 FCF vs 扣 SBC 后 FCF、正常化所有者盈余、维护性
  capex。分清"GAAP 亏但现金为正"（会计假象）和"真烧钱"——看经营现金流
  符号：为正、亏损主因是非现金 SBC/减值＝会计假象；为负＝实打实失血。

第三柱 资本配置：近 5 年每块经营现金流的去向（再投/回购/分红/并购/还债占
  比）。回购要交叉核当年股价（便宜时回购增厚、高位接盘毁价值）；并购看商誉
  堆积与减值；外加管理层激励结构（薪酬挂每股价值/ROIC 还是营收/规模、内部
  人持股）。

第四柱 生存：净债/EBITDA、利息覆盖、流动比、一年内到期墙 vs 现金。烧钱
  公司看现金跑道（净现金≠安全）；有净债 + 亏损＝最脆弱。别把"堡垒"用过头
  ——净现金里要扣全部有息负债（含短期借款），算严口径。

横切·周期校准：当前处在周期高峰时，必须做中周期归一化——别用高峰利润率喂
  终值，把"周期转冷"写成核心 Bear；处在低谷时也别用低谷利润线性外推（会
  低估）。这是对"AI 大周期不想想红利吗"的回答：用归一化防在高峰付全款、也
  防在低谷错杀。

横切·核心 driver 四维分类（放三情景前，做成一张表）：把利润拆成机械 driver
  （量×价−截流 / 分部加总），每个 driver 按四维分类——可控/外生、结构/周
  期、持久/脆弱、是否已被定价——再用公司真实动作验证。driver 的类型决定该
  走哪条 Track、给多大折现率、把哪个写成核心 Bear。


──────────────────────────────────────────────────────────────────────
五、估值（分流 + 纪律）
──────────────────────────────────────────────────────────────────────

【Track 分流（先判定，写在估值章开头）】

  Track A：成熟稳定 + 正所有者盈余 → 现金流折现（DCF）为主。
  Track B：未盈利 / 转型中 / 二元化 → 反向 DCF + 三情景，用未来稀释股数
           （计入 SBC/增发/可转债）。
  Track C：现金流持续为负 / 资产重 / 低 ROE / 价值在表外资产或特殊事件 →
           DCF 无效，改用 资产地板 + EPV + 分部加总(SOTP) + 特殊事件情景。

【通用纪律】

· 不给单一目标价。永远给区间 + 主观概率分布（熊/中/牛）。每个情景＝故事 +
  管理层应对 + 毛估价值区间。

· 三情景必须 steelman 多头。现价高于所有情景上限时，先把"市场到底看见了
  什么"补成一个完整的牛市情景（资产注入/平台化/重估），给低概率，别停在
  "任何情景都撑不起这个价"——那通常是没找全多头论点的信号。

· 反向 DCF：市场买入了什么故事。倒过来解：现价隐含多高的增速/利润率/成功
  概率？和最乐观情景比，是不是已经把完美执行提前买空。verdict 五档颜色：
  投机泡沫(红) / 偏贵(橙) / 公允偏多头(黄) / 公允(绿) / 低估(绿)。

· 预测窗口：头条用 5 年显性 + 并列一个"延伸至 10 年"的参考值。两者差距本身
  是信号——差距小＝价值扎实不靠远期；差距大＝乐观押在最难看清的第 6-10 年，
  是 Bull 最易藏泡沫处。窗口越短终值占比越高（5 年常约 85%），纪律来自把
  第 5 年后的稳态显性写出、而非塞进终值。

· 四柱 → 安全边际（头条）：把四柱判断（生意好不好＝复利引擎+所有者盈余、
  管理层行不行＝资本配置、扛不扛得住＝生存）与价格合起来。安全边际＝保守
  内在价值 − 价格，强调"我能看错多少还不亏本金"，不是精确 DCF 点。

【控股集团 / SOTP 的三个必做对（踩过坑）】

· SOTP 要按"结构修复 + 正常化"口径，别锚在低谷/当期薄利：周期低谷的块先把
  收入正常化到中周期再给倍数；稳定盈利的子公司按盈利能力给正常倍数（只给
  3-5 倍 PE 几乎一定偏低）；稀缺/独家资质块给较高倍数。自检：认定有真护城
  河、却算出 SOTP ≤ 资产地板 → 多半锚错了低谷数或给低了倍数，回头修。

· 控股集团（母公司并表了上市子公司）的净负债口径：只扣母公司层面的外部净
  负债，绝不扣合并净负债——子公司的债已反映在它自己的市值里，再扣一遍＝同
  一笔债算两次、NAV 严重偏低。母公司常是"融资管道"（借外债再转贷给子公司），
  对子公司放款会和外部债大致对冲。

· 资产型(NAV/SOTP) vs 盈利型(DCF) 对控股集团会系统性背离：DCF（盈利）落在
  约等于现价处、NAV（资产）更高，两者的差就是控股折价本身。主估值用 NAV/
  SOTP；交互器 DCF 当盈利口径交叉验证；别硬把 DCF 调成 NAV。


──────────────────────────────────────────────────────────────────────
六、A 股专属维度（必加）
──────────────────────────────────────────────────────────────────────

· 扣非净利 >> 报告净利：A 股估值一律用扣非，不用报告净利。归母靠一次性坏账
  转回/政府补助/公允价值变动美化时，扣非才见主业真相。

· 股东性质 + 政策风险：实控人是谁、国资/民营、政策敞口。无控股股东/无实际
  控制人的公司，把"谁来入主"当成估值的核心变量、不是花边——价值释放的钥匙
  几乎一定是控制权落定（国资入主/老股东回归/引战投）这个外部事件，而非业务
  变好；情景和催化剂都要绕着它写。但要警惕：这个事件可能很多年不发生（价值
  陷阱）。

· 会计可信度判断：主动找抬高账面利润的会计估计变更——折旧/摊销年限延长必须
  跨年对比表本身（别只信最新一年附注的"本年不适用"，延长发生在前某年、利润
  已被永久垫高）；减值是否足额；收入确认口径；研发资本化率。既看管理层强调
  什么、也看系统性淡化/回避什么（资金效率、亏损子公司、应收占款、高杠杆）。

· ST/退市预警清单（任一出现必须显眼标注）：审计含"持续经营存在疑虑"；证监
  局警示函/监管函；扣非连续 3 年负；应收账款 + 存货占流动资产 ≥ 70%；银行
  存款被划转、关联方异常交易、募集资金违规。注意创业板财务类退市的组合条件
  （扣非孰低为负 且 营收 < 3 亿）。

· 同业竞争别只信年报"不适用"：那是窄法律口径，会漏掉关键个人（二代/技术核
  心/创始人亲属）以个人身份设立的体外公司——对关键内部人补查公开工商登记；
  查不到就说"未见公开记录"，别替年报背书。


──────────────────────────────────────────────────────────────────────
七、质检关（出 PDF 前必过，纯后台、三道独立防线）
──────────────────────────────────────────────────────────────────────

来历：曾在一份报告里既犯幻觉（金额写错、漏算理财误判危机、把一次性当变脸），
又犯成见（套"小盘股陷阱"模板、红旗不写善意解释、一边倒）。三道防线就是堵
这两类错。

1. 代码对账（最便宜，先跑）：把草稿每个金额/百分比分成"有据/未匹配"，并
   打印地面真值（含真实净现金 = 货币资金 + 理财 − 有息负债）。

2. 防幻觉 agent（独立上下文）：起一个干净上下文的子代理，只喂原始材料 +
   草稿、不带写报告时的推理，把每个数字、每句具体事实/引语对抗性地回查到
   财务或年报原文，默认"无据"，输出 必改/存疑。

3. 防成见 agent（独立上下文）：再起一个子代理，按纪律清单逐条查（见第八节）。

独立上下文是命门——一旦让检查 agent 读了草稿结论再"复核"，它就和作者共享
盲点了。检查 agent 只挑错、不改写；最终判断和修改由人做。收两份红黄牌 →
改掉所有红牌 → 清零，才出 PDF。

派子代理防卡死：重本地大文件（如约 30 万字年报）的提取/质检代理走前台、
prompt 硬性要求"先 grep 定位章节、再读小段、禁止整篇读"——频繁小工具调用
让运行时看门狗（超 600 秒无工具调用即判停）保活；后台只留给频繁出工具调用
（联网类）或短任务。


──────────────────────────────────────────────────────────────────────
八、反成见铁律（最高优先级偏好）
──────────────────────────────────────────────────────────────────────

基调＝发现价值，不是批判公司。全程守。

· 三段式：① 中性摆事实 → ② 先给最善意/牛市视角再判断 → ③ 落到"要盯什么
  去发现价值"。

· 每个红旗先写最善意的解释、再判断；每个问题给两面、别一边倒。

· 禁用偏激标签/人格标签：毁灭价值、投机泡沫(当定性)、续命、命门、为别人买
  单、失控、赌徒型、凑规模、割韭菜……一律不用，哪怕亏损投机股也公允对待。
  成见也藏在用词里——主旨句、小节标题、形容词会偷偷定性；批评只落在"具体
  能力 + 机制证据"上，不给管理层贴人格标签。（报告里可以出现人名，naming
  本身不违规；要查的是有没有贴标签。）

· 别套模板：不带预设结论、不套"陷阱/泡沫/伟大公司"模板，不借"衰退小盘股"
  之类的负面篮子起范。

· 防乐观成见（对称版，结论偏正面时同样狠）：当结论是"便宜/有安全边际"时，
  专门查乐观偏移——① 熊市举证要铺得和牛市一样具体（别牛市有机制有画面、
  熊市一句带过）；② 别用"免费期权/赔率偏上行"这类轻快措辞把高度不确定的
  东西说得像白捡，明写"到期日不确定、可能长期不行权、代价是机会成本"；
  ③ 别把未核实的数喂进估值再据此下结论（可精确查的必须钉死）；④ 多空举证
  门槛对称。

防成见和防幻觉一样，是对抗性的：不是写完检查一遍，是让一个不知道你结论的
独立 agent 来挑。


──────────────────────────────────────────────────────────────────────
九、写作标准（最高写作标准）
──────────────────────────────────────────────────────────────────────

· 展示别断言（show, don't tell）：每个判断后面必须跟具体数字/机制/画面。
  绝不写成"放大版摘要"。

· 一章一章深挖：写透一章再下一章，深度优先于覆盖面；穷尽、给具体公告/事件/
  证据；追求完整度、不限页数。

· 各章守边界：业务概述里别把控制权条款、治理全貌、估值整段铺开——点到 +
  "详见第 X 章"即可，否则后面章节空心化、全篇重复。

· 标点与排版（强偏好）：正文完全不加粗（只标题/表头加粗）；引号除非逐字引
  原话否则一律不用。PDF 每章新起一页、微软雅黑、行距 2.0。

· 九章结构：业务概述 → 发展历程 → 行业与竞争格局 → 商业模式与盈利引擎(嵌
  第一柱) → 资本配置(嵌第三柱) → 组织治理与诚信 → 财务全貌(嵌第二、四柱 +
  会计可信度) → 投资分析与估值(三情景 + 反向DCF + 核心driver + 四柱→安全
  边际) → 风险全景(风险矩阵)。


──────────────────────────────────────────────────────────────────────
十、交付物 + 交互器要点
──────────────────────────────────────────────────────────────────────

· 完整报告 PDF：用户的阅读版（源文件是 .md）。

· 估值交互器：
  - 四柱判断仪表盘（安全边际头条 + 周期高峰提醒 + 四柱卡）；数字来自
    metrics.json，判断一句话 + 详细分析来自 valuation_inputs.json 的
    pillars 块——每家都必写 pillars + details，引用本公司具体数字、落到这只
    股票、不写课本定义。
  - 三情景（每情景必写 故事 + 治理）、反向 DCF 解读卡、业务板块桑基图、
    近 5 年股价走势 + 绿色内在价值带。
  - 下一份财报提醒横幅：每家必填 next_earnings；查不到就按"上次财报 + 约
    3 个月"估、标 estimated。
  - 美股要手写 segments.json 让桑基图画出收入组成（A 股自动抓）。

· decision.json（后台复盘用）：判断 + 价值区间 + 入场观察区 + 概率分布 +
  要盯的关键变量(催化剂) + drivers + 关键风险。


──────────────────────────────────────────────────────────────────────
十一、越学越智慧（闭环，把一次性研究变成持续进化）
──────────────────────────────────────────────────────────────────────

1. 沉淀：每家定稿后写 decision.json，钉下当时的判断 + 价值区间 + 入场区 +
   概率 + 催化剂 + 关键风险。

2. 回喂（每次分析前必做）：动手前先读教训库，把过去的坑用上。这是关键——
   光记不回喂就只是日记。

3. 复盘：找出出了新季报/新公告的公司 → 对照论点/情景/概率、找盲点 → 提炼
   1 条可推广教训（描述成"一类情形"、不绑定具体股票）加进教训库。反复出现、
   被验证重要的，升级进反成见铁律。


──────────────────────────────────────────────────────────────────────
十二、踩过的坑·可推广教训精选（动手前扫一眼）
──────────────────────────────────────────────────────────────────────

【财务阅读】
· "现金紧张"要看 货币资金 + 理财 + 大额存单 − 有息负债 的合计，别只读
  "货币资金"一行（钱常只是从活期挪进了理财）。
· 异常盈亏先剥离一次性项目（诈骗/处置损益/政府补助/减值/汇兑）再看主业；
  别把一次性亏损当业绩变脸。
· 折旧/摊销年限变更要跨年对比表本身，别只看最新一年附注的"本年不适用"。
· GAAP 亏 ≠ 经营失血——先看是不是非现金 SBC + 重研发造成的会计假象（判别
  看经营现金流符号）。

【周期 vs 结构】
· 核心业务单年大幅下滑，先判断是周期波次还是护城河塌方——两者结论完全相反，
  必须用行业"游戏规则"去分。

【估值】
· "生意值多少"和"这个价格买不买"是两个独立问题，别糊成"又贵又烂"或"又好
  又该买"。
· 现价约等于最乐观(Bull)情景时，结论是"好生意、贵价格、不在此价位买"，而
  不是因为生意好就追高。
· 控股集团 SOTP 只扣母公司外部净债、不扣合并净债（同一笔债别算两次）。
· 待决并购/特殊情形：把估值拆两条腿（成交 vs 破裂）按概率加权，别只算一条。

【事实核查】
· 凭记忆枚举参股/子公司/代码必错——务必联网 + 一手年报双重核（曾把易宝支付
  误记成参股、把贝特瑞代码记成旧的、把某参股子公司市值估高近五成）。
· 一手年报 > 二手联网，尤其涉人涉刑的指控：媒体口径要回年报/裁判文书原文核，
  未证实的不作为事实写。
· 把传闻和事实分清（如"被立案"的不实传闻 vs 真实监管处罚）、把字面相近的
  人名分清。

【成见】
· 红旗先写善意解释；不贴人格标签；不套模板；偏激词清零。
· 结论偏正面时防乐观成见，和防悲观成见一样狠（熊市铺厚、别用轻快词、别锚
  未核数）。


──────────────────────────────────────────────────────────────────────
机器自身（熔断原则，2026-07-05 入总纲——防这套方法论长成博物馆）
- 任何新机制立项前，必须指名它本可以抓住哪个已经发生过的真实错误；指不出＝不建。
- 出现新错误类型时，优先问现有五关哪一关的查项能覆盖——加查项优先于加关（第六道质检关明确不做）。
- 学习闭环没吃到足够数据（预测结算 <10 条）之前，克制再加新学习机器的冲动。
- 台账在 reviews/OPTIMIZE.md，每季度末盘一次——路线图自己也会腐烂，敢砍不再值得做的。

十三、评判"一笔分析做得好不好"的自查清单
──────────────────────────────────────────────────────────────────────

[ ] 我能不能用三句话讲清这门生意怎么赚钱、护城河在哪、游戏规则是什么？
[ ] 四柱（复利引擎/所有者盈余/资本配置/生存）每一柱都有硬数字 + 一句落到
    这家公司的判断？
[ ] Track 分流对不对？现金流为负/资产型的有没有错用 DCF？
[ ] 三情景是不是都 steelman 了？牛市是"算出来"的、不是为得出结论倒推的？
[ ] 反向 DCF 说清了"市场在买什么故事、隐含多高的预期"？
[ ] 生意 vs 价格分开答了？安全边际是"我能看错多少还不亏本金"、不是精确点？
[ ] A 股：用扣非了吗？股东性质/控制权/会计可信度/ST 预警都过了吗？
[ ] 过了三道质检关、红牌清零了吗？（代码对账 + 防幻觉 + 防成见，独立上下文）
[ ] 红旗都写了善意解释、没贴人格标签、没套模板、没偏激词？结论偏正面时防了
    乐观成见？
[ ] 报告是 show-don't-tell、一章一章深挖、不是放大版摘要？正文没加粗、没滥
    用引号？
[ ] decision.json 写了、教训库回喂了、这次有没有沉淀一条可推广教训？
