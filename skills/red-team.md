# 技能：红队结论 agent（第四道质检——攻击论点本身）

> 2026-06-10 新增。前三道质检查**事实**（check_numbers + fact-check）和**措辞纪律**（discipline-check），
> 没有人专职论证**结论本身是错的**。这第四道补上：一个独立 agent，唯一任务是构建"你的 verdict 是错的"的最强论证。
> 原理与质检关相同——**独立上下文是命门**；区别是对象从数字和用词升级到论点。

## 触发条件（不是每家都跑，将要影响行动时才跑）

满足任一即必须过红队关：
1. **用户表示要行动**（买入/加仓/卖出某只已分析的票）；
2. **价格进入 entry_watch 观察区**（review.py 价格触发→机会复盘时，红队是复盘的一部分）；
3. **首次分析结论为偏低/有安全边际**（正向结论的代价是真金白银，举证从严——这与防乐观成见铁律同向）；
4. 其余情况（结论偏贵、纯观察）可选，不强制。

## 怎么起（主 Claude 操作）

用 Agent 工具起独立 subagent，**只喂**：
- 该公司 `decision.json`（verdict / 三情景 / 概率 / predictions / odds）+ 报告第八章（估值章）；
- `financials/`（metrics.json、financials.csv）与最新价；
- **不喂**报告其余章节的论证过程、不喂写报告时的推理——红队要自己从数据出发找反例，不能顺着作者的思路走。

## 红队的任务书（给 agent 的指令骨架）

你是唯一职责为**推翻结论**的对抗性审查员。结论是 X，你就构建非 X 的最强论证：
- 结论偏空（贵/回避）→ 构建**最强多头案**：作者低估了什么上行？哪个 driver 的结构性被当成了周期性？base rate 是否被错用（这家是不是恰好属于例外类）？市场看见了什么作者没看见的？
- 结论偏多（便宜/有边际）→ 构建**最强空头案**：价值陷阱的具体剧情？哪个"地板"会塌（资产可回收性、子公司市值下修、担保代偿）？概率是否乐观、熊市是否铺薄了？流动性/杠杆在坏周期里怎么把股权吃掉？
- 两个方向都要：**攻击概率分布本身**（为什么 bear/base/bull 不该是这组数）、**攻击情景宽度**（真实结局会不会落在三情景之外）、**攻击关键假设的单点依赖**（哪条假设一倒全篇倒）。
- 输出格式：3-6 条攻击，每条【攻击点 + 依据（数据/机制/判例）+ 如果我对结论该改成什么】，最后一行给红队自评：本次攻击 强/中/弱。
- 红队**只攻击、不和稀泥**——不写"但作者也有道理"；公允性由主 Claude 裁决时负责。

## 主 Claude 怎么收（裁决，人主导）

- 逐条回应：**采纳**（改结论/概率/情景）、**部分采纳**（补写进风险章/Bear）、**驳回**（写明驳回理由——理由必须是证据，不是"我original判断如此"）。
- 红队攻击与裁决摘要写进 `analyses/<代码>/review_<日期>.md`（复盘场景）或报告第八章末尾（首次分析场景，一小段即可）。
- 改了结论 → decision.json 同步更新（verdict/概率/predictions），并在 CALIBRATION.md 记一笔（红队拦截属 E 类升级的正面样本）。

## 铁律

- 独立上下文，不喂作者推理；
- 红队意见不直接定稿——主 Claude 裁决、用户拍板（人主导，工具辅助）；
- 驳回必须给证据级理由，禁止以"原判断"为由驳回；
- 防卡死规矩同质检关：grep 定位 + 小段 Read，禁整读年报。
