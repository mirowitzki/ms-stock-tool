# 技能：分析深度 —— 从"组织事实"到"形成并论证一个价值判断"

> 来历（2026-06-19，用户拿 688237《超卓航科》深度报告对照 603358）：603358 经 depth-check 重写后事实密度已接近，但用户点出真正的差距在分析层面——"我需要的不是客观事实的罗列，而是非常深度的对公司的理解和分析，以便于寻找价值"。诊断：`depth-check.md` 管的是**事实轴**（材料用没用够、有料没用），但寻找价值靠的是**分析轴**（把数字解读成价值含义、形成贯穿全文的论点、指出市场看错在哪、诊断价值困在哪靠什么释放）。这份技能把分析轴的方法成文。
>
> 一句话：**事实深度回答"是什么、怎么样"；分析深度回答"所以对价值意味着什么、市场看错在哪、价值困在哪、什么能释放它"。一份报告的价值在后者。** 标尺＝688237《超卓航科》深版。

## 动笔前，先做"分析"这一步（不能跳过、直接码字）

采集可以外包给 agent，但下面这一步是作者（主 Claude）必须亲手做的、且要在写正文之前单列出来想清楚：

1. **先写出一句核心论点（thesis）**——用一句话说清这家公司到底是什么、价值在哪、问题在哪、合理与否取决于什么。它要能拎起全文、可记忆、有观点、敢下判断。范例（688237）："一个又窄又深、护城河极宽的军用修理内核，外加一组上市后用资本配置搭起来、已有两块跑通、一仍在培育的军民融合业务"；收尾再砸一句"它的合理与否，不在公司，而在价格"。没有这句，整篇必然退回"事实的堆叠"。
2. **找认知差（variant perception）**——市场/外界现在怎么看这家公司？哪里看错了、看漏了、或看反了？那个差，就是价值或风险的来源。这是寻找价值最核心的动作。至少找一处，明写成"市场以为 X、实际是 Y、这个差意味着……"。范例（688237）："市场普遍低估工业母机这块——毛利率其实 31.6%、远高于外界以为的十几个点"；"约 1% 的净资产收益率具有误导性，剥离过剩现金和亏损新能源后，三块高毛利业务经营性回报率 15%-25%"。
3. **诊断价值困在哪、靠什么释放**——用价值阶梯（见动作 5）找出价值被什么困住（低效资本配置 / 控股折价 / 周期低谷 / 题材未兑现 / 治理结构），以及什么动作能把它释放出来（催化剂）。这一步直接回答"edge 在哪"。范例（688237）："收益能力价值 < 资产价值＝它没在创造价值、被困在低效资本结构里；价值释放不需要业务变好，只需要资本配置变得不那么差"。
4. **定主变量**——哪个变量牵一发动全身（控制权落定 / 某个拐点 / 某项政策）？情景、风险、催化剂都绕着它转。范例（688237）："控制权落定与否，几乎牵动其余所有风险的走向"。

这四步的产物，是整篇报告的脊梁。写每一章时，每个事实和数字都要回头喂这根脊梁——印证它、修正它、或被它解读。

## 七个分析动作（写作时逐条落实，insight-check 逐条查）

1. **核心论点贯穿全文**。每章都在论证、精炼那一句 thesis；每章开头的执行摘要不是内容预览，而是该章的判断综合（能单独成立的一段判断）。
2. **每个承重数字必做"价值含义"解读**。写完一个数字，强制追问一句"so what for value"。别停在"2025 扣非塌八成"，要走到"塌掉的八成是一次性投资收益、主业扣非其实接近零并转亏——所以报告利润是会计假象、真实盈利能力在退化、看这家公司必须用扣非"。范式：数字 → 它真正反映什么 → 对价值/护城河/久期/赔率意味着什么。范例（688237）：−3500 万 → "是被一桩外部诈骗砸了个坑、剔除后仍有 1900 万盈利、2023 不是经营崩了"；核心军品 −28% → "是机型切换的低谷、不是唯一供应商地位松动"。
3. **明说市场看错在哪**。把共识写出来、再指出偏差："市场把它当 X 定价，但 Y 被低估/高估/看漏了。"哪怕结论是"市场大体定价正确"，也要说清市场在为什么故事付钱、隐含了什么假设（反向 DCF 就是干这个）。没有这一层，就不是在寻找价值、只是在描述公司。
4. **财务正反双视角——用数字反推管理体质与文化**。正向＝把三张表和分部摆开、看数据本身；**反向＝问"这组数据反推出一家什么状态、怎么管理、什么文化的公司"**。范例（688237）：连续三年负经营现金流 + 约 2 亿应收 → "反推出一家垫资给军方大客户、客户至上不敢得罪的配套商文化"；货币资金锐减而理财堆高 → "一家钱投不出去、只能理财的保守资本文化，根源是 5995 万垫款后管理层畏首畏尾"。财务章必须有这层"从数字反推体质与文化"——这是把财务和治理打通、读出"管理层是什么人、会怎么配置资本"的关键，也是外部资本能补位在哪的判断。
5. **价值阶梯 + 诊断"价值困在哪"**。四层依次摆出：① **资产价值**（地板，谨慎调整后）② **收益能力价值 EPV**（正常化所有者盈余 ÷ 要求回报率，假设零增长）③ **分部加总**（结构修复后）④ **成长/平台价值**（视故事弹性）。关键诊断有两个：(a) 若 **EPV < 资产价值** ＝ 公司没在创造价值、资本被低效占用，价值靠资本配置释放、非业务变好（经典 EPV vs asset value 信号）；若 **分部加总 >> 现状市值** ＝ 价值被结构困住，点出什么动作能释放。(b) 用"**经营性资本回报率（剔除过剩现金后、业务自身盈利对其占用资本之比）vs 合并 ROE**"的背离，把"生意本身好不好"和"合并层资本配置好不好"分开诊断——这往往是最尖锐的洞察。
6. **情景是带名字的故事 + 关键前提 + 主变量**。每个情景给一个名字、一段故事、一个关键前提、对应价值区间；点出哪个变量是牵一发动全身的主变量；涉及换股/平台并购时用每股价值口径（防摊薄陷阱：做大市值 ≠ 每股价值增厚）。别只给"扣非 × 倍数 × 概率"的机械三档。
7. **全程 so-what-for-investor + 锐利判断句**。每段分析落到"对一个要决定买不买/收购的人，这意味着什么动作、什么赔率、什么该盯"；提炼可记忆的判断句（"它不是复利机器，是被困在低效结构里的好利基生意""它缺的不是资本，是把资本配置到高回报方向的能力""合理与否不在公司、在价格"）。这些句子是分析的结晶，不是修辞。

## 红线（分析层面的"写水"，insight-check 见此即判 🔴/🟡）

- 通篇没有一句立得住的核心论点 ＝ 不合格（再多事实也只是材料）。
- 关键数字只陈述、不解读成价值含义 ＝ 罗列、不是分析。
- 全篇找不到一处认知差（市场看错在哪）＝ 没在寻找价值。
- 财务只有正向、没有"从数字反推体质与文化" ＝ 漏了半个视角。
- 估值只回答"贵不贵"、没回答"价值困在哪、什么释放它" ＝ 没回答价值问题。
- 情景只有"扣非 × 倍数 × 概率"、没有故事和主变量 ＝ 机械、非分析。

## 与其它技能的关系

- **与 depth-check（第四道关·事实轴）**：那道查"材料用没用够、有料没用"；本技能对应的 insight-check（第五道关·分析轴）查"有没有论点、有没有把事实解读成价值判断"。两道并行、各管一轴——一份报告可以事实很全（过 depth-check）却分析很浅（不过 insight-check），反之亦然。
- **与 value-judgment.md（四柱）**：四柱（复利引擎 / 所有者盈余 / 资本配置 / 生存）是事实框架；本技能是把四柱的事实拧成一个价值判断、并找出认知差与价值释放路径的方法。
- **与 report-writing.md**：那是文字标准（show-don't-tell、正文不加粗、不滥用引号）；本技能是分析标准（要有判断、要找价值、要解读每个数字）。
- **基调铁律照旧**：发现价值、不批判公司；认知差与判断要 steelman 反方、守反成见（乐观与悲观对称）。

## 报告独立性铁律（2026-06-19，用户点名）

每份个股报告必须独立成立——读者不需读过库里别的报告就能看懂。**对照只对同行/竞争对手**（同行业可比公司、直接竞争对手，用来评估竞争位置、相对估值、护城河深浅、毛利与回报的相对水平）——这是好分析、且鼓励做。**但绝不把对用户已分析过的其它个股（往往是不同公司、甚至不同行业）的对照当成分析骨架**——那让报告依赖读者的阅读史，且常常用"它不是那家"代替"独立论证这家"。反面范例：603358 初版通篇拿 688237（超卓航科）作贯穿对照，被用户要求全部拆掉——那些洞察（护城河浅、EPV<资产价值、借钱分红、价值释放路径窄）本就是这家公司自己的，借别家的壳说只会显得不独立、还绑架读者；拆壳后独立陈述毫不损失、反而更自包含。注意：本技能内引用 688237 等作方法范例，是给作者校准"分析该长什么样"用的，**不进交付给用户的报告**。
