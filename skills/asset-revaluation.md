# 资产质量逐项重估：账面价值 ≠ 真实价值（Track C 资产法的必备步骤）

> 来历：大东方 600327 物业一例——初稿用住宅式"面积×单价"把 8.21 万㎡自营百货楼估到 6.6-12.3 亿、误判真实 PB 0.8、得出"略低估有安全边际"，被用户三轮纠正。根因有两层：①技术——商业地产该用收益法不该用单价法；②动机偏差（更危险）——我潜意识想找便宜货，于是只在"能证明它便宜"的方向重估资产、对"会让它更贵"的方向警惕不足。这暴露的不是一个特例，而是框架级缺口：**会计账面价值是一套为审慎和一致性设计的记账规则，它系统性地、方向可预测地、且双向地偏离真实经济价值。** 任何用到净资产/PB/账面的估值，都必须先做资产质量逐项重估。

## 0. 核心原则

- **账面是中性起点、不是真相。** 用资产法（NAV/SOTP/Track C·破净/控股集团/低盈利有资产的公司）估值时，绝不能拿账面归母净资产直接当价值起点，必须对账面每一大块资产做"账面 vs 真实"的双向审视，输出**调整后 NAV**。
- **双向、对称用力。** 既往下调系统性高估的资产、也往上调系统性低估的资产。**只往一个方向（尤其只往上找便宜货）＝系统性偏差、是动机偏差的产物。**
- **PB 的认识论**：PB<1 不等于便宜（资产可能账面高估）、PB>1 不等于贵（可能藏着账面低估的隐蔽资产）。先重估资产质量、再判 PB 贵贱。
- **重估完还要算时间（2026-07-04 加）**：调整后 NAV 是快照；经营亏损/被抽血的资产股，NAV 是一条下行曲线——重估之后必须接着算**地板保质期**（硬地板 ÷ 年侵蚀额）、与催化剂时间表对表，见 `skills/chapter-cards.md` 第八章「资产地板保质期」（Sears 教训：资产算得大体对、输给了融化速度）。

## 1. 账面系统性高估、真实更低的资产（往下调——破净不等于便宜的真相）

| 资产科目 | 为什么账面高估真实 | 怎么重估 |
|---|---|---|
| 商誉 | 收购溢价挂账、减值永远滞后于业务恶化 | 看被收购业务是否恶化（收入/利润趋势）、减值是否充分；明显恶化的大幅折或归零。（大东方医疗商誉 2.59 亿，已累计减 1.15 亿仍未出清） |
| 长期股权投资（参股） | 权益法/成本法记账，被投资公司经营恶化时真实<账面 | 上市的按市值×穿透持股；非上市看其经营+周期位置；周期下行/已亏损的打折。（大东方汽车参股 18.98 亿占归母净资产 68%、却是质量最差的一块） |
| 存货 | 成本计价、跌价准备滞后 | 看周转天数、是否过时、行业价格趋势；滞销/过时/价格暴跌品大幅折（面板、光伏组件、消费电子、时装） |
| 应收账款 | 名义金额、坏账计提滞后 | 看账龄结构、关联方占比、对手方信用；长龄/关联方/单一大客户打折 |
| 固定资产 | 折余成本 ≠ 变现价值 | 专用设备/过剩产能/夕阳行业按清算价（远低于账面）；只有通用资产/稀缺地段物业才接近账面（钢铁、过剩光伏/面板产能） |
| 投资性房地产 / 经营性物业 | 成本模式计量、且业态可能萎缩 | 收益法（年净租金÷资本化率）、反映行业现实；**查是否已含在经营里（见第 3 节防重复）** |
| 递延所得税资产 | 依赖未来盈利才能变现 | 持续亏损公司可能永远用不上、折或归零 |
| 开发支出/资本化研发 | 资本化 ≠ 有真实价值 | 看项目前景，失败项目归零 |

## 2. 账面系统性低估、真实更高的资产（往上调——PB>1 也可能藏便宜，但严防重复计算）

| 资产 | 为什么账面低估真实 | 怎么重估 | 陷阱 |
|---|---|---|---|
| 内生品牌/无形 | 自创品牌账面≈0 | 看溢价能力、复购、定价权（贵州茅台、可口可乐） | 价值已体现在高毛利/高 ROE 里，别和经营 PE 叠加 |
| 早年低价地产/土储 | 历史成本远低于市价 | 市价/可变现价（房企土储） | 自用经营性物业的价值已含在经营里（大东方错处） |
| 成本法记账的优质参股 | 成本 ≠ 市值 | 按公允价值/市值×持股 | 周期股参股的市值含复苏预期、熊市要下修 |
| 牌照/特许经营权 | 账面为零或极低、真实稀缺 | 稀缺性、可比交易、可变现性（券商/银行/保险牌照） | 不能独立变现的牌照打折（银之杰东亚前海/华道征信） |
| 超额现金/隐性金融资产 | 藏在各科目里 | 全口径核（货币资金+理财+大额存单−有息负债） | 贸易/经营周转占款不是真净现金 |

## 3. 三条硬纪律

**纪律一·双向对称（防动机偏差）**：两个方向同时做、对称用力。结论偏"便宜/有安全边际"时，强制自检：我是不是只在支持便宜的方向（往上）重估了资产？往下的方向（商誉/坏长投/过剩产能/滞销存货）审得一样狠吗？——这是 guard-optimism-bias-too 在资产法里的最锋利一刀。

**纪律二·防重复计算（自用经营性资产）**：自用经营性资产（自营物业、自有品牌）的价值已部分体现在经营利润里（不付租金→利润偏高、品牌→毛利高）。它的重估增值只在"清算/转让/REITs/业态转换"情景下才额外兑现，**不能与按经营利润算出的持续经营估值叠加**。判别：比较"资产独立变现价值"与"持续经营价值（净利×合理倍数）"，**取较高者、绝不相加**。前者≤后者＝资产价值已被经营充分利用、没有可额外释放的隐蔽价值（自营比出租更值钱）。

**纪律三·重估方法对类型**：每类资产用对方法。商业地产/经营性物业用收益法（不是面积×单价）、且反映行业景气（中国商业地产 2024-2026 在萎缩：万达约-30%折价甩卖、二线零售物业 cap rate 升至 6.5-9%）。周期股资产按中周期正常化、不锚低谷也不锚高峰。上市资产钉死市值、不估算。

## 4. 落地：资产法估值必出"调整后 NAV 表"

报告第八章用资产法（Track C）时，必须呈现一张逐项重估表：以账面归母净资产为起点，列出主要资产科目的"账面值 → 真实值"双向调整（往下：商誉/长投/过剩资产/滞销存货减值；往上：隐蔽优质参股/品牌/可变现地产/牌照增值；防重复：自用资产不叠加），得到调整后 NAV，再据此判 PB 贵贱。**不允许直接拿账面 PB 下"便宜/贵"的结论。**

valuation_inputs.json 的三情景 story 要把这张表的关键调整写进去；reverse_dcf_commentary 要点明真实 PB 与账面 PB 的差、及差从哪来。
