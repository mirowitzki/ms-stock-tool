# 产业链研究方法论 —— 第二阶段（自上而下，从产业链找到值得研究的股票）

> 缘起：第一阶段是**自下而上**——盯住一只股票，把它读透、估值、判断（四柱框架见 `value-judgment.md`）。
> 第二阶段是**自上而下**——给一个产业 / 主题，画出完整产业链图谱，定位价值落在链条哪一节，最终产出值得研究的 A股＋美股候选。
> 这套方法 **v2 经三个互不通气的独立视角对抗性审稿升级**（行业分析师 / 战略经济学 / 价值投资者），把一批经典框架吸收了进来——
> Gadiesh & Gilbert 利润池、Helmer 7 Powers、Greenwald 进入壁垒、Marathon 资本周期、Christensen 利润守恒、
> Mauboussin 预期投资与 CAP、Williamson / Rey-Tirole 租金可占有性、GVC 治理、commoditize-your-complement、微笑曲线、经验曲线。
> **基调与第一阶段完全一致：发现价值，不是批判产业或公司。**

## 总纲：三道闸门 + 一把尺

- **铁律 · 闸门只在产业链上找价值，完全不碰个股（2026-06 用户两次强调）**：所有闸门的唯一目的，是发现真正的价值在产业链哪一节、是否持久。**个股的估值、贵不贵、买不买、反向 DCF、四柱——全部是第一阶段单股工具的活，不在闸门里做。** 用户的流程是：过完闸门、锁定价值在哪个环节 → 自己把那一节的公司送进第一阶段深析（那样更完整）。闸门里提到公司，只作"这一节由谁占据 / 集中度如何"的结构事实，不附任何投资判断、不列买卖名单。腾出的篇幅用来把环节层洞察讲得更细更透。
- **环节定价温度计（铁律的边界条款，2026-06-10）**：上面禁止的是**个股** verdict 与买卖；**环节层**的定价松紧温度（该环节代表性估值倍数的区间、与历史/跨环节的相对位置）是允许且必要的——variant perception 本来就需要知道市场把哪个环节定价定满了、哪个还有预期差。规矩：只用环节聚合口径、明标数据时点与来源、不落到任何一只票的判断/目标区间/买卖名单。
- **知识形态铁律（2026-06-10）**：链的判断与数字**先进结构化文件、页面是渲染层**——每条链维护 `nodes.json`（节点卡：五层判断+关键数字带源带置信度+替代威胁时间表+适用边界）与 `indicators.json`（领先指标定义+基线+季度数据点）。更新一个环节=改一张卡；散文里不许藏页面外查不到出处的承重数字。
- **三道人工闸门**（每道由用户拍板）：
  1. **图谱**：第一性原理把整条链拆透 → 吐出 N 个值得研究的赛道 / 核心零部件 →【用户选】
  2. **成本法**：对选中赛道做成本 / BOM 拆解，判断价值在哪个环节最持久、最值得深析 →【用户确认】
  3. **落股票**：把选中环节的公司送进第一阶段单股工具——**这一步不在闸门里做，是闸门的下游交接**。
- **本 skill governs 全程，主战场是闸门①**（下面五层框架）。闸门②③在末尾。
- **两个层、分工清楚**：闸门用环节层的价值判断——价值怎么被创造 vs 被占有、护城河是结构性还是周期租金、资本周期 peak、价值往哪迁移。等闸门锁定了值得深析的环节，第一阶段那把个股的尺（ROIC − WACC、所有者盈余、反向 DCF、四柱）才上场。闸门判环节、单股工具判个股，衔接但不混做。
- **分工不变**：能联网查到的硬数字（份额 / 产能 / capex / 价格 / 交期）**要查、要标源**；判断（护城河方向、利润迁移、周期位置、是否被定价）是你的活。**展示别断言：每个判断后面跟具体数字 / 机制 / 画面。**

## 五层框架（闸门①里，每个环节都过这五层）

### 第一层 · 拆链：第一性原理 + 先定边界

**怎么拆**：不要从"有哪些相关公司"正推（那是券商全家福），从**功能倒推**。先问这条链最终卖什么效用（价值锚），再问交付它**物理 / 技术上必须发生哪些不可绕过的转换**，逐层往上推每一节"没有它这事成不成"。
> AI 数据中心的价值锚＝**单位成本最低的有效算力**（每美元能算多少有用的训练 / 推理）。往上推：算力（逻辑芯片）← 芯片要喂数据（HBM / 存储）← 芯片间要通信（NVLink / 网络 / 光 / 铜）← 全都要供电（电源 / 母线 / 变压 / 配电）← 全都会发热（风冷→液冷）← 要装进物理空间（机柜 / 土建）← 整个要吃电（发电 / 电网 / 能源）。

**那把好刀（保留，审稿人公认的强项）**：每一节再追一刀——它是**原理上必须**，还是**只是当下的技术选择**？前者价值稳固（芯片必须被喂数据），后者价值脆弱、迟早被替代（用铜还是用光、风冷还是液冷）。这一刀直接决定哪些环节值得长期押。

**先定边界（profit pool 第一步，别漏）**：开拆前先论证这条链从哪到哪。**AI 数据中心若只画"芯片→服务器→机房"、漏掉电力底座和软件生态，结论必错**——电力是当下真正的硬约束，软件生态（CUDA）是利润归宿的关键。把这两条**作为一级子链 / 一级视角纳入边界**。

**需求台账（数量级地基，2026-06-10 新增，闸门①必做）**：链上多数错判来自需求侧的故事化高估，所以拆链时必须给需求装一个**可核算的数量级模型**——不是预测，是台账：
- **自下而上**：终端需求 = 单位需求 × 渗透率 × 替换/扩张周期（如 GW 新增装机 → 折算到每个环节的收入池：多少台变压器、多少 MW 燃机、多少套 UPS）；
- **自上而下**：用宏观口径（capex 总盘子、出货量统计）交叉核；
- **两向对不上 ≥ 一倍即红旗**——要么口径错、要么故事虚，必须当场解释，不许带着矛盾往下走；
- 台账里的母变量（如 capex/收入比）钉成可证伪预测进 `chain_decision.json`，季度 checkpoint 跟踪。
这是单股"反拟合 DCF 让代码纠正乐观"的链版：数量级一摆，很多性感故事自己就塌了。

**第一层的命门陷阱：物理必须 ≠ 经济上能拿走利润。** 空气对生命不可绕过，却不值钱——因为不稀缺、无产权、无议价。一个环节要拿超额利润，须**同时**满足：功能必须 + 供给受限 + 可占有（有壁垒挡住竞争把利润打掉）。**只做到"哪步物理必要"是工程瓶颈思维，不是经济学第一性原理**——经济学第一性要回答"租金为什么归这一节、还能不能守住"（接第二层）。

### 第二层 · 价值在哪创造 vs 被谁占有（两轴，别混为一谈）

很多环节**创造**巨大价值却**占有**不到（中段制造、标准组装），反之亦然。拆成两轴打分：

- **创造（利润池地图，要闭环）**：照 Gadiesh-Gilbert——画**收入份额 vs 利润份额**两条对照，**背离最大的环节就是信号**（收入大但利润薄＝苦力；收入小但利润厚＝价值高地）。全链利润首尾相加要对得上（闭环验证）。**度量用 ROIC − WACC，不用会计毛利**：高毛利但天量 capex / 营运资本的环节，ROIC 可能长期 < WACC——这种环节**增长越快、毁灭价值越多**（Mauboussin），一律标红"价值毁灭 / 产能黑洞"，不管多卡脖子。
- **占有（租金三问＝经济学第一性原理）**：① 这一节的超额利润**来自哪种稀缺**（要素 / 专利 / 转换成本 / 网络效应 / 牌照 / 良率门槛）？② 对手**为何打不掉**（壁垒机制）？③ 上 / 下游和**互补者能不能把它抽走**（Williamson 资产专用性 + Rey-Tirole 纵向圈定：握住瓶颈投入的环节可以抬高对手成本、断供、捆绑）。
> AI 链样本：HBM 现在 60–70% 毛利，但那是**工程出来的周期性紧缺**（CXMT / 三星扩产后会回落），不是结构性护城河——租金三问能把这种"紧缺毛利"和"护城河毛利"分开。CoWoS 的租金归台积电、不归封装材料厂，正是可占有性的差别。

### 第三层 · 护城河能不能守住（环节层，且要接得上价格）

- **进入壁垒主门（Greenwald，先过这道）**：唯一真正充分的判据是——在位者 ROIC 能否持续 > WACC，**且新玩家进不来**（客户锁定 / 成本优势 / 规模经济）。**过不了这道主门，其余要素再漂亮，护城河判"无"**。别把一堆中性优点罗列出来凑成一个其实没有壁垒的伪护城河。
- **双要件打分（Helmer 7 Powers）**：每个环节对 7 个 Power 逐个问 **Benefit（更低成本 / 更高定价）+ Barrier（对手为何无法模仿）**两要件都要在。**别漏 counter-positioning（反向定位）和 network economies（网络效应）**——对科技链最致命（CUDA 生态就是网络效应＋转换成本，英伟达的护城河大头在这、不在 GPU 制造本身）。
- **久期 CAP（这是接价格的关键）**：每节单独打一列——**这壁垒还能撑几年、会被什么技术 / 政策换掉**（结构性必须＝长 CAP；当下技术选择＝短 CAP）。终值的大头取决于护城河久期。
- **谁在商品化谁的互补品（commoditize-your-complement）**：现代科技链是**生态博弈**不是线性链。问每节"谁在压低它的互补品、把利润汇走"。
> 英伟达开源 / 压低软件互补层、把利润汇向 GPU；超大厂自研 ASIC（Broadcom / Marvell co-design）试图把英伟达商品化——**不看这层，就看不懂利润为什么不按物理重要性分配**。
- **经验曲线（替代 / 通缩速度的定量抓手）**：累计产量每翻倍、成本降 20–30%。学习率高 + 规模门槛低＝价值脆弱（快速通缩）；学习率被物理良率卡住（HBM 堆叠、先进封装良率）＝价值稳固。

### 第四层 · 供给侧资本周期（把"别在高峰买苦力"做成可操作）

> 第一阶段横切·周期校准的产业版。核心信念照搬 Marathon（《Capital Returns》）：**多数人盯需求，但需求难测、供给易测；驱动行业盈利的是供给变化，而股价往往没预判供给侧的转折。人人都在扩产的时刻，正是最危险的顶点。**

- **四象限定位**（每个候选环节贴一个标签）：**扩张顶部**（全行业扩 capex、融资潮、利润率 peak → 避）/ **衰退**（capex 收缩、亏损扩大）/ **出清底部**（产能退出、整合 → 猎）/ **复苏纪律**（少数玩家、定价纪律、ROIC 回升 → 持）。
- **供给侧仪表盘**（填硬指标、不是文字）：① 在建 / 规划产能与投放时间表；② 全行业 capex 强度；③ 近 12–24 月 IPO / 定增 / 可转债融资潮；④ 竞争者是否同步扩产（FOMO）；⑤ 当前行业利润率 vs 中周期均值（peak 偏离度）；⑥ 资产增长率（资产高增长＝未来回报低的强预警）。
- **价值迁移方向律（Christensen 利润守恒）**：利润不是随机迁移——它**流向"还不够好、需要专有整合去优化"的相邻环节**，从"已经够好、可被模块化"的环节流出。
> AI 链当下：算力已"够好"，利润正从代工 / CoWoS **下移到 HBM、电力、散热**——这正是守恒定律 + 资本周期共同预测的方向。在算力芯片本身付全款，可能正错过价值实际去向。
- **卡脖子是租金、不是护城河**：当下瓶颈环节的超额利润，正因为肥，会以最快速度吸引资本扩产 + 国产替代涌入。**要判断"瓶颈持续期"**（看在建产能 + 扩产 capex 多久补上），别静态地把利润永久记给当前瓶颈、然后按高峰利润付全款——那恰好踩进本层想防的陷阱。

### 第五层 · 这价值持久吗：结构护城河 vs 周期顶点租金（环节层出口闸）

> 闸门只在产业链上找价值在哪、是否持久。**一只具体股票今天贵不贵、反向 DCF、四柱——全部是第一阶段单股工具的活，不在闸门里做。** 第五层不给个股估值；它判断这个环节"看起来很肥"的厚利润，到底是结构性持久的护城河，还是短缺顶点会回吐的周期租金——因为成本栈里最肥的环节，往往正是周期最顶点的环节。

- **租金 vs 护城河四问**（接第四层资本周期）：① 卡脖子是结构壁垒（工艺 / IP / 良率 / 关系），还是暂时产能稀缺？② 未来 24–36 个月有多少新增产能在路上（扩产 capex 明牌直接查得到）？③ 有没有替代技术 S 曲线在逼近、价值正往哪迁？④ 最大买方（如超大云厂）能否前向整合或扶二供？——四问全中＝周期租金，会被吃掉、别当永续；只有**供给扩不出来 + 替代绕不过 + 买方动不了**，才是持久结构价值。
- **每个环节落三档**：持久结构价值（穿越周期、值得拿去深析）／ 真实但周期性（短缺顶点租金、要等供给墙、明说会回吐）／ 价值正在迁出（载体会被替代、点出迁向哪里）。
- 这一层直接挡住把短缺顶点的暴利当永续护城河——闸门②最容易犯、且犯过的错（2026-06 电力底座：差点把变压器 / 燃机的短缺租金当护城河）。**个股层面"市场定价对不对"的检验（反向 DCF / verdict 配色）属于第一阶段，闸门只交付"这一节的价值是否持久"的环节级判断。**

## 四条横切纪律

- **A股国产替代做成"机会 + 反噬"双面卡（不要只写机会）**：国产替代既是机会、也是**供给侧冲击**——一旦某环节对国产开放，常是十家涌入、价格内卷、全行业 ROIC 下台阶。每个国产替代环节填两栏：(机会) 替代空间 / 替代斜率 / 未来 2 年盈利确定性；(反噬) 已涌入多少国产玩家 / 内卷程度 / 替代完成后会不会从"卡脖子高毛利"塌成"内卷低 ROIC" / 被替代的在位者市值风险。用 **GVC 治理三变量**（交易复杂度 / 可编码性 / 本土供应商能力）判该环节是**俘获型**（几乎无法升级）还是**模块型**（有空间），而非"开放 vs 锁死"二元。三者同时满足（替代率仍低 + 玩家未过度拥挤 + 替代后仍有壁垒维持 ROIC）才算正向 catalyst。也别忘出口管制 / 实体清单的二元冲击（对 A股 算力链既是利空、又是国产替代催化）。
- **一手信号免费联网清单（免费版专家网）**：吃 Max 订阅、不碰付费数据。但"一手信号"这个动作要做——查招标 / 中标公告、扩产 / 投产公告、海关进出口、电力并网公示、卫星 / 建设许可类公开信息、上市公司互动易 / 调研纪要、行业协会数据。用免费联网逼近专家网的"一手"效果。
- **与第一阶段交接，不在闸门里做个股**：闸门锁定"价值在哪个环节"后，把该环节的公司交给第一阶段单股工具，用四柱（ROIC − WACC、所有者盈余、资本配置、生存）逐个体检——**这一步是第一阶段的活，不在闸门里做**。闸门防的是"环节没找对"，"标的对不对"由单股工具判。
> NVTS 是活样本：好赛道（AI 数据中心供电）+ 差四柱（年烧 $42.9M、SBC 一度占营收 167%、靠增发续命）——但这个判断是第一阶段做出来的，闸门只负责把"AI 数据中心供电"这个环节的价值是否持久讲清楚。
- **布局雷达反哺产业情景（2026-06-14 新增）**：第一阶段单股的「产业布局雷达」（`analyses/<TICKER>/layout.json`：龙头的资本投向 + 产品 / 合作 → 指向哪些产业）是产业链情景判断的**领先输入**——龙头买家把钱往哪砸，是供给侧最早的信号。**反哺到四处**：① 供给侧仪表盘 / 资本周期（capex 先行：龙头投某环节 = 资本即将涌入）；② 需求台账·买方侧（龙头的采购承诺是最硬的自下而上需求数据点）；③ 价值迁移（利润往哪个相邻环节迁的实时读数）；④ 情景先验（龙头用真金白银给某个未来投票、抬高那个分支概率）。**但必须守四条纪律，否则退化成追热点**：(a) **资本洪流是双刃剑**——同一股涌入的资本既是近期需求信号、又是 24–36 个月后产能过剩的种子（资本周期顶点），强信号要**同时**抬高需求兑现（牛）与供给过剩回吐（熊）两个分支，不是只抬牛；(b) **反互补品陷阱**——龙头可能正为了把某环节做成又多又便宜、好让自己的核心环节收租（commoditize your complement），那"重投"反而是"这一节会被压成薄利"的**反向**信号，必须问『它是在这一节创造价值，还是在把它商品化为自己服务』；(c) **公司的赌注 ≠ 产业的未来**——龙头押某赛道常是买期权对冲（如 NVDA 押量子），信号是假设、不是确认；(d) **单源偏差**——一家是一个视角，要看是否多家（超大厂 / 竞品 / 链上玩家）资本都指向同一处，多家共识才够强。**结构化落地**：跨公司聚合见 dashboard「资本投向热力榜」（`refresh_dashboard.py` 扫所有 layout.json）；接进具体链的情景证据见 `chains/<slug>/chain_decision.json` 的 `layout_signals` 字段（每条带双刃读法 + 关联到哪条 prediction，复盘时一起检验）。

## 闸门①交付物规格（产业链图谱 + N 个候选赛道）

1. **产业链图谱**：价值锚 → 全链拆解（**含电力底座、软件生态两条**）→ 每一节的五层体检摘要（创造 / 占有 / 护城河+久期 / 资本周期象限 / 是否被定价）。利润池（收入 vs 利润背离）、当下卡脖子、资本周期象限要能一眼看到。
0.5 **开篇两节必含（2026-06-11 硬化——商业航天/锂电首版漏了、用户点名后补齐为三链标配）**：
   - **「这条链的底色」**：一段提纲挈领的链级定性（这是什么生意、钱现在处于资本周期什么状态）+ "所以这一关的重点是三件事"结构化卡片 + **β 风险框**（悬在整链头上的需求/历史地基风险 + 一句纪律）。底色是读者的第一锚，没有它后面全是细节没有判断。
   - **「第一性原理：这条链在交付什么」**：①**价值锚**（整条链为什么存在的那一两个数字；若当下买单者不按价值锚走——如国家意志/政策驱动——必须在锚框里写明）→ ②**分层钱流可视化**（上游到下游逐层、每环节标 最肥 rich / 中 mid / 苦力 thin，**判级必须转译自 nodes.json 节点卡的 capture/rent_or_moat、先写进 map_tier 字段再渲染**；图例注明本链档位轴语义 + "不跨链比色"）→ ③**横切层带**（贯穿全链、解释"利润为什么不按物理重要性/BOM 占比分配"的那一层：AI 链=CUDA 软件生态、商业航天=国家与星座方的双重权力、锂电=加工费定价模式+地缘供需错位）→ ④那把刀（原理上必须 vs 当下技术选择）与拆链边界论证。
   - 渲染语义纪律：分层图颜色只表"当下占有快照"，**久期另说**——"已兑现"与"持久"是两个判断，限定词（大规模/口径/巨型）是判断的一部分、渲染层一个字都不许丢。
   - **判断节的呈现格式（2026-06-11 用户反馈"太简略晦涩"后定型，必守）**：「那把刀」与「价值被谁占有」两节不许写成压缩段落——格式＝**先用白话讲清判别工具本身**（那把刀：原理必须 / 当下技术选择 / 必须但无壁垒 三种刀法；占有：租金三问 必要吗→稀缺吗→占有得住吗 + 三问全过且持久=占有、只过前两问=租金、只过一问=苦力），**再逐环节表格体检**（占有表四列：环节 / 三问体检（每问给✓✗和证据数字）/ 久期与威胁 / 判定）。占有节是闸门①最重的判断、标题就写明"本页最重的判断"；推理过程要摊开给读者看、不许只给结论。
1.5 **需求台账**（2026-06-10 新增、必含）：自下而上（单位需求×渗透×替换周期 → 各环节收入池）与自上而下（capex 总盘/出货统计）两向核算并交叉，对不上 ≥ 一倍即红旗当场解释；母变量钉成可证伪预测进 `chain_decision.json`。
2. **N 个候选赛道 / 核心零部件 scorecard**（端给用户选的那张清单）：每个候选含——
   - 它在链里**哪一节**
   - **价值创造**分（利润池地位 / ROIC−WACC）
   - **价值占有**分（租金三问 / 议价权 / 可占有性）
   - **护城河 + 久期 CAP**
   - **资本周期象限**（扩张顶部 / 出清底部 / 整合纪律）
   - **价值是否持久**（结构护城河 vs 短缺顶点周期租金；个股是否被定价留给第一阶段）
   - **这一节由谁占据**（A股 / 美股代表玩家、集中度，仅作结构事实指路，**不做任何估值与买卖判断**）
   - **一句话：为什么值得研究**（最好是"我和市场看法不同在哪"）
   - **该盯的领先指标**（2–5 个可定期联网取的高频数列）——**缺指标列＝交付不合格**（2026-06-10 硬化：曾在 AI 链 scorecard 里漏交付，指标必须同步进 `indicators.json`）
3. 形态：**判断与数字先落结构化文件（`nodes.json` + `indicators.json`），页面是渲染层**（2026-06-10 知识形态铁律）；可交互图谱（节点=环节、挂公司）随后包上，复用第一阶段 explorer 的做法。

## 闸门②③（成本法 + 选股，衔接）

- **闸门②·成本法**：用户选中某赛道后，把该环节的产品拆成**成本 / BOM 堆栈**，看价值具体压在哪个零件、哪种材料、哪道工序——图谱定位到环节，成本法钻进环节。
  - **BOM/成本栈双源纪律（2026-06-10）**：拆解类数字（成本占比/单机价值量/交期）口径方差极大——承重数字要两个独立来源互证；只有单源就显式标"单源 + 置信度"；成本栈一律给区间、不给单点。
  - **适用边界必填节（2026-06-10，中美分叉教训泛化成规格）**：每个闸门②结论页必须有一节**适用边界**——这节的价值由**哪个市场的需求**撑、在什么**要素价格**（气/电/原料/人工）与**制度环境**（电网体制/管制/补贴/贸易壁垒）下成立、时间窗多宽。要素成本敏感的环节（能源/电力/材料）**默认做中美分叉**；判断"持久价值"之前先回答"这是谁的命题"。（来历：电力底座曾把美国页岩气经济账全球化，被用户两轮质疑戳穿。）
  - **替代威胁时间表（2026-06-10）**：被判为持久/半持久的环节，配一张带日期的 S 曲线威胁表（威胁 / 该看到的信号 / 大致时窗），钉进 `nodes.json` 的 `threat_timeline`、由季度 checkpoint 跟踪——替代风险要有日历，不能停在一句"远期可能被颠覆"。
  - **铁律（2026-06 血的教训）：闸门②不能只拆成本和价值占有（一到三层），必须同样跑第四层（资本周期 / peak 校准）和第五层（结构护城河 vs 周期租金）。** 卡脖子是周期租金、不是持久护城河——租金会被新增产能 + 替代技术 + 买方反制吃掉；成本栈里最肥的环节，往往正是周期最顶点的环节。只做成本拆解会得出"价值在最卡脖子的环节"，而那一节的厚利润可能大半是短缺顶点租金、产能墙一落成就回吐。每个环节出结论前过四问：① 卡脖子是结构壁垒（工艺 / IP / 良率 / 关系），还是暂时产能稀缺？② 未来 24–36 个月有多少新增产能在路上（扩产 capex 明牌直接查得到）？③ 有没有替代技术 S 曲线在逼近、价值正往哪迁？④ 最大买方能否前向整合 / 扶二供？四问全中＝周期租金、降级；只有供给扩不出来 + 替代绕不过 + 买方动不了，才是持久结构价值。**全程在环节层判断、不碰个股**——"好环节 ≠ 好股票"成立，但"这只股票贵不贵、会不会像 Wolfspeed 那样卡脖子 owner 照样归零"，是第一阶段单股工具的活，不在闸门里做。
- **闸门③·选股 = 交接给第一阶段**：闸门锁定值得深析的环节后，把该环节的公司送进第一阶段单股工具，用四柱 + 反向 DCF 选标的。**这一步不在闸门里做**——闸门的产出止于"价值在哪个环节、是否持久"，选哪只个股、贵不贵是单股工具的事。
  - **铁律（2026-06 血的教训）：交接区列"这个环节有哪些上市公司"时，必须先派一个独立 agent 联网核查这份占位者清单。** 把每个环节的 A股 + 美股占位者查全（补漏龙头）、逐个核对代码（防张冠李戴）、剔除只蹭概念的错配、标清谁是真龙头 / 纯不纯。凭记忆枚举上市公司极易漏（漏过 A股单晶叶片的万泽 000534）或错（把代码写成毫不相关的另一家公司）；连核查 agent 自己都可能把代码搞错（时代电气是 688187、不是 688008），所以代码还要再复核一遍。这是质检关延伸到"选公司"这一步：闸门判环节靠推理，列公司靠联网核查、不靠脑子。

1. **沉淀（每次出闸门结论后）**：把链里**可证伪**的判断钉进 `chains/<slug>/chain_decision.json`——除 `key_judgments`（判断+watch+review_by）外，**必含 `predictions` 四元组**（指标+阈值+期限+查证处，status: open/hit/miss/unresolved）与 `next_checkpoint`（季度）；每条预测挂到 `indicators.json` 的具体指标。

## 工程铁律（页面自包含——踩过坑）

- **产业链页面必须自包含：CSS / JS 全部内联。** 否则 Safari 用 file:// 打开时加载不了父目录 `../_shared/` 的资源、整页没样式（第一阶段交互器全内联就是这个原因）。可编辑的共享源在 `chains/_shared/{chain_ui.css, glossary.js}`（术语浮窗在 glossary.js）；**改完共享文件必须跑 `python scripts/inline_chain_assets.py`**——它认页面里的 `<style id="chain-ui">` / `<script id="glossary">` 标记、把最新内容重新烤进每页（可反复刷新）。
- 每条链一个目录 `chains/<slug>/`，标准文件：`chain.json`（喂仪表盘卡：`gates` / `gates_done` / `selected` / `pages`）+ `chain_decision.json`（判断+predictions+next_checkpoint，喂 review.py 与值班台）+ `nodes.json`（节点卡真相源）+ `indicators.json`（领先指标与季度数据点）。术语浮窗别 linkify 标题类元素（flex 容器会被切乱，已排除 h1 / .sec-title 等）。

## 红线 / 常见错误

- **别把"物理必须"当"能赚钱"**——必须 + 供给受限 + 可占有，三者缺一不可。
- **别用毛利率当利润池度量**——用 ROIC − WACC；高毛利的资本黑洞照样毁价值。
- **别静态地把利润记给当下卡脖子环节**——卡脖子是租金，会被扩产和国产替代消解，要判断持续期。
- **别只画线性链漏掉生态**——互补者 / 平台 / 谁商品化谁，常常才是利润归宿的真因。
- **别漏电力底座**——AI 数据中心当下真正的硬约束是电（并网排队），不是芯片。
- **别在闸门里做个股**——环节好 ≠ 公司好，但"公司好不好"由第一阶段单股工具判（四柱 / 反向 DCF）；闸门不碰个股估值与买卖名单。
- **别跳过第五层就吐候选**——没判"这环节的厚利润是结构护城河还是周期顶点租金"，工具就退回"画地图"；注意这是环节层判断、不是个股估值。
- **国产替代别只写机会面**——它同时是供给侧内卷冲击。
- **查不到就说查不到**——免费联网有边界，标出来，绝不假装覆盖全了。
