# 技能：理解生意（CEO 视角）

## 这个技能要解决的问题
在做任何估值之前，先像这家公司的 CEO 一样真正看懂这门生意。真正的价值投资，绝大部分时间花在“读懂生意”，
而不是算 DCF。看不懂的生意，再低的市盈率也只是一个数字。

本技能的产出**不是对 10-K 的摘要**，而是对“这门生意到底是怎么回事”的重构——
写得像在给一位刚上任的 CEO 做交接简报：这个行业到底怎么玩、我们到底怎么赢、我们到底哪里脆弱。

## 核心纪律
- **行动胜于言辞。** 真实的文化与战略，从资本配置历史、过往决策、对待客户/员工/股东的方式去判断，
  而不是从“我们的价值观”这类口号去判断。
- **看激励。** 想知道各方会怎么做，先看他们被什么激励——客户、竞争对手、供应商、管理层各自的激励是什么。
- **诚实面对“看不懂”。** 看不懂不是失败，是信号：要么去补研究，要么这门生意在能力圈之外，应当放弃。
- **桌面下的规则往往不在 10-K 里。** 10-K 是经过公关处理的公开文件。真实获客逻辑、管理层真实想法、
  企业文化，需要靠委托书、致股东信、电话会议、外部资料（联网检索）来补全。

## 反成见铁律（最高优先级 · 每次分析开头自检）

> 来历：曾因带成见，把一家"净现金 + 稀缺资产 + 控制权题材"的公司，错读成"治理黑幕 + 资金危机 + 投机泡沫"。这几条是为防止同类错误立的硬规矩，**优先级高于本文件其他所有内容**。

1. **不带预设结论、不套模板。** "陷阱 / 泡沫 / 伟大公司 / 该避开"这类标签都是**成见篮子**。结论必须从证据一条条长出来，**绝不能先有结论再找证据**。开分析前不预判这家公司是好是坏。

2. **每个红旗，先写"最善意的解释"再下判断（steelman）。** 看到任何负面信号（存款异常、业绩变脸、现金骤降、关联交易、核心业务下滑……），**强制先问：如果这其实没问题，最合理的解释会是什么？** 去公开资料里查这个解释能否成立，再决定它到底是不是问题。把"最坏解读"当默认，是最大的错误来源。

3. **一次性 ≠ 经常性。** 任何异常盈亏，先查它是不是一次性事件（诈骗损失、处置损益、补助、减值、汇兑）。**剥离一次性后再看主业**。把一次性损失当成"业绩变脸 / 造假嫌疑"是典型误判。

4. **真实家底要合并算，别只读一行。** "现金紧张"必须看 **货币资金 + 交易性金融资产(理财) + 大额存单 − 有息负债** 的合计，不能只看"货币资金"那一行——钱常常只是从活期挪进了理财。先确认是不是真缺钱，再谈"资金危机"。

5. **周期低谷 ≠ 结构性衰退。** 核心业务某年大幅下滑，先判断是**需求/订单的周期波次**（机型切换、行业去库存）还是**护城河塌方**。前者会回来、后者不会——结论完全相反，必须用下文的行业"游戏规则"去区分。

6. **均衡，不是手软。** 每个问题都同时给"减分项"和"缓释 / 加分项"；引用他人主观评价（尤其负面的）要标明"这是某方观点、非客观定论"。**均衡是为了准确，不是为了客气**——一边倒的报告通常是没看全。

7. **成见藏在用词里，不只藏在结论里。** 哪怕每个红旗都写了善意解释，**一句话主旨、执行摘要、小节标题、对管理层的人格标签**仍可能在偷偷定性。禁止用"凑规模 / 圈钱 / 偏门 / 赌徒型 / 陷阱 / 泡沫 / 伟大公司"这类带情绪的标签概括公司或管理层；把**动作中性地描述出来**（"用收购和新建配置第二增长曲线""连年投入、尚未转正的新业务"），让读者自己判断。需要批评时，批评**具体能力**（资本配置弱、内控在补课、缺有机增长引擎）并给机制证据，**不给人格定性**。**主旨句同样要 steelman**——一句话概括里也不许一边倒。检验：把你的主旨句换成最善意但仍诚实的措辞，结论会不会变？会变，说明原措辞带了成见。

8. **防乐观成见——结论偏正面时同样狠（2026-06-09 立、2026-06-10 进铁律清单）。** 当结论是"便宜 / 有安全边际"时，专门查乐观偏移：① 熊市举证要铺得和牛市一样具体（别牛市有机制有画面、熊市一句带过）；② 别用"免费期权 / 赔率偏上行"这类轻快措辞把高度不确定、可能多年不行权的东西说得像白捡——明写到期日不确定、代价是机会成本与低分红；③ 别把未核实的数喂进估值再据此下结论（可精确查的必须钉死）；④ 多空举证门槛对称。价值陷阱（便宜但无人释放价值而长期不涨）是偏正面结论最该写厚的风险。（来历：000009 初稿被防成见关逮到 4 个 🔴。）

## 两个视角

### 一、对外视角：这门生意在市场上怎么活、怎么赢、怎么赚钱
1. **它到底在做什么** —— 用一个聪明的 12 岁孩子能听懂的一段话讲清楚：卖什么、卖给谁、解决了什么问题。
   如果讲不清楚，这本身就是“超出能力圈”的信号。
2. **钱到底从哪儿赚** —— 真实的盈利引擎，常常**不在收入最大的地方**（会员费 vs 商品、刀架 vs 刀片、
   浮存金……）。搞清楚利润的真实机制，而不只是收入构成。
3. **行业的游戏规则**
   - **明规则（桌面上）**：行业结构——竞争烈度、买方/供应商议价权、进入壁垒、替代品威胁（波特五力的实质）。
   - **潜规则（桌面下）**：客户到底**因为什么**留下来？转换成本高、是默认选项、是关系绑定、是习惯、
     还是真的没有更好的去处？——这个答案，就是护城河本身（或它的缺席）。

### 二、对内视角：这门生意作为一个组织是怎么运转的
4. **组织架构** —— 业务怎么切分（事业部 / 地区 / 产品线）？决策权集中在哪里？
   这套结构暴露了什么战略意图和管理哲学？
5. **怎么管理的** —— 管理层是谁、出身、过往战绩；尤其是 **资本配置的历史记录**
   （回购的价位、并购的成败、分红与再投资的取舍）——这是评判管理层最看重的一点。
   还有薪酬与持股结构：管理层的利益和股东是否一致？
6. **企业文化** —— 靠**行为**推断出的真实价值观与做事方式。线索：员工流动率、创始人基因是否还在、
   长期主义还是季度导向、对待客户和员工的方式。文化决定了在没人盯着的时候，组织会怎么做决定。

### 收口
7. **我还没看懂的部分** —— 诚实列出现有资料没能回答的问题。这份清单直接指明下一步该去查什么，
   也是判断“是否在能力圈内”的依据。

## 工作方式
- **动手前先读 `reviews/LESSONS.md`（机构记忆 / 教训库）**——把过去踩过的坑用上，这是工具"越学越智慧"的回喂环节。
- **第一步先判原型（2026-06-10 新增）**：读 `reviews/ARCHETYPES.md`，给这家公司贴 1-2 个原型标签（写进 decision.json 的 `archetype`），把同型判例的结论与易犯错调出来并排对照再深读；现有原型装不下就新开一条。原型是检索工具、不是结论模板——反成见铁律仍然最高。
- **写报告前必读 `skills/report-writing.md`（写作铁律：展示别断言、一章一章深挖）**——这是报告质量的最高标准；结构按 `templates/report-template.md`。**报告写水过、被用户连批两次，不能再犯。**
- **输入**：`analyses/<TICKER>/filings/` 里的 10-K 与委托书原文；`analyses/<TICKER>/financials/` 里的结构化财务数据。
- **补全**：第 4–6 点（组织 / 管理 / 文化）在 10-K 里往往缺失——主动联网检索管理层访谈、致股东信、
  电话会议纪要、第三方评价等（交互式会话里联网免费）。
- **唯一产出：`<TICKER>_公司完整报告.md`（机构级深度报告，追求完整度、不框定页数）**。用户 2026-05-31 **删掉了 dossier 和 memo 两个模块**——以后只要一份非常完整的报告 + 估值交互器，别再生成 dossier.md / memo.md。
  - 给完全不懂这家公司的人通读、且自成一体。**严格按机构研究报告的章节结构写**（骨架见 `templates/report-template.md`）：每章先一段**执行摘要**、再**正文详情**；穷尽地讲透 业务概述 → 发展历程 → 行业与竞争格局（含"游戏规则"）→ 商业模式与盈利引擎 → 资本配置 → 组织治理与诚信 → 财务全貌（正向+反向两视角、数据→管理层视角→管理与文化三层）→ **投资分析与估值（替代原 memo）** → 风险全景（含风险矩阵）。
  - **判断标准：把这门生意彻底讲透。该多长就多长、不设页数上限。绝不写成"放大版摘要"——每个业务线、每笔资本运作、每项治理与风险都要深挖到具体数字、具体公告、具体证据**，像专业尽调报告那样。这是工具最核心的交付物，不允许敷衍。
- **边界**：这一步专注”理解”；理解 + 能力圈判断写完后，**自动进入第 2 层估值**（不再停下问用户——用户 2026-05-31 改）。
