> 三条铁律：
> 1. **代码供数、我下判断**——卡里的数字（业务速览/总账速览）由代码从 `segments.json` / `financials.csv` 算，判断（脊梁/护城河/暗线/双面判读…）由我写进 `valuation_inputs.json` 的 `chN` 块。
> 2. **卡（执行摘要）在上、正文在下、同一个框**——`render_explorer` 把 `chN` 卡嵌在该章正文顶部；报告 `.md` 里那章的 `### 执行摘要` 小节会被 `_strip_exec_summary` 剥掉（卡承担、正文里不重复），但 `.md` / PDF 源保留。
> 3. **标准进代码闸门、不靠自觉**——`check_chapters.py` 校验已定标准的章"卡填没填全、报告脚手架写没写"；`qc_gate` 出 PDF 前硬拦、`render_explorer` 渲染时报缺。每新定一章，就把它加进 `REQUIRED_CARDS` / `CHAPTER_SCAFFOLDS`。
> 4. **正文先写、卡片后提炼**——卡是正文的执行摘要，正文必须先写到位、过质检，卡才从成稿正文提炼。先画卡是本末倒置，会导致论述被压缩、出处没落实。
> 5. **平台型公司逐块走**——主业集中的公司，商业模式/游戏规则/市场往哪走各一条；跨界多板块的平台型公司，这三样都逐块分析（每块是一个独立市场），只有综合判断（护城河落在哪、价值集中、决胜变量）是公司级。

## 内行门道（游戏规则）怎么挖：五步套路

游戏规则＝这个行当内行才懂的玩法、外行看不出的那种，解释这门生意到底怎么赚钱、为什么是这种财务特征——它不是看新闻就懂的竞争风险（集采要降价那种，归市场方向那一节）。先立商业模式（钱怎么转、谁掌握定价），门道才有附着点；再按五步挖、且每条带出处：

1. **公司自己说了什么**——穷尽年报/招股书/公告/问询函，钉死公司级事实（供应商集中度、客户结构、收入构成、自认的风险）。最硬、最可追溯。
2. **公司系统性回避了什么**——门道常在它躲的、不在它说的（如大东方把卖药说成全发育诊疗、不提适应症、不拆剂型）。回避处就是信号。
3. **翻上下游和外部，把缺口补成带出处的事实**——上下游龙头财报、行业研报、监管/集采/医保/药监文件、央媒。看大东方医疗，上游金赛/长春高新的财报是最真的镜子。
4. **每条标出处层级 + 承重三角验证**——公司披露 / 外部权威源 / 我的推断三层分清；承重判断至少两个独立源对上才写死，标推断的绝不冒充事实。
5. **外行以为对内行知道的落差自检**——一条门道，只有外行会漏看或看错才算门道；看新闻就懂的踢回竞争风险。

每条门道的写法：商业模式先用 bullet 把钱流（进货/触达/获客/黏客/变现/成色/价值归谁）拆透，再推门道；门道指向藏起来的风险（下行）还是藏起来的价值（上行），认知差落在这上面。**门道挖掘的样板＝600327 第三章增高针那块**（适应症擦边长在医保之外、弃标把高利润剂型留院外躲集采、公司年报自承快消触达，三条都有外部一手出处）。

## 写作纪律（正文，所有公司所有章都适用）

正文是给读者看的干净分析，不是我做分析的过程实录：

- **不写后台/过程话**——不写"逐条带出处、单独判、我挖出来"，不写"这是外行看不出的门道"这种提醒读者它难看出的话，不写为结构选择做的辩解。让读者从分析里自己体会到门道。
- **出处留幕后**——采集时的精确定位（年报行号、外部链接）不进正文；正文只在能加分处自然带一句来源（公司年报、央媒、业内、上游财报）。出处底子另存、可随时回核。
- **不用引号**——除非逐字引原话。
- **不加粗**——只标题/表头加粗。
- **戒"不是……而是……"**——这是 AI 写作的拐杖（靠先否定一个稻草人来制造强调）；直接把话说出来、让对比从事实并置里自己出来。
- **戒一切否定开头/定义式否定**——和上一条同源：先说它不是什么、不能怎样，再说它是什么（"X 不能被简单归进 Y""它不长在最大业务上""不能只看…要看""不取决于…而取决于…""不在于…而在于…"）。正面直说它是什么。带实义的事实性否定（医保不报销特发性矮小、门店困在无锡一城）保留——戒的是用否定垫一句制造强调的修辞，不是消灭所有"不"字。（用户 2026-06-29 点名。）
- **展示别断言**——每个判断后跟具体数字、机制或证据。

## 怎么给一章定标准（流程）

定一章 = 定四件事：① 这章的**承重判断**（必须交付的那一个判断）② 用什么**呈现**承载它（卡的形态）③ **卡片字段** ④ **数据分工**（代码算什么、我写什么）。外加一条**正文深度线**（这章正文的硬标准）。定完落地：

- `valuation_inputs.json` 加 `chN` 块（字段＝我写的判断）；
- `render_explorer.py` 加 `build_chN_card()`（代码供数）+ 模板 `chNCardHTML()`（渲染）+ `renderReport` 在 `i===N-1` 那张卡顶部嵌入；
- `check_chapters.py` 的 `REQUIRED_CARDS` 加这张卡的必填字段、`CHAPTER_SCAFFOLDS` 加这章正文必含的表；
- `report-template.md` 对应章注明"必出 X 卡 + Y 脚手架"。

## 第二章 历程判断卡（已定）

- **承重判断**：**看行为不看口号**——从历史动作里读出"控股股东/管理层会怎么对待这个平台"的行为模式 + 会重演的暗线（或清晰的期权）。对资本运作平台型标的，历史的预测力比任何财务比率都强。
- **标尺**：超卓航科（688237）深版《发展历程》——执行摘要先立叙事弧、看行为读管理层、植入峰值坐标、剥口号纠外界叙事、一次性 vs 经营分开、控制权/期权单列、总账表双面收束。
- **呈现（卡的 6 槽位）**：
  1. **历程脊梁**（`spine`）——一句话把整段史拉直（如 600327："国资老字号→均瑶资本运作平台→减法/加法/收缩"）。
  2. **分段时间轴**（`phases`）——2–4 段，每段 `{label, period, kind, text, tags[]}`；`kind`=neutral/warn/bad/good/eng 决定配色（中性/要盯/利空已兑现/正面/战略）。
  3. **看行为读出的模式**（`revealed_behavior`）——从动作读管理层/控股股东行为模式（钱用在哪、资本纪律、关联交易倾向）。
  4. **会重演的暗线 / 清晰的期权**（`darkline{label, kind, text}`）——按公司二选一填（暗线如 600327 抽血、期权如超卓控制权题材）；`label` 跟着改。
  5. **峰值坐标**（`peak_anchor`，可选）——历史利润/规模峰值当基准。**口径要对**：如 600327 营收峰值在汽车全并表的 2020（¥79 亿），归母峰值在 2021（含汽车处置一次性收益），别混。
  6. **总账速览 + 双面判读**（`scorecard_read{exposes, hidden_strength}`）——多年营收/归母/经营现金流（代码从 `financials.csv` 算）+ 一句"数字暴露什么"+"没讲完的底气"。
- **数据分工**：总账速览数字＝代码（`build_ch2_card` 复用 `build_history`，取最近 6 年 营收/归母/经营现金流；财务里没有"扣非"概念，扣非放正文手抄全表）；其余判断＝我写进 `ch2` 块；`peak_anchor` 由 block 提供（是判断、口径要核）。
- **闸门必填**：`spine, phases, revealed_behavior, darkline.text, scorecard_read.exposes, scorecard_read.hidden_strength`。
- **正文深度线（7 条必做，写报告第二章时照此、过 depth/insight 关）**：
  ① 执行摘要先立叙事弧（分清晰 N 段），不平铺流水账；
  ② 历史沿革大事记表（时间/类型/大事，从家族/上市前到最近一季、每行带具体数字）；
  ③ 逐段按命名阶段展开（不机械按年）：每段"做了什么动作[剥口号]→为什么→暴露什么"；
  ④ 植入峰值坐标，后续起伏对照它读；
  ⑤ 剥口号 ＋ 纠正外界错误叙事（认知差）＋ 一次性 vs 经营分开；
  ⑥ 看行为不看口号：从资金部署/资本纪律/关联交易倾向读管理层；
  ⑦ 总账表双面收束：多年表 +「暴露的几个问题」+「没讲完的底气」+ thesis 级收束。
- **报告脚手架（闸门校验）**：第二章正文必含 **≥2 张 markdown 表**（大事记表 + 上市以来总账表）。

## 第三章 行业判断卡（已定，标尺=超卓 688237 深版）

- **承重判断**：这家公司在什么竞争结构里、护城河有多真多持久、价值集中在哪块、决胜变量是什么。核心动作＝推出每门生意的游戏规则（内行门道，见上面五步套路），证明它怎么赚钱、又脆弱在哪。
- **正文结构（平台型公司逐块走）**：公司级开篇（格局总览 + 竞争结构表，**表里直接列每块的主要对手**）→ 逐块深挖（每块一个完整单元：竞争位置 → **竞争格局**[对手是谁、份额、谁强谁弱、这家排第几——这是"竞争格局"四个字真正要交付的内容] → **价值归谁**[这条产业链/价值链里谁拿走钱、谁有定价权，是竞争位置的落点] → **竞争门道**[五步套路、带出处] → 这块市场往哪走）→ 综合（谁掌握价值对照 → 核心护城河 → 价值集中 vs 压力 → 决胜变量 + 小结）。主业集中的公司则不逐块、各一条。**落地样板＝600327 第三章（三块各按此结构走、竞争格局带对手与份额）。**
- **三章/四章分界（门道分两种）**：第三章往外看市场和对手，第四章往里看自家利润机器。一条尺子：讲市场结构/对手/价值链里谁拿走钱 → 三章；讲这家自己怎么把收入变成利润和现金 → 四章。所以**钱流机制（进货/触达/变现这套"怎么赚钱"的拆解）、盈利门道（如百货二房东抽成、三凤桥自营吃掉溢价）归第四章盈利引擎**，第三章不写；第三章只保留**竞争门道**（长在市场结构/价值链上的门道，如医保外擦边、集采弃标、地域护城河=天花板）。门道因此分两种：竞争门道→三章、盈利门道→四章。（用户 2026-06-29 逼出：三章一度把盈利机制全堆进来，正名是"行业与竞争格局"却没写竞争格局。）
- **市场往哪走（必做、要可证伪）**：判方向、不判快照——这个市场朝哪走、为什么、结构在怎么移（美光教训：只判当下结构里的价值、没判市场往哪走，会错过大涨或踩进塌方）。平台型逐块判。**交付标准＝一段趋势数字（多年、证明在往哪走、不是一张快照）＋一个有日期的前瞻催化剂＋出处**；戒写成不带数字的一句感觉（"经营缓降""需求稳定"这种断言）。验收：读者能据此自己核实方向判得对不对。（用户 2026-06-29 逼出：往哪走原来三块都靠感觉断言、无数字无出处。）
- **卡（精炼版，门道留正文）**：`ch3` 块＝`spine`（格局脊梁）/ `segment_dim` / `segments{业务:{industry,structure,position,kind,control,control_kind,control_note,market}}`（竞争结构 + 谁掌握价值 + 该块市场方向）/ `moat` / `value_concentration` / `pressure` / `key_variable`。卡片坐在正文之上、正文就在下面，所以卡只做精炼判断速览，门道细节靠正文。
- **数据分工**：竞争结构地图的营收/占比＝代码（`build_ch3_card` 复用 `segments.json`，同第一章机制）；竞争判断＝我写进 `ch3` 块。
- **闸门必填**：`spine, segments, moat, value_concentration, pressure, key_variable`；报告第三章必含 **≥1 张竞争结构表**。

## 第四章 经营判断卡（已定，CEO 经营说明书：商业模式 + 游戏规则；落地样板=600327）

- **承重判断**：假如读者是新接手的 CEO，让他读完能讲清楚——这几门生意分别是门什么生意、怎么运转、明规则暗规则各是什么、每门怎么玩才能赢、以及哪门是真正赚钱的发动机（定性、不摆财务）。**最高优先级＝商业模式 + 游戏规则明暗的详细论述**（标尺＝原 600327 第三章那套：钱怎么转逐条拆 + 游戏规则明一条暗一条、讲到外行看漏的那层）。
- **正文结构（平台型逐门走）**：① 三门生意总览表（业务 / 本质是门什么生意 / 客户是谁·卖什么 / 怎么才算赢 / 赚不赚钱）→ ② **逐门拆解（全章重头）**：每门走 你接手的是什么 → 怎么运转（钱和人怎么转：进货/触达/获客/黏客/变现，作为经营动作、不是毛利）→ 游戏规则·明（这门生意明面上怎么运转、比什么）→ 游戏规则·暗（外行看不出、却决定生死的几条：监管/上游/替代/模式陷阱等）→ 怎么玩才能赢（决定这门生意做不做得好的关键动作）→ 赚不赚钱（一句话定性、不摆财务数）→ ③ 三门合起来看（哪门真赚钱的轻量结论 + 价值落在哪、该往哪使劲；末尾一句把财务全貌指向第七章）。主业集中的公司则不逐门、各一条。
- **卡（精炼版，明暗门道细节留正文）**：`ch4` 块＝`spine`（经营脊梁：几门生意各玩各的 + 哪门赚钱）/ `segment_dim` / `segments{业务:{essence,play,role,role_kind}}`（essence=本质做什么生意、play=怎么玩/游戏规则明暗一句、role=赚不赚钱定性、`role_kind`=eng/good/warn/bad/neutral 配色；revenue/占比 代码从 `segments.json` 算）/ `who_earns`（哪门真赚钱的轻量结论）/ `ceo_levers`（每门的决胜操作杆）。财务四柱在仪表盘、财务分析在第七章，卡不碰。

- **资产口径情景要给判断带、不是单点（用户 2026-07-01 追问"为什么是具体数字不是模糊区间"）**：资产口径（`value_per_share`）公司，`valuation_inputs.json` 每个情景除 `value_per_share`（中位代表值、驱动安全边际/到熊到牛距离，与报告口径一致）外，**补 `value_low`/`value_high`（判断带上下沿）**——交互器把每个情景显示成"¥2.60–2.70"带、整条价值区间读作下沿到上沿（大东方=¥2.6–3.8），呼应"模糊地对、每个情景本身也是判断带、不是精确点位"。**中性最窄**（它是账面÷股本的硬锚、精确是诚实的），熊/牛更宽（估的判断带）。样板 600327：熊 2.6/2.65/2.7、中 3.1/3.15/3.2、牛 3.7/3.75/3.8。现金流折现口径的公司引擎按假设自动生成带、无需填。**安全边际仍锚在情景代表值（中位）上、不锚区间下沿**——保持和报告的 −16%/+19% 一致、不制造工具与报告打架。
