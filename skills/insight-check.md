# 技能：质检关·第五道防线 —— 洞察核查（insight-check，防"有事实没判断"）

> 来历（2026-06-19，用户拿 688237 深版对照 603358）：前四道质检管对账 / 数字真假 / 立场 / 事实深度（depth-check）——但一份事实很全、立场也中性、却通篇只在"陈述与组织事实、没有形成并论证一个价值判断"的报告，能全过前四关，依然不是用户要的"为寻找价值服务的深度分析"。这一关专查分析轴。
> **触发：出 PDF 前，在 depth-check 之后、作为第五道（也是最后一道）；🔴 清零才出 PDF。** 标尺＝688237《超卓航科》深版的分析密度。

## 总则

- **独立上下文**：insight-check agent 喂 ① 报告草稿 ② `skills/analysis-depth.md`（判据）③ 必要时原始材料（用于判断"这里本可以有认知差/价值解读、却漏了"）。**不喂作者的推理**。
- **它判的是分析、不是事实**：数字真假是 fact-check、材料用没用够是 depth-check、立场偏颇是 discipline——这一关只问一件事：**这份报告有没有形成并论证一个价值判断？还是只在深度地组织事实？**
- **只挑错、不改写**：逐项 + 逐章输出，主 Claude 据此回去做分析、重写。
- 防卡死规矩同全局：草稿可整篇分段读；要回原始材料判"有洞察没挖"时，grep + 小段读。

## 按 analysis-depth 的"七个动作"逐项查（这是全局，先过这关）

1. **核心论点**：全文有没有一句立得住、可记忆、有观点的 thesis？它有没有贯穿各章、被不断印证/精炼？还是只有一段松散的总结？（没有 thesis ＝ 🔴）
2. **数字的价值解读**：抽查 5-8 个承重数字，每个后面有没有"so what for value"的解读（数字 → 真正反映什么 → 对价值/护城河/久期/赔率意味着什么）？还是只陈述了数字和机制？（多数只陈述 ＝ 🔴；部分缺 ＝ 🟡）
3. **认知差（variant perception）**：全篇有没有至少一处明确的"市场以为 X、实际 Y、这个差是价值/风险"？反向 DCF 有没有讲清市场在为什么故事付钱、隐含什么假设？（一处都没有 ＝ 🔴）
4. **财务正反双视角**：财务章有没有"从数字反推这是一家什么体质、怎么管理、什么文化的公司"这层（反向视角）？还是只有正向的数据陈列？（没有反向 ＝ 🔴/🟡）
5. **价值阶梯 + 价值困在哪**：估值有没有摆出价值阶梯（资产价值/EPV/分部加总/成长）、并诊断"价值被什么困住、什么动作释放它"？有没有用"经营性回报率 vs 合并 ROE 背离"之类把"生意好不好"和"资本配置好不好"分开？还是只回答了"贵不贵"？（只回答贵不贵 ＝ 🔴/🟡）
6. **情景的故事性与主变量**：三/四情景是否各有名字、故事、关键前提，而非"扣非 × 倍数 × 概率"的机械三档？有没有点出牵一发动全身的主变量？（机械三档 ＝ 🟡）
7. **so-what-for-investor + 判断句**：分析有没有落到"对要决定买不买/收购的人意味着什么动作/赔率"？有没有可记忆的判断结晶句？（通篇只描述、无落点 ＝ 🟡）

## 逐章扫一遍（哪几章只在陈述事实、没在做判断）

对九章各判一句：这一章是"形成/论证了价值判断"（✅），还是"深度地组织了事实、但判断稀薄"（🟡/🔴）。重点盯财务章（有没有反向视角）、估值章（有没有价值阶梯+认知差）、业务/行业章（有没有把"它是什么生意、护城河多深、价值在哪一块"讲成判断而非描述）。

## 输出格式

- 七个动作逐条：【动作 + 评级 ✅/🟡/🔴 + 诊断 + 举例（草稿哪里做到了/哪里只停在陈述）】。
- 九章逐章一句：判断浓还是稀。
- 然后：① 整体评级（合格/不合格）② 全篇最该补的 3 处分析（不是补事实、是补判断——比如"这个数字本可解读成 X 价值含义""这里本可指出市场看错在 Y""估值缺价值阶梯诊断"）③ 一句话：这份报告离 688237 的分析深度，差在哪个动作上最多。
- **最后一行：通过 / 不通过（核心论点缺失、或多数关键数字无价值解读、或全篇无认知差 → 不通过）。**

## 流程（主 Claude 操作）

1. 草稿过完 fact-check + discipline + depth-check 后，起独立 insight-check agent（喂草稿 + analysis-depth.md）。
2. 收清单 → 对每处补的是"分析/判断"、不是"事实"（回去想清楚 thesis、找认知差、解读数字、做价值阶梯诊断）→ 重写 → 复跑直到无 🔴。
3. 反复出现的"有事实没判断"模式，升级进 `reviews/LESSONS.md` 与 analysis-depth.md。

## 配套铁律（写报告时就守）

- **先有判断、再码字**：动笔前先做 analysis-depth 的"四步"（定 thesis、找认知差、诊断价值困在哪、定主变量），把脊梁立起来，再写正文喂它。跳过这步直接组织事实，必然写成"有事实没判断"。
- **每个数字都欠一句"所以呢"**：写完数字停一下，补"对价值意味着什么"，否则就是罗列。
- **分析不外包**：采集 agent 给事实和行号；形成论点、找认知差、反推体质、做价值阶梯诊断，是作者必须亲手做的、最不可外包的一步。
- **报告独立、只比同行（2026-06-19 加查项）**：对照只对同行/竞争对手（评估竞争位置、相对估值、护城河深浅），每份个股报告独立成立、不交叉引用用户已分析过的其它个股当分析骨架（见 analysis-depth『报告独立性铁律』）。insight-check 扫到把对其它已分析个股的对照当骨架 = 🟡/🔴，要求拆成独立论证或同行对比。
