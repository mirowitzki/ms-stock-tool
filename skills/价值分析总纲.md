# 股票价值分析总纲（方法论母文档）

> 这是【MS股票价值分析工具】整套方法论的总纲——把散落在各 skill 文件、模板、教训库里的东西串成一条主线。
> 读这一份，就能知道"我是怎么分析一家公司的、靠什么纪律不犯傻"。每个模块末尾指向更细的专题文件。
> 数据时点会变，方法不变。先读这份，再读 `reviews/LESSONS.md`（踩过的坑），再动手。

---

## 〇、一句话概括这套方法

**人主导、工具辅助；代码算数、人下判断；先看懂生意，再分开回答"生意值多少"和"这个价格买不买"；给区间和概率、不给单一目标价；用独立的对抗性检查防自己的幻觉和成见；每分析一家就往教训库里沉淀一条，越学越智慧。**

它不是一台"算出目标价"的机器，而是一张**判断卡**：帮你把一家公司看透、把价值和价格的关系说清、把自己最容易犯的错堵住。

## 一、五条底层信念（不要挑战，这是地基）

1. **人主导，工具辅助。** 工具替你读资料、算数字、按框架梳理；最终判断是人的事。
2. **代码算数，Claude 判断。** 抓数据、解析、算 DCF/四柱/估值——全部交代码，免费且精确，**绝不用大模型做算术**。理解生意、判断护城河、评估管理层、写报告——这是判断密集、价值最高的部分，交人/Claude。
3. **看不懂就不估值。** 讲不出一个可信的生意故事，就在估值章里如实说"看不清/太难"，而不是硬估一个数。
4. **生意 vs 价格，永远分开答。** 好生意可以是烂股票（买太贵），脆弱生意再便宜也可能是陷阱。把"这门生意值多少"和"这个价格买不买"糊成一句话，是最常见的错。
5. **模糊的正确 > 精准的错误。** 给毛估区间 + 方向 + 主观概率，锚在治理和情景故事上；别追一个看似精确、实则虚假的单一目标价。

## 二、完整流水线（按顺序）

```
取数（纯代码） → 深读 → 写一份完整报告 → 过质检关 → 出交付物 → 复盘沉淀
```

最终交付物只有两个：**一份机构级完整报告（PDF）+ 一个估值交互器**。外加后台不显示的 `decision.json`（决策记录，供复盘）。

| 步骤 | 做什么 | 工具/产物 |
|---|---|---|
| 0 取数 | 招股书 + 近 5 年年报 + 高信号公告 + 财务/分部/季报 + 近 5 年月度股价 | `fetch_a_stocks.py`(A股)/`fetch_filings.py`(美股)/`fetch_prices.py` |
| 1 算硬数字 | 四柱真相源（ROIC/FCF/资本配置/生存/盈利质量取证） | `compute_metrics.py` → `metrics.json`（改完计算代码先跑 `test_metrics.py` 金标准回归） |
| 2 深读 | **先判原型（ARCHETYPES 调同型判例）**，再读招股书 + 近 5 年年报 + 高信号公告 + 联网补组织/管理/文化 | 见模块三、五、六 |
| 3 写报告 | 九章机构级、show-don't-tell、四柱嵌入、含估值章 | `<TICKER>_公司完整报告.md` |
| 4 质检关 | 代码对账 + 防幻觉 agent + 防成见 agent，🔴 清零才放行；**将行动/接近观察区的再加红队结论关** | 见模块七、`skills/red-team.md` |
| 5 出交付 | PDF + 交互器(valuation_inputs.json) + decision.json（含可证伪预测四元组/odds/premortem） | `render_pdf.py`/`render_explorer.py`/`refresh_dashboard.py` |
| 6 复盘 | 三类触发（新数据/到期/价格进观察区）→ 盲评先行 → 按 driver 记分 → 误差归类 → 登校准台账 | `review.py` → `CALIBRATION.md` + `LESSONS.md` |

**数据规模铁律**：上市 ≤5 年 → 招股书 + 全部年报；上市 >5 年 → 招股书 + 只读近 5 年。别想读 20 年资料、会消化不过来；聚焦深挖、别贪多。

**取数前必做**：先读 `reviews/LESSONS.md`（机构记忆）+ `reviews/ARCHETYPES.md`（判原型、调同型判例）——光记不回喂，就只是日记。

## 三、理解生意（估值之前的闸门）

详见 `skills/business-understanding.md` + `skills/moat-analysis.md`。

- **它卖什么、卖给谁、解决什么问题。** 逐个业务板块讲透：营收、占比、毛利率、同比、来源、谁在做（哪个子公司、持股多少）、谁是利润中心、谁在萎缩。
- **横跨哪几个行业、在每个里的位置。** 公司是规则制定者还是规则接受者？规则接受者很难有持续的经营性超额利润。
- **推导这门生意的"游戏规则"。** 护城河和财务特征是同一套规则的一体两面（高 ROIC 凭什么持续）。
- **看行为、不看口号。** 判断管理层与文化，优先看资本配置历史等"行动"，其次才是"言辞"。桌面下的规则不在 10-K 里——组织、管理、文化、真实获客逻辑，要靠委托书、致股东信、电话会、联网检索补全。
- **近期动作雷达**（详见 `skills/valuation.md` 第九条）：扫最近 6–12 个月 PR/公告/发布会，用四问法（剥口号取动作/收入机制+时点/落 5 年还是 6-10 年/反向 DCF 是否已被定价）反推故事和催化剂，但**不让 PR 定价**。

## 四、价值判断·四柱（生意好不好、扛不扛得住）

详见 `skills/value-judgment.md`。硬数字从 `metrics.json` 取（代码算），判断由人结合定性证据下、但必须引用这些数字。

1. **复利引擎**：ROIC 水平与趋势、**增量 ROIC（新投的钱赚不赚）**、再投资率/跑道、ROE。把 ROIC 接回护城河——这是复利机器，还是融化的冰？增量 ROIC < 资金成本＝过了黄金期。注意轻资产/ROIC 失真旗。
2. **所有者盈余**：报告 FCF vs **扣 SBC 后 FCF**、正常化所有者盈余、维护性 capex。**分清"GAAP 亏但现金为正"（会计假象）和"真烧钱"——看经营现金流符号**：经营现金流为正、亏损主因是非现金 SBC/减值＝会计假象（如 SITM）；经营现金流为负＝实打实失血（如 NVTS）。
3. **资本配置**：近 5 年每块经营现金流的去向（再投/回购/分红/并购/还债占比）。**回购要交叉核当年股价**（便宜时回购增厚、高位接盘毁价值）；并购看商誉堆积与减值；外加管理层激励结构（薪酬挂每股价值/ROIC 还是营收/规模、内部人持股）。
4. **生存**：净债/EBITDA、利息覆盖、流动比、一年内到期墙 vs 现金。**烧钱公司看现金跑道（净现金≠安全）；有净债 + 亏损＝最脆弱。** 别把"堡垒"这个词用过头——净现金里要扣全部有息负债（含短期借款），算严口径。

**横切·周期校准**：若 `cycle_calibration.peak_suspect` 被标旗（当前 ROIC/利润率是周期高峰），**必须做中周期归一化**——别用高峰利润率喂终值，把"周期转冷/资本开支见顶"写成核心 Bear。反过来，处在周期低谷时也别用低谷利润线性外推（那会低估）。这是对"AI 大周期不想想红利吗"的回答：用归一化防在高峰付全款、也防在低谷错杀。

**横切·核心 driver 四维分类**（放三情景前，做成一张表）：把利润拆成机械 driver（量×价−截流 / 分部加总），每个 driver 按四维分类——**可控/外生、结构/周期、持久/脆弱、是否已被定价**——再用公司真实动作验证。driver 的类型决定该走哪条 Track、给多大折现率、把哪个写成核心 Bear。每个 driver 同步进 `decision.json` 的 `drivers` 字段供复盘对账。

## 五、估值（分流 + 纪律）

详见 `skills/valuation.md`。

### Track 分流（先判定，写在估值章开头）
- **Track A**：成熟稳定 + 正所有者盈余 → 现金流折现（DCF）为主。
- **Track B**：未盈利 / 转型中 / 二元化 → 反向 DCF + 三情景，用未来稀释股数（计入 SBC/增发/可转债）。
- **Track C**：现金流持续为负 / 资产重 / 低 ROE / 价值在表外资产或特殊事件 → **DCF 无效**，改用 **资产地板 + EPV + 分部加总（SOTP）+ 特殊事件情景**。

### 通用纪律
- **不给单一目标价。** 永远给区间 + 主观概率分布（熊/中/牛）。每个情景＝故事 + 管理层应对 + 毛估价值区间。
- **base rate 先行（外部锚，2026-06-10）**：给情景定概率、给终值定成熟 FCF 利润率之前，先报 `reviews/BASE_RATES.md` 同类事件的历史频率，再论证这家为什么偏离；成熟利润率超同业历史最佳值必须单独论证。没有外部锚的概率是拍脑袋。
- **对手桌检查（2026-06-10）**：Bull/Base 情景写完，过一遍竞争对手/最大客户/供应商渠道/监管者的最优反应——反应之后故事还成立才算成立。把"没人还手"当隐含假设是 Bull 最常见的暗伤。
- **单位经济硬要求（2026-06-10）**：凡有披露，Bull 必须量×价×单位成本算得通；讲不出单位经济的 Bull 概率降档。
- **安全边际双口径（2026-06-10）**：头条并列①保守口径（现价 vs 中性下沿——最坏看错亏多少）②期望口径（odds 不对称度 + 5 年隐含年化，代码机械推导）；**概率加权中枢是期望值、不是目标价**。
- **三情景必须 steelman 多头。** 现价高于所有情景上限时，先把"市场到底看见了什么"补成一个完整的牛市情景（资产注入/平台化/re-rating），给低概率，别停在"任何情景都撑不起这个价"——那通常是没找全多头论点的信号。
- **反向 DCF：市场买入了什么故事。** 倒过来解：现价隐含多高的增速/利润率/成功概率？和最乐观情景比，是不是已经把完美执行提前买空。`reverse_dcf_commentary` 必填，verdict 颜色：`speculative_bubble`(🔴) / `stretched`(🟠) / `fair_with_bull`(🟡) / `fair`(🟢) / `undervalued`(绿)。
- **预测窗口**：头条用 **5 年显性** + 并列一个"延伸至 10 年"的参考值。两者差距本身是信号——差距小＝价值扎实不靠远期；差距大＝乐观押在最难看清的第 6-10 年，是 Bull 最易藏泡沫处。窗口越短终值占比越高（5 年常 ~85%），纪律来自把第 5 年后的稳态显性写出、而非塞进终值。
- **四柱 → 安全边际（头条）**：把四柱判断（生意好不好＝复利引擎+所有者盈余、管理层行不行＝资本配置、扛不扛得住＝生存）与价格合起来。**安全边际＝保守内在价值 − 价格，强调"我能看错多少还不亏本金"，不是精确 DCF 点。**

### 控股集团 / SOTP 的两个必做对（踩过坑）
- **SOTP 要按"结构修复 + 正常化"口径，别锚在低谷/当期薄利**：周期低谷的块先把收入正常化到中周期再给倍数；稳定盈利的子公司按盈利能力给正常倍数（只给 3-5×PE 几乎一定偏低）；稀缺/独家资质块给较高倍数。自检：认定有真护城河、却算出 SOTP ≤ 资产地板 → 多半锚错了低谷数或给低了倍数，回头修。
- **控股集团（母公司并表了上市子公司）的净负债口径**：**只扣母公司层面的外部净负债，绝不扣合并净负债**——子公司的债已反映在它自己的市值里，再扣一遍＝同一笔债算两次、NAV 严重偏低。母公司常是"融资管道"（借外债再转贷给子公司），对子公司放款会和外部债大致对冲。
- **资产型(NAV/SOTP) vs 盈利型(DCF) 对控股集团会系统性背离**：DCF（盈利）落在 ≈ 现价处、NAV（资产）更高，两者的差就是控股折价本身。主估值用 NAV/SOTP；交互器 DCF 当盈利口径交叉验证、commentary 写明背离＝控股折价；别硬把 DCF 调成 NAV。

## 六、A 股专属维度（必加）

- **扣非净利 >> 报告净利**：A 股估值一律用扣非，不用报告净利（教训：网宿、众合、银之杰都有显著差距；归母靠一次性坏账转回/政府补助/公允价值变动美化时，扣非才见主业真相）。
- **股东性质 + 政策风险**：实控人是谁、国资/民营、政策敞口。**无控股股东/无实际控制人的公司，把"谁来入主"当成估值的核心变量、不是花边**——价值释放的钥匙几乎一定是控制权落定（国资入主/老股东回归/引战投）这个外部事件，而非业务变好；情景和催化剂都要绕着它写。但要警惕：这个事件**可能很多年不发生**（价值陷阱）。
- **会计可信度判断**：主动找抬高账面利润的会计估计变更——**折旧/摊销年限延长必须跨年 diff 表本身**（别只信最新一年附注的"本年不适用"，延长发生在前某年、利润已被永久垫高）；减值是否足额；收入确认口径；研发资本化率。总结管理层口径时既看强调什么、也看系统性淡化/回避什么（资金效率、亏损子公司、应收占款、高杠杆）。
- **ST/退市预警清单**（任一出现必须显眼标注）：审计含"持续经营存在疑虑"；证监局警示函/监管函；扣非连续 3 年负；应收账款 + 存货占流动资产 ≥ 70%；银行存款被划转、关联方异常交易、募集资金违规。注意创业板财务类退市的组合条件（扣非孰低为负 **且** 营收 < 3 亿）。
- **同业竞争别只信年报"不适用"**：那是窄法律口径，会漏掉关键个人（二代/技术核心/创始人亲属）以个人身份设立的体外公司——对关键内部人补查公开工商登记；查不到就说"未见公开记录"，别替年报背书。

## 七、质检关（出 PDF 前必过，纯后台、三道独立防线 + 行动前第四道）

详见 `skills/fact-check.md` + `skills/discipline-check.md`。来历：曾在一份报告里既犯幻觉（金额写错、漏算理财误判危机、把一次性当变脸），又犯成见（套"小盘股陷阱"模板、红旗不写善意解释、一边倒）。三道防线就是堵这两类错。

1. **代码对账（最便宜，先跑）**：`check_numbers.py` 把草稿每个金额/百分比分成"✓有据/⚠未匹配"，并打印地面真值（含真实净现金=货币资金+理财−有息负债）。
2. **防幻觉 agent（独立上下文）**：用 Agent 工具起一个干净上下文的子代理，**只喂原始材料 + 草稿、不带写报告时的推理**，把每个数字、每句具体事实/引语对抗性地回查到 `financials/` 或 `filings/` 原文，默认"无据"，输出 🔴必改/🟡存疑。
3. **防成见 agent（独立上下文）**：再起一个子代理，按纪律清单逐条查（见模块八）。

**独立上下文是命门**——一旦让检查 agent 读了草稿结论再"复核"，它就和作者共享盲点了。检查 agent 只挑错、不改写；最终判断和修改由主 Claude 做。**收两份红黄牌 → 改掉所有 🔴 → 清零，才出 PDF。**

4. **红队结论 agent（第四道，2026-06-10 新增，攻击论点本身）**：前三道查事实和措辞、不查结论。当**用户要行动 / 价格进入观察区 / 首次结论为偏低有边际**时，必须再起一个独立 agent，唯一任务＝构建"verdict 是错的"最强论证（偏空结论给最强多头案、偏多结论给最强空头案、攻击概率分布与情景宽度）；主 Claude 逐条回应或修改，驳回必须给证据级理由。详见 `skills/red-team.md`。

> 另：`check_numbers.py` 的地面真值 metrics.json **本身也可能错**（净债口径曾系统性漏算短借、咬过两家）——冲突时查 `survival.debt_components` 覆盖缺口、回年报附注裁决；改了计算代码必跑 `python3 scripts/test_metrics.py` 金标准回归。

> 派子代理防卡死：重本地大文件（如约 30 万字年报）的提取/质检代理走**前台**、prompt 硬性要求"先 grep 定位章节、再 Read 小段(offset/limit)、禁止整篇读"——频繁小工具调用让运行时看门狗（>600 秒无工具调用即判停）保活；后台只留给频繁出工具调用（联网类）或短任务。

## 八、反成见铁律（最高优先级偏好）

**基调＝发现价值，不是批判公司。** 用户强偏好，全程守。

- **三段式**：① 中性摆事实 → ② 先给最善意/牛市视角再判断 → ③ 落到"要盯什么去发现价值"。
- **每个红旗先写最善意的解释、再判断；每个问题给两面、别一边倒。**
- **禁用偏激标签/人格标签**：毁灭价值、投机泡沫(当定性)、续命、命门、为别人买单、失控、赌徒型、凑规模、割韭菜……一律不用，哪怕亏损投机股也公允对待。**成见也藏在用词里**——主旨句、小节标题、形容词会偷偷定性；批评只落在"具体能力 + 机制证据"上，不给管理层贴人格标签。（报告里可以出现人名，naming 本身不违规；要查的是有没有贴标签。）
- **别套模板**：不带预设结论、不套"陷阱/泡沫/伟大公司"模板，不借"衰退小盘股"之类的负面篮子起范。
- **防乐观成见（对称版，结论偏正面时同样狠）**：当结论是"便宜/有安全边际"时，专门查乐观偏移——① 熊市举证要铺得和牛市一样具体（别牛市有机制有画面、熊市一句带过）；② 别用"免费期权/赔率偏上行"这类轻快措辞把高度不确定的东西说得像白捡，明写"到期日不确定、可能长期不行权、代价是机会成本"；③ 别把未核实的数喂进估值再据此下结论（可精确查的必须钉死）；④ 多空举证门槛对称。

> 防成见和防幻觉一样，是对抗性的：不是写完检查一遍，是让一个不知道你结论的独立 agent 来挑。

## 九、写作标准（最高写作标准）

详见 `skills/report-writing.md` + `templates/report-template.md`（九章结构）。

- **展示别断言（show, don't tell）**：每个判断后面必须跟具体数字/机制/画面。绝不写成"放大版摘要"。
- **一章一章深挖**：写透一章再下一章，深度优先于覆盖面；穷尽、给具体公告/事件/证据；追求完整度、不限页数。
- **各章守边界**：业务概述里别把控制权条款、治理全貌、估值整段铺开——点到 +「详见第 X 章」即可，否则后面章节空心化、全篇重复。
- **标点与排版（用户强偏好）**：**正文完全不加粗**（只标题/表头加粗）；**引号除非逐字引原话否则一律不用**。PDF 每章新起一页、微软雅黑、行距 2.0。（注：本总纲属方法论文档、用了加粗做结构，是文档体例；写报告正文和日常回复时不加粗。）
- **九章结构**：业务概述 → 发展历程 → 行业与竞争格局 → 商业模式与盈利引擎(嵌第一柱) → 资本配置(嵌第三柱) → 组织治理与诚信 → 财务全貌(嵌第二、四柱 + 会计可信度) → 投资分析与估值(三情景 + 反向DCF + 核心driver + 四柱→安全边际) → 风险全景(风险矩阵)。

## 十一、越学越智慧（闭环，把一次性研究变成可记分的持续进化）

详见 `skills/postmortem.md`（2026-06-10 大改版）。复盘对象三层：**driver 预测 → 单家公司 → 这台机器本身**。

1. **沉淀**：每家定稿后写 `decision.json`——除判断/区间/概率外，把预测钉成**可判对错的四元组**（指标+阈值+期限+查证处）、写 `review_by` 和数字化 `entry_watch`、贴原型标签、存事前验尸两段；odds 与隐含年化由代码算。
2. **回喂（每次分析前必做）**：先读 `reviews/LESSONS.md`（教训）+ `reviews/ARCHETYPES.md`（同型判例）+ 用到概率时查 `reviews/BASE_RATES.md`（外部锚）。**光记不回喂就只是日记**。
3. **复盘（三类触发：新数据 / review_by 或预测到期 / 价格进观察区）**：先**盲评**（独立 agent 只看新数据、不看旧结论）再对照原判断 → 逐条给 predictions 打分（hit/miss/unresolved，**按 driver 记分、不按股价**）→ miss 按五类归因（数据错/生意理解错/概率校准错/不可知意外/纪律违反）→ 打分登 `reviews/CALIBRATION.md`、提炼 ≤1 条可推广教训进 LESSONS → **属"清单本可拦住"的，升级成 fact-check/discipline-check 查项（教训的终点是清单、不是散文）**。防 resulting：单次坏结果不证明决策错、靠运气对的也不算对。
4. **机器级复盘（季度）**：汇总台账看概率桶校准（说 45% 时是不是 45%）、verdict 方向命中分布（纪律还是系统性偏空）、误差类别分布 → 升级动作写回各库。

## 十二、踩过的坑·可推广教训精选（动手前扫一眼）

> 完整列表在 `reviews/LESSONS.md`，这里是最高频、最致命的几条。

**财务阅读**
- "现金紧张"要看 货币资金 + 理财 + 大额存单 − 有息负债 的合计，别只读"货币资金"一行（钱常只是从活期挪进了理财）。
- 异常盈亏先剥离一次性项目（诈骗/处置损益/政府补助/减值/汇兑）再看主业；别把一次性亏损当业绩变脸。
- 折旧/摊销年限变更要跨年 diff 表本身，别只看最新一年附注的"本年不适用"。
- GAAP 亏 ≠ 经营失血——先看是不是非现金 SBC + 重研发造成的会计假象（判别看经营现金流符号）。

**周期 vs 结构**
- 核心业务单年大幅下滑，先判断是周期波次还是护城河塌方——两者结论完全相反，必须用行业"游戏规则"去分。

**估值**
- "生意值多少"和"这个价格买不买"是两个独立问题，别糊成"又贵又烂"或"又好又该买"。
- 现价 ≈ 最乐观(Bull)情景时，结论是"好生意、贵价格、不在此价位买"，而不是因为生意好就追高。
- 控股集团 SOTP 只扣母公司外部净债、不扣合并净债（同一笔债别算两次）。
- 待决并购/特殊情形：把估值拆两条腿（成交 vs 破裂）按概率加权，别只算一条。

**事实核查**
- 凭记忆枚举参股/子公司/代码必错——务必联网 + 一手年报双重核（曾把易宝支付误记成银之杰参股、把贝特瑞代码记成旧的 835185、把马应龙市值估高近五成）。
- 一手年报 > 二手联网，尤其涉人涉刑的指控：媒体口径要回年报/裁判文书原文核，未证实的不作为事实写。
- 把传闻和事实分清（如"被立案"的不实传闻 vs 真实监管处罚）、把字面相近的人名分清（李俊≠李军、何剑≠何晔）。

**成见**
- 红旗先写善意解释；不贴人格标签；不套模板；偏激词清零。
- 结论偏正面时防乐观成见，和防悲观成见一样狠（熊市铺厚、别用轻快词、别锚未核数）。

**机器自身（熔断原则，2026-07-05 入总纲——防这套方法论长成博物馆）**
- 任何新机制立项前，必须指名它本可以抓住哪个已经发生过的真实错误；指不出＝不建。
- 出现新错误类型时，优先问现有五关哪一关的查项能覆盖——加查项优先于加关（第六道质检关明确不做）。
- 学习闭环没吃到足够数据（预测结算 <10 条）之前，克制再加新学习机器的冲动。
- 台账在 `reviews/OPTIMIZE.md`，每季度末盘一次——路线图自己也会腐烂，敢砍不再值得做的。

## 十三、评判"一笔分析做得好不好"的自查清单

- [ ] 我能不能用三句话讲清这门生意怎么赚钱、护城河在哪、游戏规则是什么？
- [ ] 判过原型、调过同型判例了吗（ARCHETYPES）？
- [ ] 四柱（复利引擎/所有者盈余/资本配置/生存）每一柱都有硬数字 + 一句落到这家公司的判断？净债是全口径吗（查 debt_components 覆盖缺口）？盈利质量取证的 flags 处理了吗？
- [ ] Track 分流对不对？现金流为负/资产型的有没有错用 DCF？

- [ ] 情景概率和成熟利润率给了 base rate 外部参照吗（BASE_RATES）？
- [ ] 反向 DCF 说清了"市场在买什么故事、隐含多高的预期"？
- [ ] 生意 vs 价格分开答了？安全边际双口径（保守 + 期望/odds）都给了、没把加权中枢当目标价？
- [ ] 周期行业做了供给侧外查（行业 capex/在建产能/融资潮）、不只看自家高峰旗？
