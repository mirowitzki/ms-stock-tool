# 技能：论点保鲜巡检（季报后给"现在的论点"续命——不是给过去打分）

> 来历（2026-07-05，OPTIMIZE O14）：postmortem 给过去的预测打分，但没人给**现在的论点**续命——
> 报告是快照、论点按季度腐烂（RKLB 教训：分析锚 $71.74、三个月后价格 $108/基本面大动，
> 靠人肉巡查才发现脱节）。巴菲特 Tesco 的 dawdling 也是同一族：恶化的证据一季季进来、
> 旧结论一季季沿用。这个岗位的活：每季财报后，把每家的承重判断逐条对一遍新数据。

## 什么时候跑

每季财报季结束后（A 股 4/8/10 月末、美股各家财报后），对**在册全部公司**跑一轮；
review.py 的"新季报"触发就是入口。每家目标 30 分钟，快审、不重做。

## 每家怎么走（30 分钟流程）

1. **重跑代码**：`python3 scripts/compute_metrics.py <代码>`（四柱+全部旗标自动更新：
   现金验真 / 量层剪刀差 / 周期高峰 / 盈利质量）；`refresh_quotes` 已日常刷价。
2. **九章承重判断逐条标状态**：把报告各章的承重判断（每章判断卡的 verdict/spine）拉成清单，
   对最新季报逐条标——**站得住 / 动摇 / 翻了**：
   - 站得住＝新数据印证或无冲突；
   - 动摇＝方向存疑但证据不足以翻（写明缺什么证据、下一季看什么）；
   - 翻了＝承重判断被新数据证伪。
3. **只有"翻了"触发全量重做**（重抓数→重写相关章→过五关→重登记）；"动摇"只登记观察点，
   不在巡检里偷偷改结论（与 postmortem 流程 7 同一条纪律）。
4. **顺带核三样**：价格相对分析锚漂了多少（±30% 以上必须重看 reverse_dcf_commentary 措辞）、
   predictions 有没有提前兑现/证伪、entry_watch 的 invalidation 有没有被新公告触发。
5. **产出 append 进该公司的 review 文件**（`review_<日期>.md` 或新建）：一张三列表
   （承重判断 / 状态 / 依据一句话），别写散文。

## 与复盘（postmortem）的分工

- 复盘＝到期结算过去的预测（打分、归类、进校准台账）——往回看；
- 保鲜巡检＝检查现在的论点还新不新鲜——往前看；
- 两者常在同一次触发里连着做（先巡检、再结算到期预测），但产出分开记。

## 铁律

- 快审不是重做：30 分钟一家，超时说明该走全量重做而不是巡检；
- "翻了"的判定要引具体新数据（哪个数字/哪份公告），不许凭感觉；
- 巡检发现的可推广教训照常进 LESSONS / 原型库（结案归档同款纪律）。
