在第 1 层（dossier + 完整报告 + 能力圈判断）完成后**自动运行**（用户 2026-05-31 改：不再等用户确认能力圈）。

## 估值哲学（总纲 · 所有公司、两条 Track 都适用）

这六条是本工具做估值的根本方法论。**任何一次估值都必须体现它们**，无论 Track A 还是 Track B。

### 一、估值的本质：得到一个【价值区间】，不是一个数
估值不是算出一个精确的"内在价值"，而是基于"对企业未来的若干假设"得出一个**价值区间**。未来不可知，所以用 **2–4 个情景 / 故事**代替单一预测。**"大致正确"远胜过"精确地错"**——宁可给一个诚实的宽区间，也不要一个虚假的精确点。

### 二、故事在前，数字在后（关键顺序，不能颠倒）
每个情景**首先是一个自洽的故事**：接下来几年这家公司会发生什么、关键变量怎么走、竞争格局如何演变、若成真它会长成什么样。**然后从故事里"推出"大致的增长率、利润率**——这些 rate 都是模糊的"毛估"，而且**彼此逻辑必须自洽**：高增长通常伴随高投入、需要更高折现率，不能只挑对自己有利的那一端拼凑。
**绝不能反过来——先定一个 CAGR，再硬凑一个故事去解释它。** 那是用数字伪装判断。

### 三、每个故事给一个价格【区间】，不是单点
既然 rate 本身是模糊的，就让每个情景的关键 rate 各取一个**区间**（如营收 CAGR 15–25%、成熟期 FCF 率 12–16%、折现率 11–13%），算出来的每股价值自然也是一个**区间**（"这个故事大致值 $X–$Y/股"）。
代码层面用 `scripts/valuation.py` 的 **`scenario_value_range`**：每个情景传入各 rate 的"低 / 高"两端，它把**保守组合**（低增长 + 低利润率 + 高折现率）和**乐观组合**（高增长 + 高利润率 + 低折现率）各算一遍，输出价值区间，而不是单一数字。

### 三补、预测窗口：5 年显性为头条，10 年为延伸参考（默认）
- **头条口径＝5 年显性预测**（`scenario_value_range` / `reverse_dcf` 的 `years` 默认 5）。5 年内的护城河、产品周期、管理层任期、竞争格局基本看得清，更在能力圈内、可证伪性强；第 6–10 年对多数公司是讲故事。轨迹仍由 Y1→Y10 定义，5 年口径＝截取前 5 年做显性期、终值落在第 5 年、稳态用成熟 FCF 利润率。
- **同时并列一个"延伸至 10 年"的参考值**（同函数传 `years=10`）。**两者差距本身就是信号**：差距小（如成熟慢牛 002091，5 年≈10 年）＝价值扎实、不靠远期；差距大（如 SITM / NVTS，10 年中枢是 5 年的 2–4 倍）＝市场把大量乐观押在了最难看清的第 6–10 年——这正是 Bull 故事最容易藏泡沫的地方。
- **反直觉但要记牢**：窗口越短，终值占总估值的比例越高（5 年常占 ~85%、10 年 ~70%）。缩短窗口不会让你少依赖长期假设，只是把它从逐年路径挪进终值。**纪律来自把第 5 年后的稳态（这里＝成熟 FCF 利润率）显性写出来，而不是塞进一个偷偷调高的终值。**
- 交互器同此口径：情景卡头条是 5 年区间、并标"若延伸至 10 年 ≈ $X（参考）"；营收/FCF 图前 5 年实线（显性）、后 5 年虚线（参考）；反向 DCF 主显 5 年隐含、并列 10 年。

### 三补二、概率与终值的外部锚：base rate 先行（2026-06-10 新增）
估值里最主观的两个输入——**情景概率**和**成熟期 FCF 利润率**——不许纯凭内部视角拍。规矩（外部视角先行）：
- **给情景定概率之前**，先查 `reviews/BASE_RATES.md` 同类事件的历史频率，在估值章写一行：同类情形的 base rate 约 X、我认为这家偏离因为 Y（公司特有的强证据）。没有强证据，概率不许大幅偏离 base rate——偏离越大、举证责任越重。（例：A 股跨界转型做成第二主业的先验偏低，市场却按六七成定价——这一句对比本身就是结论的一半。）
- **终值天花板**：成熟期 FCF 利润率是全体系最承重的单个数字（5 年口径下终值占价值约 85%）。设定时必须给出**同业历史最佳值**作参照（见 BASE_RATES 第二节）；假设值超过历史上同类公司做到过的水平，必须单独论证凭什么（默认提级审查，超过 25-30% 尤其要警惕）。
- 每次分析顺手往 BASE_RATES.md 添或核一条；复盘时若先验被结果打脸，回去改库（C 类误差）。

### 四、安全边际是核心：先看下行，再看上行
**不要因为"故事成立"就认为该买。** 真正的问题是：**即使在保守 / 悲观的故事里，价格是否已经够低、低到不会让我永久亏掉本金？**
- **先问"最坏情况亏多少"，再看上行。**
- 假设拿不准时**一律往保守取**。
- **头条用双口径（2026-06-10 新增）**：①**保守口径**＝现价相对中性情景下沿的折扣（回答：最坏看错亏多少——这是 margin of safety 的本义）；②**期望口径**＝赔率与隐含回报（odds：现价到价值区间两端的不对称度；expected_irr_5y＝(价值/现价)^(1/5)−1，**代码机械推导、不是预测**）。两者并列、各答各的问题；**概率加权中枢是期望值、不是目标价**，别把它当保守估计用。odds 与 IRR 写进 `decision.json`（schema 见 `skills/postmortem.md`）。
- **不要拿管理层最乐观的预测当锚**——尤其当它有食言 / 反复跳票记录时（看第 1 层整理的"预测 vs 兑现"记录）。
- 安全边际不是建议，是**闸门**：不够就不买，公司再好也一样。

### 五、反向 DCF = 市场买入的那个故事
把**当前价格**反解成"**市场正在押注的那个故事**"（用 `reverse_dcf` 得到隐含的增速 / 利润率，再翻译成具体叙事），然后和你自己的几个故事并排比较：
- 若市场的故事比你**最乐观的故事还激进** → **没有安全边际**，公司再好也不构成买入理由。
- **价格 ≠ 价值；好公司 ≠ 好投资。** 一家伟大的公司，买在透支了未来十年的价格上，仍是一笔糟糕的投资。
- **当现价高于你所有情景的上限时，先别急着判"价格不可能/没道理"——回头把"市场到底看见了什么"这个多头故事 steelman 到底**（再融资/资产注入、平台化换股的每股增厚、整体 re-rating……），给它一段完整自洽的故事 + 一个（可以很低的）概率，再下结论。"任何情景都撑不起这个价"往往不是结论、而是信号：**多头的真实论点你还没找全**——那既不公允（违反反成见），也意味着你没真正读懂这个价格在赌什么。把它补成一个情景，再说有没有安全边际。

**market_story 必须挂真实来源（2026-07-05 加，O9）**：反向 DCF 算出"隐含什么"是硬的，但"市场为什么信这个故事"不能是我猜的——`reverse_dcf_commentary.market_story` 要引 **≥2 条真实的市场叙事来源**（主流卖方观点、媒体共识报道，标题级引用即可；市场无人覆盖就如实写"无卖方覆盖、叙事由 XX 事件驱动"）。认知差＝对照真实共识、不是对照想象中的市场。

**判断带宽度要反映真实不确定度（2026-07-05 加，O10）**：情景的 value_low/value_high 判断带不许装饰性收窄——带宽跟着不确定来源走：**硬锚可以窄**（中性=账面÷股本这类可精确复算的，窄是诚实）；**软资产敞口大/估的成分大就要宽**；周期型给正常化区间。检验一句话：这个带宽是"我真的只有这么点不确定"还是"显得精确好看"？（600327 样板的读法：单情景 ±2% 窄带是围绕代表值的呈现带、真实不确定度由熊到牛整条区间 ¥2.6-3.8＝±19% 表达，且下行另有软资产减值+抽血的显式构成——窄带有锚就合法，无锚的窄带违规。）

### 六、讲不出可信的故事 = 看不懂 = 放弃
如果你**无法为一家公司形成几个可信、自洽的故事**（关键变量说不清、行业看不懂、管理层判断不了），那就是**超出能力圈**：放进"太难"篮子，**不勉强估值**。给一堆假设硬算出来的数字，只会制造"我懂了"的错觉。

### 七、"好生意"和"好价格"是两个独立问题，分开回答
**绝不能把"贵"和"烂"糊成一句话。** 任何结论都拆成两问、分别作答：
1. **作为一门生意，它值多少？**——护城河、正常化盈利能力、分部加总，**与现价无关**。
2. **作为这个价格的股票，现在买值不值？**——现价 vs 内在价值区间 → 有没有安全边际。

一门好生意可以是烂股票（买太贵），一门平庸生意也可以是好股票（买够便宜）。**先把"生意值多少"说清楚，再单独判断"这个价格"。** 把两者混成"又贵又烂"或"又好又该买"，几乎一定是分析没做透——这是最容易犯、代价最大的错。

### 八、估值锚在"治理 + scenario story"，模糊无妨
估值不是去逼近一个精确数，而是回答：**这家公司应该如何被治理、未来会发生哪些 story，每个 story 下它大致值多少。** 从故事推价值，**毛估区间即可，模糊一点完全没关系**——"模糊的正确"远胜"精准的错误"。

### 九、近期动作雷达：用 PR / 公告反推故事（但绝不被它牵着走）
公司最近的新闻稿、公告、发布会、业绩指引，是"接下来几年会做什么"这个问题最新鲜的原材料——和五年显性故事天然对口。**但 PR 是口号最密集的地方，而我们的铁律是"看行为、不看口号"。** 所以近期消息的用法是：**反推动作 → 喂故事和催化剂，但绝不让它定价。** 每条近期动作过下面四问，再决定它进不进估值：

1. **剥掉形容词，动作是什么？** 把"重塑/颠覆/史上最强"翻译成可证伪的事实：出什么产品、投多少钱、签了谁、给了什么指引。**只有真金白银/路线图的承诺（行为）才算数，纯叙事（口号）只当作要 steelman 也要怀疑的对象。**
2. **收入机制 + 时点？** 钱具体怎么赚、TAM 多大、何时出货放量、毛利几何、从谁嘴里抢肉、对手会怎么反击。**当心"看着新增、其实早算在现有口径里"**（如某颗芯片的收入其实已含在现有系统销售里，真正增量远小于头条数字）。
3. **落在哪个窗口——五年显性，还是 6–10 年远期？** 这直接接第三补条的五年/十年口径。**越是轰动的"长期愿景"，越要警惕它其实是押在最难看清的第 6–10 年**——那正是 Bull 最容易藏泡沫的地方。近期能放量的进五年线、长期期权进十年参考线。
4. **是否已经被定价？** 把这条动作塞进**反向 DCF**：现价是不是已经假设了它成功。**轰动 ≈ 多半已被 price-in**——等人人喊颠覆时，股价通常早动过了，这时追的是叙事动能、不是价值。若隐含预期已经离谱，这条 PR 不构成买入理由、只构成更高的风险。

过完四问，动作的去向是**两处，都不是直接改目标价**：① 写进对应情景（多半 Bull / Base）的 **story**，并据此**谨慎微调主观概率**（已被定价的就别硬抬概率）；② 写进 `decision.json` 的**催化剂清单**，做成可盯的里程碑（设计导入、OEM 采用、实际出货量、份额数据），供 `review.py` 复盘对账。报告里固化成"近期动作雷达"小节（见 `templates/report-template.md`）。**诚实优先：若结论是"已被定价"或"属 6–10 年远期"，就如实写，绝不为了让故事性感而硬造上行。**

## 第一道分流：判断这家公司属于哪一类

估值方法不止一种。**用错方法会得到看似精确但毫无意义的数字。** 先判断公司属于哪一类：

| 公司画像 | 走哪条 Track |
|---|---|
| 有稳定为正的所有者盈余、利润率/ROIC 长期稳定、生意可预测 | **Track A：标准两阶段 DCF** |
| 未盈利、利润率剧烈波动、价值押在未来某个里程碑（产品上市、技术突破、市场拐点） | **Track B：情景前瞻 DCF + 反向 DCF** |
| 过渡中（近 1-2 年才转正但还不稳定） | **Track B**（但对乐观情景保持额外谦逊） |
| 盈利微薄但**资产重 / 现金多 / 低 ROE / 周期底部 / 多业务且有特殊事件**（控制权变更、重组、剥离） | **Track C：资产地板 + EPV + 分部加总 + 特殊事件情景** |

**关键判断信号**：看 `financials.csv` 里近 5 年的所有者盈余（经营性现金流 − 资本开支）。
- 如果近 5 年至少 3 年为正、且 5 年累计为正 → Track A
- 如果近 5 年累计为负 → Track B
- 如果一年正一年负、剧烈波动 → Track B

## Track A：成熟公司的标准 DCF

### 原则
- **数字用代码算**：所有计算交给 `scripts/valuation.py` 的 `two_stage_dcf`，基于 `financials.csv` 的精确数据。Claude 只负责给出**判断性输入**（增长率、折现率、永续增长率）并解释理由。
- **所有者盈余 > 报表净利润**：用经营现金流 − 资本开支的口径近似自由现金流；并对资本开支做"维持性 vs 扩张性"的判断（这一步是判断，不是算术）。

### 步骤
1. 让 `valuation.py` 算出近几年的所有者盈余 / 自由现金流。
2. 基于第 1 层对生意的理解，给出 DCF 的假设：
   - 高速增长阶段的增速与年数（能从"生意为什么会增长"讲清楚，而不是拍脑袋）
   - 永续增长率（保守，通常 2-4%，不超过长期 GDP 增速）
   - 折现率（反映不确定性；越看不懂、越不确定，要求越高，通常 8-12%）
3. 也用更朴素的参照：盈利收益率 vs 长期国债利率；在质量与增长背景下看市盈率。
4. **安全边际闸门**：价格是否显著低于内在价值估计？没有足够安全边际 = 不买。

## Track B：未盈利成长公司的情景 + 反向 DCF

### 为什么不用标准 DCF
- **起始所有者盈余为负** → 标准 DCF 数学上跑不出有意义的结果（负数复合增长是无意义的）
- **单一"基准"假设掩盖了真正的不确定性** —— 这类公司估值的关键不是"精确预测一个数"，而是"理解可能性的分布"
- **价值集中在未来某个里程碑上** —— Neutron 能不能飞、AI 模型能不能落地、新药能不能批——是二元化结果，平均假设会同时高估悲观情景的下行和低估乐观情景的上行

### 步骤

#### 1. 建三个情景（不是 +/-10% 调整，是讲三个完整故事）

**悲观（Bear）**：关键里程碑失败或长期搁置。公司退回到一个"小而稳"的版本，长期难以稳定盈利。
**中性（Base）**：关键里程碑按推迟后的时间表实现，但被竞争对手压制，达不到管理层当年最乐观的预测。
**乐观（Bull）**：关键里程碑成功兑现，原始战略叙事大部分实现，但仍保留对执行风险的折扣。

每个情景围绕公司的**关键变量**展开（如 RKLB 的 Neutron 成败 + 盈利路径、新药公司的关键试验结果、AI 公司的技术拐点）。

**每个情景都要写成一段叙事，不是几行参数。** 讲清楚：接下来几年这家公司会发生什么、关键变量怎么走、如果成真它会长成什么样——然后才挂一个毛估的价值区间。情景的故事必须基于这家公司自己的资料和关键变量来写，**绝不套模板**。

**对手桌检查（2026-06-10 新增，Bull/Base 必过）**：情景写完后过一遍牌桌上其他人的最优反应——**竞争对手**会怎么反击、**最大客户**会不会压价/自研/扶二供、**供应商/渠道**会不会涨价抽走增量、**监管者**会不会出手。反应之后故事还成立，才算成立。（教训：CRCL 的增长果实被 Coinbase 重谈分账吃掉——渠道方的最优反应就是涨价；不做对手桌推演，Bull 常把"没人还手"当隐含假设。）

**单位经济硬要求（2026-06-10 新增）**：凡有披露，Bull 情景必须落到单位经济算得通——单价 × 销量 × 单位成本能拼出那个利润，而不是一条凭空的利润率曲线；讲不出单位经济的 Bull，概率自动降档处理。

#### 2. 从故事推出各 rate 的【区间】（低 / 高），不是单点

故事写完后，**从故事里推出**下面这些 rate，每个都给一个**低 / 高区间**（区间宽度反映你对这个故事的把握程度）：

| rate | 说明 |
|---|---|
| **营收 CAGR（低 / 高）** | 从"生意为什么会增长"推出，不是拍脑袋的年增 X% |
| **成熟期 FCF 利润率（低 / 高）** | 终值期的自由现金流率；参照同行能达到的天花板 |
| **折现率（低 / 高）** | 不确定性越大要求越高；Track B 通常 11–15% |
| **起始 FCF 利润率** | 今天的实际 FCF 率（可为负），决定从亏到盈的爬升起点 |
| **永续增长率** | 保守，2–4%，不超过长期 GDP |
| **未来稀释后的股数** | **Track B 最容易忽略的杀手——必须用"未来"股数，不是今天的** |

**rate 之间要逻辑自洽**（第二条原则）：高增长的故事往往伴随更高投入与更高折现率，别只挑好的那一端。

**为什么未来股数关键**：Track B 公司大概率持续股权融资以渡过烧钱期。今天 5 亿股 → 5 年后可能 6-7 亿股。用今天的股数算每股价值会**系统性高估 20-40%**。

#### 3. 用 `scenario_value_range` 算每情景的价值【区间】

把每个情景的 rate 区间传给 `scenario_value_range`：它用**保守组合**（CAGR 低 + 利润率 低 + 折现率 高）和**乐观组合**（CAGR 高 + 利润率 高 + 折现率 低）各算一遍，输出该故事的每股价值区间 $X–$Y。**每个情景的输出是一个区间，不是一个数。** 把 2–4 个情景的区间合起来，就是这家公司的总价值区间。

#### 4. 用 `reverse_dcf` 做现实检验，并翻译成"市场买入了什么故事"

反过来问：**今天的市场价已经隐含了什么预期？**

先用代码把隐含预期解出来（两种模式）：
- 固定一个合理的成熟期 FCF 利润率（比如 15%），反解：营收必须以多少 CAGR 增长？
- 固定一个合理的营收增速（比如 20% CAGR），反解：成熟期 FCF 利润率必须达到多少？

**但这串数字不是结论，只是原料。反向 DCF 的灵魂，是把它翻译成一个【针对这只股票的、具体的故事】**——今天这个价格，等于市场在押注一个怎样的未来？这个故事必须基于这家公司自己的关键变量写，**绝不能只甩"隐含 X% CAGR、Y% 折现率"就完事，也绝不套模板**。

> 写法示范（RKLB）：「以今天的股价，市场买入的是这样一个故事——Neutron 不仅按时成功首飞，还在两三年内迅速上量、成为 Falcon 9 之外真正被信任的中型火箭；政府长期把它当作不可替代的国家安全二供；Space Systems 持续高速增长。十年后 Rocket Lab 要长成一家年营收数百亿、体量逼近今天 SpaceX 的航天巨头。要相信今天的价格合理，你就得相信这个故事会兑现——而历史上能持续这种增速的公司屈指可数。」

写完故事，再对照三情景判断方向（幅度毛估即可）：
- 如果当前价格已经在 price-in 乐观情景（甚至更激进）→ "看到价值"其实是在 bet 进一步乐观 —— 危险
- 如果当前价格在悲观和中性之间 → 中性情景兑现就有显著上行 —— 合理风险/收益
- 如果当前价格已经在悲观情景以下 → 极度悲观假设已被定价 —— 反向机会

#### 5. 逆向思考：悲观情景的永久性损失

如果悲观情景兑现，**当前价格 → 悲观情景内在价值的跌幅是多少**？这是你愿意承担的最大下行。

如果"悲观情景下永远跌不回"+"乐观情景给的上行只有 50-100%"，那**赔率/概率不对**，不应买。

#### 6. 安全边际判断

- 安全边际 = (区间下沿 − 当前价) / 当前价
- Track B 公司因为不确定性大，要求的安全边际要比 Track A 大（30-50% vs 20-30%）
- 安全边际不够 → 不买
- 把"判断性假设"清单留给用户，让他能调整任一假设重算

## Track C：资产重 / 现金多 / 低 ROE / 有特殊事件的公司

### 为什么 A、B 都不合适
这类公司（典型：盈利微薄、资产负债表很重或现金/理财很多、合并 ROE 极低、多业务且毛利被某一块拖累、又叠加控制权变更 / 重组 / 剥离等特殊事件）——**标准 DCF 跑不出意义**（现金流薄且波动、合并口径失真），**情景前瞻 DCF 也抓不住价值**（它的价值不在"未来一条增长曲线"，而在"资产 + 把资产重新配置好的期权"）。

> 经验法则：**经营现金流连续多年为负时，DCF 一律不作主方法**，只作辅助参考。

### 四把尺子（都给毛估区间，不求精确）
1. **调整后资产价值（价值地板）**：净资产按可回收性谨慎调整（商誉 / 应收 / 存货打折、理财按净值、**真实现金 = 货币资金 + 理财 + 大额存单 − 有息负债**）。现金多、负债低时，这个地板往往很扎实，是下行保护。
2. **收益能力价值 EPV（假设零增长）**：正常化所有者盈余 ÷ 要求回报率 + 净现金。**若 EPV < 调整后资产价值，说明公司在合并层面"毁灭价值"**——资产换个用途或还给股东，比留在公司里更值钱。这是关键诊断：价值释放靠"资本配置变好"，不靠"业务变好"。
3. **分部加总 SOTP**：在"结构修复、亏损块出清"的假设下，把每块业务单独估值再加总 + 净现金。常远高于合并口径——**差额就是被低效结构困住、要靠催化剂才释放的护城河价值**。（分部数据用 `financials/segments.json`。）三条纪律，缺一就把 SOTP 做废、把稀缺资产估成白菜价：
   - **按正常化盈利估，别锚在低谷/当期薄利上。** 盈利块用"正常化净利 × 合理倍数"；**若前文判定某块的下滑是"周期波次、会回来"，这里就必须把收入/利润正常化到中周期再给倍数**，不能拿低谷当期数去乘——否则与前文自相矛盾。
   - **倍数要分稀缺度。** 有护城河/独家资质/定价权的块给与之相称的较高倍数；稳定盈利的并购子公司按盈利能力给正常制造业倍数（**只给 3-5×PE 几乎一定偏低**）；平庸竞争块给普通倍数；亏损块给 0 或负。
   - **一致性自检**：SOTP 与前文的护城河/周期判断必须自洽。**若你认定有真护城河、却算出 SOTP ≤ 资产地板，几乎一定是锚在了低谷收入或给了过低倍数**——真有护城河时 SOTP 通常应明显高于地板，回头修。
4. **特殊事件 / scenario story**：控制权变更、亏损业务剥离、周期拐点、历史包袱了结……每个都是一段 story，对应一个价值区间 + 毛估概率。**价值就锚在"公司应该如何治理 + 会发生哪些 story"上，模糊无妨。**

### 结论方式
把四把尺子排出层次（**地板 < EPV < 分部加总 < 各情景上限**），再对照现价，分别回答第七条那两个独立问题：①生意值多少 ②这个价格买不买。**下行优先**（地板托不托得住）、**绝不给单一目标价**。反向 DCF 仍要做：把现价反解成"市场在为哪个情景买单"，看它是否已透支最乐观的 story。

## 逆向检查（反过来想）

在下结论前，**先问：什么会让这是一笔糟糕的投资？**

把最强的反方论证写出来。常见反方角度：
- 关键里程碑可能失败的真实概率，是不是被低估了？
- 竞争对手的下一步动作会不会改变游戏规则？
- 监管/政治环境会不会突然变化？
- 创始人/关键人物离开会发生什么？
- 当前估值是否已经透支了 5 年最好的执行？

如果反方论证站得住，**不要被"它很便宜"或"它有很大上行"说服**。

## 关键纪律（适用两种 Track）

1. **一切呈现都是"毛估估"，看方向别盯小数点。** 价值投资里"大致正确"远胜"精确地错"。`valuation.py` 内部精确计算没问题，但**写进 memo / 报告 / explorer 给人看的数字一律用约数或区间**（如"约 $4–6""大致个位数美元"），涨跌幅取整到约 5–10%；结论给"毛估价值区间 + 方向判断（大致贵 / 便宜 / 公允，以及大约差几倍）"，**绝不给单一精确目标价**。
2. **列出"判断性假设"清单**让用户能调整。每一个假设都标注是"我们的判断"，不是"事实"。
3. **算术全部由代码完成**，Claude 只做判断。
4. **逆向检查永远在最后跑**，避免确认偏误。
5. **安全边际是闸门**，不是建议。

### Track A 的 memo 结构
1. **护城河结论**（一行 + 类型）
2. **所有者盈余表**（近 5 年数字）
3. **DCF 假设与结果**（一张表 + 一行结论）
4. **安全边际**（一个数字 + 一句结论）
5. **关键风险**（3-5 条 bullet）
6. **最终判断**（2-3 句话）

### Track B 的 memo 结构
1. **走 Track B 的原因**（一行）
2. **每个情景 = 一段故事 + 故事隐含的毛估 rate（标注"毛估"）+ 一个价格区间**（故事在前、rate 从故事推出、价值是区间不是单点）
3. **反向 DCF：市场买入了什么故事**（把当前价翻译成市场押注的具体故事 + 它和你几个故事的对照）
4. **下行优先：悲观故事里最多亏多少**（一句 + 毛估幅度——这是核心，先于上行）
5. **结论**：把各情景区间合成**一个总价值区间**，对照当前价给**方向判断**（贵 / 便宜 / 公允，大约差几倍）；**以下行风险为重，不给单一目标价**
6. **关键判断性假设清单**（让用户能调整，对应到 explorer 滑块）

报告里可以出现人名（实控人/董监高/关键交易对手等，用户 2026-05-31 改）；但仍不给管理层贴人格标签。

**判断标准**：如果一段话像在写"分析报告"，它属于深度报告。memo 只回答"我应该买吗 / 在什么价位 / 凭什么故事"。
