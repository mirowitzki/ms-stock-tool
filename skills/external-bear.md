# 技能：真实外部反方采集（第八章「市场上真实的反方」小节的进料）

> 来历（2026-07-05，OPTIMIZE O8）：全系统体检点破"五个法官一个脑子"——五道质检关和 steelman 都是同一个
> Claude 扮的，自造的反方共享自己的盲点。红杉基金对 Valeant 的教训正是这个：内部研究做得再全，
> 缺一个不共享你盲点的真实空头。解法不是加第六道关（熔断原则），而是把"真实的外部反方"
> 变成第八章的标配内容 + discipline-check 的一个查项。

## 岗位定义

一个**联网采集 agent**：去市场上找真实存在的看空/谨慎/质疑观点，带出处带日期，交给主 Claude 逐条回应。
它和 steelman 的区别：steelman 是我替市场编最强反方（可能编在我的盲区外面看不到的地方），
这个岗位是把**真实的**反方原样搬回来——观点可以质量参差，但盲点分布和我不同，这正是价值。
它和红队（red-team.md）的区别：红队攻击我的结论本身、是质检关；这个岗位采集市场观点、是报告内容的进料。

## 什么时候跑

- **每份新报告的第八章必做**（写估值章时派出）；
- 存量报告在下次被触碰时（复盘/重大更新/回补）顺带补上；
- 复盘时如果盲评与旧结论分歧大，也值得再采一轮（市场的反方可能变了）。

## 怎么派（主 Claude 操作）

用 Agent 工具起联网 subagent，任务书要点：
1. 搜集该公司的真实负面/看空/谨慎观点，时间越近越好：券商研报的谨慎观点、财经媒体质疑报道、
   投资者社区的高质量看空帖（要有具体论据、不要纯情绪）、涉及控股股东/行业的负面报道。
2. 每条给：观点概括 + 具体论据 + 来源（平台/媒体+标题+日期）+ 来源等级（按 fact-check.md 证据分级）。
3. **禁止编造观点再安来源**；搜不到就如实说。
4. **无人覆盖本身是发现**：小盘冷门股常常没人认真看空——"没有真实反方"要如实写进小节
   （这时市场观点缺位、steelman 的责任更重，不能拿"没人看空"当利好）。

## 小节怎么写（报告第八章「市场上真实的反方」）

- **≥3 条带出处的真实反方观点**（不足 3 条时如实写明市场讨论热度低、找到几条算几条）；
- 每条**逐条回应**：同意（已在我的熊市/风险里，指出在哪）/ 部分同意（补进对应章节）/ 不同意（给证据级理由，不许用"我原判断如此"）；
- 收口一句：真实反方与我的分歧核心在哪、谁的证据更硬；
- 措辞守用户视角铁律：小节标题用「市场上真实的反方」，不出现 agent/采集/external-bear 这类后台词。

## 与质检的关系

- discipline-check 查项 13.6：第八章有没有这个小节、反方是不是带出处的真实观点（自造 steelman 不算）、有没有逐条回应；
- fact-check 照常核这个小节里的事实与出处（媒体系单源的按证据分级标注）。

## 铁律

- 真实反方的观点**原样呈现再回应**，不许先削弱再回应（稻草人）；
- 回应里驳回必须给证据级理由；
- 社区/自媒体观点标明等级、不冒充研报；涉人涉刑的指控回一手文书核（fact-check 铁律）。
